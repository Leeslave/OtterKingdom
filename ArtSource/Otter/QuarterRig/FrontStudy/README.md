# 정면 시안 V1

`front-v1.png`: 2026-10-12 제작한 화면 정면(남쪽)을 바라보는 캐릭터 시안. 현재 리깅 미리보기의 캐릭터를 참고한 built-in image_gen 생성 이미지입니다. 아이보리 불투명 배경, 파츠 분리 및 리깅 전. 확정 기준 V9는 변경하지 않았습니다.

프롬프트: 현재 ¾뷰 수달을 완전한 정면 전신으로 회전한 턴어라운드 시안. 노란 탐험가 모자와 갈색 띠, 둥근 귀, 크고 둥근 갈색 머리, 아이보리 주둥이와 분홍 볼, 가운데 작은 코와 미소, 크림 반팔, 금색 단추 두 개와 중앙 주머니가 있는 초록 멜빵바지, 어깨의 갈색 가방 끈을 유지. 좌우 눈·어깨·팔·발 대칭, 수평 모자 챙, 짧고 통통한 일자 바지와 작은 갈색 발. 가방과 꼬리는 뒤에 가려짐. 두껍고 균일한 갈색 선, 따뜻한 단색 중심의 2D 게임 그림. 큰 머리와 짧은 몸통 비율 유지. 아이보리 배경, UI·텍스트·그림자 제외.
