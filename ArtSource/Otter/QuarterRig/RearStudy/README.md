## 리깅 V1 (전체 미리보기 V12)

리깅 완료: 상위 `preview.html`의 북서/북동/남서/남동 버튼으로 확인합니다. 북동 뒤쪽 리깅을 좌우 반전해 북서를 표시합니다. 실제 월드 이동이 아닌 제자리 걷기이며 Unity에는 아직 연결하지 않았습니다. 앞쪽은 V11, 사용자 확정 기준은 별도 보존한 V9입니다.

- `rear-parts-atlas.png`: 생성된 뒤쪽 파츠 원본
- `parts/`: 머리+모자, 몸통, 팔, 다리, 꼬리, 가방 PNG
- `rig.json`: 뒤쪽 계층, 피벗, 배치, 레이어 및 보행 설정
- `walk-nw-v1.gif`, `walk-ne-v1.gif`: 방향별 걷기
- `walk-nw-ne-v1.gif`: 두 방향 나란히 보기
- `rig-inspection.png`: 관절과 분리 파츠 확인 화면

머리·몸통·양팔·양다리·꼬리·가방을 9개 변환 노드로 연결했습니다. 파츠에 가려진 부분은 image_gen으로 보완했습니다. 발은 생성 이미지, 바지통은 이전에 승인된 일자 형태의 둥근 도형으로 렌더링합니다. 두꺼운 다리와 가방·꼬리의 지연 움직임을 적용했습니다. 북서 반전은 장비 비대칭까지 함께 반전합니다.

검증: 네 방향 전환, 걷기/대기, 보폭 0/1/1.5의 접지, 관절·분해 표시, 양쪽 24프레임 캡처, 브라우저 오류 없음. 구현 소스는 `Tools/QuarterRig/`의 build.cjs, preview.html, check.cjs, export_rear.py입니다.

파츠 생성 방식: built-in image_gen. 프롬프트 요지: 오른쪽 북동 시안을 같은 스타일로 3열×2행의 투명 파츠 시트로 분리. 윗줄은 얼굴 없는 뒤통수+모자 / 머리·팔·다리·가방 없는 뒤쪽 몸통 / 크림 소매와 갈색 손의 팔. 아랫줄은 짧고 통통한 초록 바지+발 / 왼쪽 아래로 향하는 수달 꼬리 / 플랩과 금색 버클의 갈색 가방. 가려진 어깨와 허리를 채우고, 각 파츠를 충분한 여백으로 분리, 내부 불투명·외부 투명, 텍스트와 배경 제외.

`northwest-northeast-v1.png`: 왼쪽 북서(↖), 오른쪽 북동(↗) 이동 자세의 뒤쪽 ¾뷰. 정면 시안과 현재 리깅의 의상·가방을 참고한 built-in image_gen 생성 이미지입니다. 아이보리 불투명 배경, 파츠 분리·리깅 전. 기준 V9와 기존 리깅은 변경하지 않았습니다.

생성 프롬프트: 같은 수달 탐험가의 북서 및 북동 뒤쪽 45도 전신 모습을 같은 크기로 나란히 배치. 뒤통수와 갈색 플랩·버클 가방을 주로 보이고 얼굴·눈·코·앞주머니는 보이지 않게. 노란 탐험가 모자, 갈색 띠, 둥근 귀, 크림 반팔, 초록 멜빵바지, 짧고 통통한 일자 바지와 작은 갈색 발, 가방 아래에서 뒤로 이어지는 굵은 수달 꼬리 유지. 한 발 내딛는 자세와 가벼운 팔 교차. 큰 머리와 작은 몸통, 두꺼운 갈색 외곽선, 따뜻한 단색 위주의 2D 게임 스타일. 아이보리 배경, 그림자·텍스트·UI·추가 오브젝트 제외.
