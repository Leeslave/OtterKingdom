# 첨부 해달 · 웨이터/맨몸 V9 리그

2026-10-13. 사용자 첨부 웨이터 이미지와 맨몸 이미지를 바탕으로 만든 앞쪽 오른쪽 ¾뷰 컷아웃 리그.

- `preview.html`: 단독 브라우저 미리보기. 웨이터/맨몸 전환, 대기/걷기, 속도/보폭, 좌우 반전, 작은 크기, 관절/분해, 부위별 위치·크기 조절.
- `waiter-walk.gif`, `bare-walk.gif`: 각각 24프레임, V9 주기 0.84초.
- `waiter.png`, `bare.png`, `*-phases.png`: 조립 상태와 주요 위상 캡처.
- `reference-waiter.png`, `reference-bare.png`: 전달받은 원본 그대로 보존.
- `atlas.png`, `parts/`: built-in image_gen으로 ¾뷰를 재구성하고 추출한 7개 투명 파츠. 최초 생성안은 `atlas-v1.png`.
- `rig.json`, `provenance.json`, `verification.json`: 관절/파츠 데이터, 기준 원본 해시, 검증 기록.

## 적용 범위

고정된 `QuarterRig/Baseline-V9`의 pose/legPose 함수와 legSolver 값을 사용했다. 0.84초 주기, 반 보폭 6px, 발 들기 6px, 디딤 비율 0.6, 다리 60×76px, 회전 진폭 0.025rad를 유지한다. 외형별 파츠 높이는 별도 조정했고, 나비넥타이가 가려지지 않도록 머리의 부모 기준 Y를 -54에서 -98로 변경했다. 다리는 사각 바지통을 덧그리지 않고 둥근 파츠 전체를 발바닥 기준으로 움직인다.

맨몸/웨이터는 몸통과 팔 파츠를 교체한다. 머리와 다리, 꼬리는 공유한다. 귀 안쪽은 맨몸 참고의 갈색으로 통일했다. 입력 이미지에 없던 꼬리와 ¾뷰 가려진 영역은 생성 도구로 보완했다. 정면 원본의 픽셀을 그대로 분리한 것이 아니며 생성 과정의 형태 차이가 있다. 웨이터 복장은 별도 몸통/팔 교체 방식으로, 이전 주인공의 자유 PNG 의상 피팅 UI와는 별개다.

체형 조절은 이 캐릭터만의 localStorage 키를 사용하며 설정 JSON을 내보낼 수 있다. 기존 주인공 설정이나 파일은 변경하지 않는다. 이 캐릭터의 발끝 개별 조절은 제공하지 않고 발·다리 전체 크기를 조절한다.

## 검증

V9 걷기 함수 텍스트와 legSolver 동일성, 기준 파일 3개 해시 불변, 두 복장의 24프레임 렌더, 발 디딤 Y 오차 0, 복장 전환, 대기/좌우 반전/작게 보기/관절/분해, 체형 조절 및 초기화, 390px 화면 가로 넘침과 페이지 오류를 확인했다. 최종 두 복장과 주요 걷기 위상을 눈으로 확인했다.

Unity 연결, 뒷모습, 다른 방향의 독립 파츠, 실제 월드 이동은 아직 포함하지 않는다.

## 재생성

Node에 `sharp`, `playwright` 모듈 경로를 설정하고 저장소 루트에서:

```powershell
node Tools/WaiterRig/build.cjs
node Tools/WaiterRig/verify.cjs
```

조절 패널 코드는 `Tools/StarterOtterRig/tuning.js`를 읽어 이 캐릭터용 저장 키와 초기값 문구로 임베드한다. 결과 HTML에는 이미지/코드가 모두 포함되어 있다.

## 골반 폭 조정
사용자 요청으로 몸통 하단 폭을 72%로 축소했다. 상단 38%는 유지하고 그 아래부터 부드럽게 좁힌다. 렌더러의 slimPelvis와 이미지별 캐시를 사용하며 맨몸/웨이터 모두 적용된다. 원본 파츠 PNG와 걷기 경로는 유지한다. 최종 두 복장 렌더와 걷기 검증을 다시 수행했다.
