## 구조

얼굴, 키, 체형, 팔다리 길이는 고정한다. 머리 / 몸통 / 왼팔 / 오른팔 / 양다리 / 꼬리 7개 표시 파츠이며, 다리는 하나의 원본을 좌우 반전해 공유한다. `parts/`에는 투명 PNG 6개가 있다. `rig.json`에 파츠 영역, 계층, 크기, 피벗, 레이어 및 모자/상의/양소매 연결점이 있다.

픽셀 좌표는 오른쪽이 +X, 아래쪽이 +Y이고 회전은 라디안이다. 각 `pos`는 부모 기준이며 `pivot`은 잘린 그림의 좌상단 기준 정규화 좌표다. Unity로 옮길 때는 Y와 회전 부호, 피벗 Y를 변환해야 한다. 착용물은 머리/몸통/각 팔에 연결한다. 실제 착용물과 털색 마스크는 아직 없다.

이 리그는 파츠를 관절에서 회전시키는 **강체 컷아웃**이다. SpriteSkin용 메시/웨이트나 Unity 프리팹은 아직 만들지 않았다. 이미지 생성 도구로 콘셉트를 리깅용으로 재구성했으므로 원본을 픽셀 그대로 분리한 것은 아니다. 기존 게임 씬, 리그, 캐릭터 코드에는 연결하거나 변경하지 않았다.

## 동작과 검증

대기: 미세한 몸 이동, 머리/팔/꼬리 흔들림. 얼굴 교체 없음.
걷기: 0.85초 주기 정면 제자리 발 교대와 팔 스윙. 실제 이동 속도와 발 접지는 후속 연동에서 조정한다.
손 흔들기: 화면 오른쪽 팔의 어깨 회전과 머리 기울기. 손목/팔꿈치 별도 관절 없음.

Edge Chromium에서 3개 동작의 12개 위상을 캡처하고 변환값, 컨트롤, 390px 화면 가로 넘침, 페이지 오류를 검사했다. 최종 걷기/손 흔들기/분해 화면을 시각 확인했다. 결과는 `verification.json`.

## 재생성

Node.js의 `sharp`, `playwright`가 필요하다. 이 환경에서는 `NODE_PATH`에 bundled dependencies/node/node_modules를 지정한다.

```powershell
node Tools/StarterOtterRig/build.cjs
node Tools/StarterOtterRig/verify.cjs
```

빌드는 이 폴더만 갱신한다. 검증은 설치된 Edge를 headless로 사용한다. `parts-atlas-v1.png`는 팔 흔적이 몸통에 남은 초기안이고, `parts-atlas.png`가 이를 정리한 최종 파츠 원본이다. 생성 방식과 프롬프트는 `PROMPTS.md`.
