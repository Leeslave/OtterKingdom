# 레벨별 메인 퀘스트 · 고랑 해금 (B2 · B3)

- 작성: choiwoohyck (+ Claude), 2026-10-06, `feature/Settlement`
- 근거: `성장곡선_퀘스트_기획서.md` 0·1·3·4·5·7장. **구조는 기획서 그대로**, 내용은 지금 게임 흐름(정착 진행 P0~P3 · 영토 · 낚시터 Lv.15)에 맞춰 다시 짰다.
- 결정 (2026-10-06): 기획서대로 / 고랑 한 칸씩 + 레벨 조건 / ~~일일·도전 퀘스트는 경험치 없음~~ → 같은 날 변경: **어느 퀘스트든 깨면 경험치** (지난 레벨의 도전도)
- 수치는 모두 **임시**. 플레이 실측(분석 로그) 뒤 조정한다.

## 1. 규칙

| 규칙 | 내용 |
|---|---|
| 메인 | 레벨마다 2~5개, **하나씩 순서대로** (모두 한 줄 체인: 앞 단계 보상을 받으면 다음). 목록 맨 위 |
| 경험치 | 한 레벨의 메인 경험치 합 = 그 레벨의 필요 경험치. 스스로 경험치를 주는 정착 단계(공동사업·영토 미션)와 레벨을 바로 올리는 부탁(의자 → Lv.2, 광산 길 → Lv.3)은 **경험치 0**, 나머지 퀘스트가 채움 |
| 도전 | 예전 누적 체인(수확 N개, 판매 N골드 …). 골드 + 예전 경험치(40 ~ 1,100, 지난 레벨의 것도 받으면 줌). 칩 "도전" |
| 일일 | **Lv.9부터**, 골드 + 받는 순간 레벨 필요 경험치의 10%. 칩 "일일" |
| 옛 세이브 | 처음 불러올 때 한 번: 지금 레벨보다 낮은 레벨의 메인은 받은 것으로 넘김 (보상 없이). 저장 표시 `__main_chain` |
| 그 밖의 경험치 | 공동사업·영토 미션(고정), 생활 의뢰(레벨 %)는 그대로 → 선택 콘텐츠를 하면 조금 빨라짐 |

### 새 목표 종류 (`QuestGoalType`)

| 종류 | 세는 것 |
|---|---|
| `Milestone` | 정착 단계: 끝낸 부탁 ID 또는 열린 발전 ID (`_target`). 기록으로 다시 셈 → 퀘스트가 열리기 전에 이룬 것도 들어감 |
| `VisitZone` | 장소 도착 (`_target` = 씬 이름). 이미 그 장소에 있으면 바로 |
| `UnlockFurrow` | 고랑 열기 (`TransactionSource.PlotUnlock`) |
| `ExpandBag` | 가방 칸 늘리기 (`InventoryExpand`) — 지금 표에는 안 씀 |
| `CompleteDaily` | 일일 퀘스트 보상 받기 |
| (기존) `ShopPurchase` | 아이템을 정하면 그 상품만 (예: 감자 모종) |

## 3. 고랑 한 칸씩 (B3)

| 고랑 | 밭 1 (3칸) | 밭 2 첫 칸 | 밭 2 둘째 | 밭 2 셋째 | 밭 3 첫 칸 | 밭 3 둘째 | 밭 3 셋째 |
|---|---|---|---|---|---|---|---|
| 레벨 | 처음부터 | 5 | 6 | 8 | 9 | 11 | 13 |
| 골드 | — | 300 | 600 | 1,000 | 1,600 | 2,500 | 4,000 |

- 표: `FarmBalanceData.furrowUnlocks` (에셋 없이 코드 기본값). 순서대로만 열린다. 잠긴 밭이나 "잠김" 칸을 누르면 다음 고랑 안내 (레벨이 안 되면 "왕국 레벨 N에 …").
- 세이브: `FurrowSlotSaveData.locked`. 예전에 100코인에 연 밭은 세 칸 모두 열린 채로.
- 오프라인 농사 등록 수 = 연 고랑 수.

## 4. 상점 상품 레벨 (`ShopProduct._requiredLevel`)

감자 모종 Lv.4, 고구마 모종 Lv.8, 딸기 모종 Lv.11. 장난감은 처음부터. 레벨 전에는 카드 가격 자리에 "Lv.N", 누르면 요정이 "…을 왕국 레벨 N부터 팔게요!"

## 5. 안 한 것

- 화면 열기·이야기 보기 목표 (Lv.1~2 튜토리얼이 정착 진행으로 바뀌어 필요 없음)
- 낚시터 Lv.10 · 광산 Lv.20 (기획서) → 지금 흐름(광산 Lv.2~3, 낚시터 Lv.15) 유지
- 방문 해달 만나기 목표 (B1 방문 해달이 생기면 추가)
