## 1. 규칙

| 규칙 | 내용 |
|---|---|
| 메인 | 레벨마다 2~5개, **하나씩 순서대로** (모두 한 줄 체인: 앞 단계 보상을 받으면 다음). 목록 맨 위 |
| 경험치 | 한 레벨의 메인 경험치 합 = 그 레벨의 필요 경험치. 스스로 경험치를 주는 정착 단계(공동사업·영토 미션)와 레벨을 바로 올리는 부탁(의자 → Lv.2, 광산 길 → Lv.3)은 **경험치 0**, 나머지 퀘스트가 채움 |
| 도전 | 예전 누적 체인(수확 N개, 판매 N골드 …). 골드 + 예전 경험치(40 ~ 1,100, 지난 레벨의 것도 받으면 줌). 칩 "도전" |
| 일일 | **Lv.9부터**, 골드 + 받는 순간 레벨 필요 경험치의 10%. 칩 "일일" |
| 옛 세이브 | 처음 불러올 때 한 번: 지금 레벨보다 낮은 레벨의 메인은 받은 것으로 넘김 (보상 없이). 저장 표시 `__main_chain` |
| 그 밖의 경험치 | 공동사업·영토 미션(고정), 생활 의뢰(레벨 %)는 그대로 → 선택 콘텐츠를 하면 조금 빨라짐 |

### 새 목표 종류 (`QuestGoalType`)

| 종류 | 세는 것 |
|---|---|
| `Milestone` | 정착 단계: 끝낸 부탁 ID 또는 열린 발전 ID (`_target`). 기록으로 다시 셈 → 퀘스트가 열리기 전에 이룬 것도 들어감 |
| `VisitZone` | 장소 도착 (`_target` = 씬 이름). 이미 그 장소에 있으면 바로 |
| `UnlockFurrow` | 고랑 열기: 밭 1을 뺀 **열린 고랑 수 ≥ 순번**(`_target` 1~6, Lv.11·11·12·12·13·13)이면 완료. 기록으로 다시 셈 → 퀘스트보다 고랑을 먼저 열어도 막히지 않음 (8차 QA, 2026-10-12. 예전엔 퀘스트가 열린 동안 낸 `PlotUnlock`만 셌음) |
| `ExpandBag` | 가방 칸 늘리기 (`InventoryExpand`) — 지금 표에는 안 씀 |
| `CompleteDaily` | 일일 퀘스트 보상 받기. 오늘 받은 일일 수로 다시 셈 → 이 퀘스트가 열리기 전에 오늘 일일을 받았어도 들어감 (QA_Lv1-10, Lv.9엔 일일이 "오늘의 장사" 하나뿐이라 먼저 받으면 다음 날까지 막혔음) |
| (기존) `ShopPurchase` | 아이템을 정하면 그 상품만 (예: 감자 모종) |
| (기존) `Upgrade` | 생산 업그레이드 횟수 (열린 동안). `_target` = `pickaxe`면 곡괭이 레벨 - 1로 다시 셈 — Lv.5 "더 좋은 도구" (곡괭이 강화는 4번이 끝이라 미리 다 올리면 밭 전엔 셀 수 없었음, QA_Lv1-10) |

- 경험치 표 (`ProgressionSetup.Levels`): Lv.19까지 그대로, Lv.20부터 늘어나는 폭이 레벨마다 100씩 커짐 — Lv.20 10,400 → Lv.49 94,500. 레벨업 조개는 5레벨마다 80, 나머지 30. 이미 있는 레벨 표 에셋은 고친 값을 지키고 늘어난 레벨만 뒤에 붙임.
- Lv.18~22는 이미 있던 뒷이야기(갱도 3~5층, 가스 사건, 마을 길드, 성, 황금 흙, 길드 지부)를 메인으로 안내. 새 기록: 갱도 층 정복 `maze_floor_<층>_cleared` · 곡괭이 `maze_pickaxe_<단계>` (갱도에 들어갈 때 다시 셈), 흙 `farm_soil_<단계>` (농장이 다시 셈).
- 예전 Lv.18~19 누적 메인(작물 2,500 · 4,000, 업그레이드 3, 물고기 250, 판매 20만 · 30만, 가구 8, 광석 1,000)은 도전으로. 업그레이드는 다 올리면 막힐 수 있어 Lv.18부터 메인에 쓰지 않음.
- Lv.23~49는 **새 콘텐츠가 붙기 전의 임시 반복 메인** (`QuestSetup.WithLateMains`). 새 시설 · 지역 · 이야기가 생기면 그 레벨 줄을 표로 옮겨 바꾼다.
- 표 판 5 — 옛 세이브는 지나온 레벨의 새 메인을 보상 없이 넘김. 예전 최고 레벨(Lv.20)에 있던 세이브는 Lv.20 메인부터 이어서 함. 테스트 `MainQuestChainTests.Level16To49_EveryLevelHasMainChain`.
- 첫 단계가 메인으로 옮겨 간 예전 퀘스트 5개는 ID를 그대로 써서 진행 기록이 이어진다: `main_gather_1`, `main_sales_1`, `main_rock_1`, `main_mine_1`, `quest_first_carrots`.

## 4. 상점 상품 레벨 (`ShopProduct._requiredLevel`)

씨앗은 모두 밭(Lv.10) 뒤: 무 · 비트 Lv.10, 감자 · 토란 Lv.11, 고구마 · 애호박 · 자색 감자 Lv.12, 딸기 · 라즈베리 Lv.13 (그 뒤 흰 딸기 14 · 블루베리 15 · 황금 당근 17 · 황금 감자 19). 장난감은 처음부터. 레벨 전에는 카드 가격 자리에 "Lv.N", 누르면 요정이 "…을 왕국 레벨 N부터 팔게요!"
