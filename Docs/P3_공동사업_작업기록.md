# P3 — 마을 공동사업 · 생활 의뢰 · 농사 편의 · 요정 등장 순서 작업기록

기준: `해달왕국_P3_기획서.md` v1.1 (2026-10-04) / 기준 커밋 `491d219` (develop, P2 머지) / 브랜치 `feature/P3`

> **회관을 지은 뒤(Lv.7~), 생산물을 공동사업에 나눠 넣으며 광장이 넓어지고 이웃이 늘고, Lv.10에 첫 마을 모임을 연다.** 농사는 어느 지역에 있든 농부가 수확하고, 모종이 없으면 그 칸만 기다리며 한 번 알린다. 요정은 농부를 밭에 파견한 뒤 찾아온다.

## 3. 구조

### P3-F 농사 (`FarmService`)

| 항목 | 내용 |
| --- | --- |
| 수확 주체 | `FarmService.Tick`이 농부의 일까지 계산 (모든 장소의 GameManager가 부름). 다 자란 칸을 정해진 순서(밭 → 칸)로 한 칸씩, `FarmBalanceData.farmerHarvestSec`(10초) 뒤 가방에 넣고 같은 작물을 다시 심음 |
| 밭 씬의 해달 | `FarmerOtterController`는 `TryGetHarvestTarget`의 칸으로 걸어가 수확 애니메이션만 보여 줌. 애니메이션 끝은 수확과 무관 |
| 시간 | 온라인(어느 장소든) `Tick` = 성장 + 농부. 장면 전환 사이 시간도 `Tick`. **앱을 꺼 둔 시간·백그라운드는 `Grow`(성장만)** — 오프라인 생산 규칙(등록 작물·느린 속도·모종)은 기존 `OfflineProductionService` 그대로 |
| 장면 전환 | 수확 중인 칸·남은 시간을 `SaveData.farmerWork`에 저장 → 다른 장소의 GameManager가 이어서 함 (같은 작물을 두 번 수확하지 않음) |
| 수확과 수령 | 이 게임은 수확물 저장소 = 가방. 수확 = 가방에 들어감(퀘스트 "수확" 집계도 이때 한 번). 판매는 기존대로 플레이어가 |
| 가방 가득 | 들어갈 자리가 없는 칸은 건너뜀 (버리거나 넘치게 쌓지 않음). 알림: "가방이 가득해서 밭 수확이 멈췄어요" |
| 모종 부족 | 다시 심을 모종이 없으면 칸을 비우고 `FurrowSlotSaveData.waitingSeedCropId`에 작물을 남김 → 배지 "모종 없음". 매 틱 앞에서 모종이 생긴 칸부터 차례로 심음(마지막 모종을 두 칸이 쓰지 않음). 직접 심어도 대기 해제 |
| 모종 종류 | 실제 데이터 확인: 당근·오이 = 영구형(늘 심음), 감자·고구마 = 소모형(가방의 모종 수). 부족 판정은 소모형만 |
| 알림 | `FarmService.NoticeRaised` → `GameNotices`(막지 않는 띠, 어느 장소든, 레벨업·튜토리얼·완료 팝업·화면 전환이 끝난 뒤). 정상 → 문제로 바뀔 때만, 여러 칸은 "밭 N곳 (작물들)"로 묶음. `SaveData.farmNotice`에 알린 상태를 남겨 재접속·장면 이동에 다시 띄우지 않음. 필드가 없던 세이브는 지금 상태로 맞추고 알리지 않음 |
| [상점으로] | 요정이 도착했으면 알림 띠에서 바로 상점(어디서든 열림). 오기 전이면 "모종을 판매하는 요정이 찾아오고 있어요" |
| 직접 심기 실패 | "{작물} 모종이 없어요. 요정 상점에서 구매해 주세요." (같은 문장 팝업은 겹치지 않음 — 기존 GameUI 규칙) |

### 조율 (`SettlementManager.P3`)

- 납품: `TryDeliver(재료 하나)` / `TryDeliverAll` — 확인 → 골드·아이템 결제 → 납품량 증가 → 다 냈으면 `_paid` 발전 → 저장 한 번. 결제처는 `IProjectWallet`(기본 = 재화·가방 매니저, 테스트 = 가짜)
- 단계: `TryAdvanceProject` — 건설 시작(대기열이 차 있으면 `Busy`, 납품 보존) / 주민 고르기 화면 / 모임 열기. 소품은 `TryChooseWelcomeProp`(한 번만 고름) · 장애물은 `TryClearProjectObstacle`
- 완료: 기록이 바뀌면 다음 프레임 `UpdateProjects` → 집 기록 맞추기 → 모든 단계 끝 → 결과 발전 · 방명록 · 보상 기록 + 경험치(같은 프레임) → 알림 띠. 불러올 때는 알림 없이 맞추고, 기록은 끝났는데 보상 기록이 없으면 그때 한 번 줌
- 입주: 이웃집이 완성되면 자리에 집 인스턴스 → 포근이가 방문(Visitor)으로 찾아옴 → 광장 대기 줄로 등장 = 만남 → 말을 걸면 [입주] 확인 → 집의 입주민 + 주민(Resident) → 노동력 +1
- 모임: `TryHoldGathering` = 모임 기록(=완료·보상) → `GatheringDirector`가 안전한 때 연출. 다 보거나 건너뛰면 `gathering_viewed`. 기념 기록(게시판 카드·공동사업 화면)에서 다시 보기
- 생활 의뢰: `EnsureLifeRequests`(빈 칸 채우기) · `TryCompleteLifeDelivery` · `TryStartLifeWork`(같은 노동력 판정, 광장 현장에서 일함) · `TrySwapLifeRequest`(손대기 전만, 보상 없음). 회차 작업의 완료 기록은 지워 쌓이지 않음

## 6. 아트 · 미실행 · 보류

- **임시 아트** (`Tools/UIGen/p3_art.py`): 비축 상자, 공동 식탁(피크닉 천·바구니를 나무 식탁에 얹음), 화분, 빨랫줄 — 도형으로 그린 스티커 느낌. 동쪽 바닥은 기존 바닥 오른쪽 절반을 좌우 반전(이음매 자연스러움, 아래쪽 바다가 거울처럼 이어짐). 이웃집은 파란 집 반전, 새 이웃은 일반 해달(농부와 같은 모습 — 농부는 밭에 가 있어 광장에서 겹치지 않음), 얼굴은 농부 초상 재사용. 회관 앞 장식은 화분 두 개
- 모임 연출: 주민 광장 프리팹의 첫 그림을 복사해 앉히고 살짝 들썩이는 정도 (식사 애니메이션 없음 — 기획서 최소안)
- 기념 화면: 고정 문구 카드(함께한 해달 이름). 별도 도감 편입 없음
- 회관 화면에 공동사업 카드를 따로 넣지 않고 기존 "다음 목표" 칸을 썼다 (회관 팝업은 프리팹이 고정 배치라 런타임 삽입을 피함). 전체 카드는 공동사업 화면
- 실행하지 않음: 새 게임부터 P0~P3 끝까지 한 번에, 실기기 터치, 오프라인 장시간 복귀 중 확장 정비 완료 화면
- 밸런스: 실측 시간 없음. 농부 수확 처리량이 "걷기 + 애니메이션"에서 "칸당 10초 고정"으로 바뀌어 고랑이 많을 때 조금 빨라질 수 있음 (성장곡선 8.1 표 기준 9칸·30초 작물: 분당 5.93 → 6.0회)
