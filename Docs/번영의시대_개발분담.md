## 1. 나누는 원칙

- **A = 월드 · 생산 쪽** (산업 · 물류 · 도시 외형): 재료가 만들어지고, 쌓이고, 옮겨지고, 마을이 달라 보이는 것.
- **B = 메타 · 진행 쪽** (연구 · 퀘스트 · 경제 · 이야기 · 저장): 무엇을 언제 열지, 무엇을 요구하고 주는지, 세이브.
- 서로의 파일을 고치지 않도록 **폴더 · 파일 주인을 정함** (5장). 둘 사이는 **3장의 약속(API · ID · 기록 이름)**으로만 연결.
- 첫 주에 3장의 약속을 **빈 껍데기(stub)로 먼저 머지** → 그 뒤엔 각자 진행해도 막히지 않음.

## 6. A 구현 결정 (2026-11-03, 1차)

지금 게임은 시설이 모은 목재 · 돌이 **저절로 가방에 들어감** (`SettlementManager.RunProduction`). 그래서 기획서의 "수거 자동화"를 이렇게 맞춤:

| 기능 | 동작 |
|---|---|
| 가공 (I01 판재 · I02 석재 블록) | 시설 창에서 켬 → 그 시설이 모은 원재료가 **가방 대신 가공에 먼저** 들어감 (남는 것만 가방). 가방의 원재료를 직접 넣을 수도 있음. 처음 켜면 1개 바로 줌. 6분에 1개, 재료 10번 몫까지 넣어 둠 |
| 시설 보관함 | 만든 가공품은 시설에 쌓임 (8시간치 상한, 차면 멈춤 — 재료는 안 빠짐) |
| 수령 | 시설 창 [창고로] → 왕국 창고 (창고가 차면 남은 건 시설에) |
| 왕국 창고 | 판재 · 석재 블록은 가방이 아니라 창고에만. L01 전에는 60칸 임시 보관, **L01 공동 창고 → 200칸** |
| 수레 (L02 1곳 · L03 3곳) | 고른 시설의 가공품을 **저절로 창고로** (2초마다 장부로, 화면의 수레는 연출) |
| 오프라인 | 기존 8시간 정산 그대로: 원재료 → 가공 → 수레 → 창고 순서. 돌아옴 팝업에 "판재 N개" |
| 퀘스트 기록 | 처음 만들면 `first_plank` · `first_stone_block` |

- 데이터: `Tools/Industry/Create Data` (`Assets/Editor/Industry/IndustrySetup.cs`) → 아이템 · 레시피(`Scriptable Obejects/Industry/`) · `Resources/IndustryConfig`. 임시 아이콘 `python Tools/UIGen/industry_icons.py`
- 연구 시스템 전 시험: 플레이 중 `Tools/Industry/Dev — Learn P0 Techs` (I01 I02 L01 L02 C01 C02를 배운 것으로, 저장 안 함)
- 테스트: `IndustryTests` (창고 칸 · 예약 · 가공 시간/재료/보관함 · 수레 · 세이브)
- 화면 (2차): 마을 회관 → [일터와 설비] 창을 탭 창으로 다시 만듦 (`RuntimeUIWindow` + `RuntimeUICards`, 뽑기 · 가방 화면과 같은 리본 · 모서리 X · 탭 · 줄 카드). 탭 [생산 · 가공 · 창고 · 설비], 가공 · 창고 탭은 가공을 배웠거나 창고에 무언가 있을 때만. 가공 카드 = 스위치로 켜고 끔 · 재료 줄 [+] · 완성 줄 [받기] · 수레 스위치(L02부터). 창고 탭 = 칸 막대 + 가방 모양 칸 격자. `OpenWarehouse()`는 창고 탭으로 엶.
- 광장 (3차, `IndustryPlazaView` — SettlementPlazaView가 붙임):
  - 가공을 배운 시설 앞 작업대 (목공소 = 제재 작업대, 채석 작업소 = 돌 재단대). 시설에 쌓인 가공품 더미(적음 · 보통 · 많음) — **누르면 창고로** ("+3 판재").
  - 왕국 창고 자리 = 상자 더미 + 표지 (농업 창고 앞, 없으면 게시판 옆).
  - 수레(L02): 그 시설에서 일하는 해달 하나가 수레를 밀고 시설 ↔ 창고 자리를 오감 (가는 길엔 실은 수레, 오는 길엔 빈 수레). **연출일 뿐** 장부는 2초마다 따로 → 길이 막히면 25초 뒤 그 자리로 옮김. 수레꾼은 `IndustryPlazaView.IsCarter`로 SettlementPlazaView가 일터 일을 안 줌.
  - 건물 누르기: 목공소 · 채석 작업소 → 일터 창 가공 탭. 작은 집(C02 뒤) → 주택 개량 창.

### 6.2 B가 붙일 때 (L07 · L08 · 연구)

- **연구**: B의 연구 시스템이 `TechGate.Provider = id => 배웠나`를 넣고, 배울 때 `TechGate.NotifyLearned(id)`를 부르면 A의 모든 기능이 그대로 열림 (지금은 개발 메뉴의 `DevLearn`).
- **계약 자동 배달 (L07)**: B의 계약(E03 · E05)에 "자동 납품" 칸을 두고, 매 정산마다 `SettlementManager.Instance.Warehouse.Available(item)`을 보고 `TryConsume`으로 납품. 재료 순서(기획서 7.2: 공사 예약 → 공동사업 예약 → 가공 원료 → 거래)는 `Warehouse.Reserve` / `ConsumeReserved`로 지킴.
- **통합 유통망 (L08)**: 큰 공동사업이 시작될 때 필요한 창고 자재를 `Warehouse.Reserve`로 먼저 잡아 두고, 다 모이면 `ConsumeReserved` — 예약한 몫은 가공 · 만들기 · 왕국 공사가 못 씀 (`Available`만 봄).
- **퀘스트**: 6.1의 목표 · 발전 ID + 왕국 공사 기록 (`town_*`).
