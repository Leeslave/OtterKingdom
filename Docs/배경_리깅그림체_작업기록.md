# 배경을 리깅 해달 그림체에 맞추기 — 작업 기록

작성일: 2026-10-13 (feature/OmissionFunction)

## 목표

리깅 해달(ArtSource/Otter/QuarterRig)은 진한 갈색 외곽선, 2단으로 나뉜 납작한 명암, 차분하고 따뜻한 색(작업복 세이지 #687848, 털 #d88868, 크림 #f8e8c8)으로 그려져 있다.
반면 광장 지도는 AI로 키운 수채화 느낌이라 붓 자국이 많고, 형광 연두와 시안색 물에 외곽선도 없어서 해달과 그림체가 따로 놀았다.

## 방식: 다시 그리지 않고 다시 칠하기

이전에 AI로 다시 그린 지도(AlignedOtterMap, Pastel, ThinLine 등)는 원래 지도와 위치가 어긋나 되돌렸다(42ef0c1).
이번에는 **원본 지도를 영역별로 나눈 뒤 다시 칠하는 방식**이라 해안선, 길, 걷기 영역, 영토 좌표가 원본과 픽셀 단위로 같다. 그래서 씬이나 레이아웃 데이터는 고치지 않았다.

- `Tools/MapStyle/stylize_map.py` — 지도
  - 풀, 흙길, 물, 돌, 바다 바위섬, 꽃을 색으로 나눈 뒤 붓 자국을 지우고 납작한 색으로 칠한다.
  - 명암: 풀은 그늘 덩어리를 옅게 넣고, 흙길에는 풀밭 아래로 얇은 그림자를 깐다. 물은 해안에서 멀수록 진하게 칠하고, 원본의 밝은 물결은 연한 물결 무늬로 살린다.
  - 선: 풀밭 가장자리는 올리브 갈색 1.6px, 돌은 진한 갈색, 물가는 청록 선과 크림색 거품 띠로 그린다. 선은 해달 외곽선보다 얇고 옅게 둬서 캐릭터가 먼저 눈에 띄게 했다.
  - 광장 동남쪽 공터의 조개 표식은 돌과 밝기가 비슷해 좌표(`SHELL_MARKS`)로 지정했다. 무늬 선을 살려 크림색으로 칠한다.
- `Tools/MapStyle/grade_props.py` — 숲 나무, 덤불, 그루터기(Territory/Forest_*)와 광장 소품(Props/Prop_*)
  - 모양과 선은 그대로 두고 색만 바꾼다. 형광 연두를 세이지 초록(92°) 쪽으로 당기고 채도를 낮춘 뒤, 검은 선은 진한 갈색으로 바꾼다.

## 적용된 파일

- `Assets/Art/Plaza/Plaza_WorldMap.jpg` — 같은 이름이라 GUID가 같다. Unity가 다시 가져오기만 하면 된다.
- `Assets/Art/Plaza/Territory/Forest_*.png` (6장), `Assets/Art/Plaza/Props/Prop_*.png` (12장)
- 원본 보관: `ArtSource/Plaza/BeforeRigStyle/` — 두 스크립트 모두 매번 여기서 새로 만들기 때문에 여러 번 돌려도 효과가 겹치지 않는다.
- 비교 이미지: `Docs/Images/배경_리깅그림체_비교.png`, `Docs/Images/배경_리깅그림체_전체지도.png`

## 다시 만들기 / 되돌리기

```
python Tools/MapStyle/stylize_map.py
python Tools/MapStyle/grade_props.py
```

- 색과 선 굵기는 각 스크립트 위쪽의 `PAL`, `GREEN_*` 값으로 조정한다.
- `Tools/MapExpansion/build_territory_art.py`로 지도나 숲을 다시 만들면 결과가 덮어써진다. 그 경우 새 결과를 `ArtSource/Plaza/BeforeRigStyle/`에 복사한 뒤 위 두 줄을 다시 돌린다.
- 되돌리기: `git checkout -- Assets/Art/Plaza/Plaza_WorldMap.jpg Assets/Art/Plaza/Territory Assets/Art/Plaza/Props`

## 남은 일

- Unity에서 직접 확인하지 않았다. 확인할 것: 기본 줌(9)과 최대 확대(6)에서 선이 너무 흐리거나 굵지 않은지, WebGL(텍스처 2048 제한)에서 어떻게 보이는지.
- 지도의 기본 배율이 2.7배 확대라 선이 조금 부드럽게 번진다. 더 또렷하게 하려면 이 방식으로 8144px 지도를 만들어 조각으로 깔아야 한다(이전에 했던 HD 조각 방식).
