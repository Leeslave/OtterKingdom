# 가챠 개편 — 특수 해달 조각 · 장신구 · 재료, 장난감 삭제

- 작성일: 2026-10-22
- 상태: 기획 확정분 + 수치 가안. 아직 게임에 적용하지 않음 (아래 9장 단계대로 진행).
- 레퍼런스: 쿠키런 킹덤의 소울스톤 — 뽑으면 캐릭터 조각이 나오고, 일정 개수를 모으면 해금, 더 모으면 별 승급.
- 대체 문서: `장난감삭제_해달가챠_응원동료_기획안.md`의 3장(편성) · 4장(건물과의 관계) · 6장(장난감 해달 출현 조건)은 이어서 쓰고, 5장(중복은 공용 조각) · 가챠 결과가 해달 그 자체라는 부분은 이 문서로 바꾼다.

## 1. 사용자 결정 (2026-10-22)

| 질문 | 결정 |
|---|---|
| 조각으로 해금하는 특수 해달 | **가챠 전용 새 직업 해달** (음유시인 · 정원사 등). 쿵쿵이 · 데굴이 같은 기존 주민은 지금처럼 이야기로 등장 |
| 해금한 특수 해달의 역할 | **명부에서 최대 3마리 편성 → 고유 버프**. 집 · 부지 · 광장 리깅 필요 없음 |
| 해금 뒤 같은 해달 조각 | **별 승급 (쿠키런식)**: 1성 → 5성, 별이 오르면 버프가 커짐 |
| 장신구 장착 대상 | **모든 주민 해달** (농부 · 광부 · 낚시꾼 · 건설 · 나무 · 채굴 해달 등) |
| 장신구 칸 | **해달 한 마리당 1칸** |
| 같은 장신구 중복 | **강화 재료**: 같은 장신구를 겹쳐 강화하면 효과가 커짐 |
| 기존 장난감 | **보상 없이 삭제** (가방 · 광장에 놓인 것 모두) |
| 배너 | **상시 + 픽업**. 상시에는 하루 1회 골드 뽑기 포함. 골드 전용 배너는 정리 |

## 2. 뽑기 결과 구성

한 번 뽑으면 아래 셋 중 하나가 나온다. 등급 · 천장 · 10회 연출 구조는 지금 가챠를 그대로 쓰고, 나오는 물건만 바꾼다.

| 결과 | 가안 확률 | 내용 |
|---|---|---|
| 재료 꾸러미 (흔함) | 55% | 목재 · 돌 묶음. 작은 꾸러미(목재 20 · 돌 15) / 큰 꾸러미(목재 50 · 돌 40) |
| 장신구 | 30% | 일반 22% · 레어 7% · 에픽 1% |
| 특수 해달 조각 | 15% | 레어 해달 조각 12% (1~3개) · 에픽 해달 조각 3% (1~2개) |

- 천장: 10회째는 **레어 이상(레어 장신구 또는 해달 조각) 확정**, 상시 80회 · 픽업 60회째는 **에픽 해달 조각 5개 확정**. 지금 천장 기록(`GachaSaveData`)을 그대로 이어 씀.
- 픽업 배너: 해달 조각이 나오면 절반은 그 배너의 픽업 해달 조각. 픽업을 놓친 다음 에픽 조각은 픽업 확정 (지금 규칙과 같음).
- 재료 꾸러미 수량은 첫 버전엔 고정. 레벨이 오르면 시설 비용이 커지므로, 플레이 측정 뒤 왕국 레벨 비례로 바꿀지 정한다.
- 결과 카드: `음유시인 조각 ×2 (12/20)` · `깃털 모자 (새 장신구!)` · `목재 50 · 돌 40`. 조각은 해금까지 남은 수를 같이 보여 준다.

## 3. 특수 해달 (가챠 전용 새 직업)

### 3.1 해금 · 별 승급 (가안)

| 단계 | 레어 해달 | 에픽 해달 |
|---|---|---|
| 해금 (1성) | 조각 20 | 조각 30 |
| 2성 | +20 | +30 |
| 3성 | +30 | +50 |
| 4성 | +50 | +80 |
| 5성 | +80 | +120 |
| 합계 | 200 | 310 |

- 해금은 자동이 아니라 명부에서 **[해금하기]**를 눌러 진행 (해금 순간 연출). 별 승급도 명부에서 버튼으로.
- 5성 뒤에 나오는 조각은 **반짝 조각**(지금 재화 `Shard`)으로 바뀐다. 반짝 조각은 교환소에서 원하는 해달 조각을 고르는 데 쓴다 (레어 조각 1개 = 반짝 3, 에픽 조각 1개 = 반짝 5, 가안).
- 아직 해금 안 한 해달의 조각도 그대로 쌓인다.

### 3.2 첫 명단 (6종 가안)

기존 응원 동료 기획안 3장의 직업을 쓰되, 실제로 효과가 동작하는 6종부터 시작한다.

| 해달 (가안) | 등급 | 버프 (1성 → 5성) | 걸리는 곳 |
|---|---|---|---|
| 음유시인 | 레어 | 주민 이동속도 +4 → +12% | 광장 산책 · 농부 운반 · 건설 현장 이동 |
| 정원사 | 레어 | 작물 성장 시간 −4 → −12% | 새로 심는 작물 (`KingdomBonusKind.GrowSpeed`) |
| 산림관리사 | 레어 | 목재 획득 +5 → +15% | 목공소 생산 · 개간 목재 |
| 지질학자 | 레어 | 돌 획득 +5 → +15% | 채석 작업소 생산 · 광장 바위 · 광산 돌 (`StoneYield`) |
| 회계사 | 에픽 | 판매가 +3 → +10% | 판매 (`SellPrice`) |
| 건축가 | 에픽 | 공사 시간 −4 → −12% | 새 공사 (`BuildSpeed`) |

- 별마다 효과: 1성 기본, 5성은 기본의 약 3배. 중간 별은 고르게 나눔.
- 첫 버전 외형: 초상화 · 이름 · 한 줄 소개만. 광장 리깅 · 전용 동작은 후속.

### 3.3 편성

- 응원 칸 3칸. 처음 1칸, 첫 개간 뒤 2칸, 농업 시작(Lv.10) 뒤 3칸 (기존 기획안 그대로).
- 같은 계열(같은 버프 종류)은 한 마리만. 편성 교체는 무료, 이미 시작한 공사 · 작업 시간은 다시 계산하지 않음.
- 버프는 `KingdomBonus`로 합산 (건물 · 구역 · 편성 함께). 계열별 상한은 수급표로 정함.

## 4. 장신구

- 모든 **주민 해달**에게 1칸. 방문객 · 입주 대기 해달 · 특수 해달(편성용)은 제외.
- 효과는 **그 해달 한 마리에게만** 걸림. 화면에 보이지 않음 (해달 정보 창에 아이콘 · 효과 문구만).
- 장신구는 하나에 효과 하나. 같은 장신구를 여러 해달이 동시에 낄 수는 없음 (한 개 = 한 해달). 다른 해달에게 옮겨 끼우기는 무료.

### 4.1 첫 장신구 (가안)

| 장신구 | 효과 (일반 / 레어 / 에픽, 강화 0) | 쓸모 있는 해달 |
|---|---|---|
| 깃털 모자 | 이동속도 +8 / +12 / +18% | 농부(운반) · 건설 해달 · 광장을 걷는 모든 주민 |
| 반짝 장갑 | 작업 시간 −6 / −9 / −14% | 주민 작업(개간 · 쓸기)을 맡는 해달 |
| 행운 목걸이 | 얻는 양 +6 / +9 / +14% | 농부(수확) · 광부(채굴) · 낚시꾼(물고기) · 목공소 · 채석 작업소 해달(그 해달 몫 생산) |

- 같은 이름이라도 등급별로 다른 장신구 (예: 레어 깃털 모자).
- 강화: 같은 장신구(같은 등급) 1개를 넣으면 +1, 최대 +4. 강화 1번마다 효과가 기본값의 25%씩 늘어 +4면 2배.
- 최대 강화 뒤 같은 장신구가 나오면 반짝 조각으로 (일반 1 · 레어 5 · 에픽 30, 지금 중복 규칙과 같음).

## 5. 재료

- 목재 · 돌을 가방에 바로 넣음 (`ItemChangeReason`에 뽑기 이유 추가). 가방이 가득하면 넣지 못한 몫은 반짝 조각으로 (지금 규칙과 같음).
- 첫 버전은 목재 · 돌만. 요정 약초 · 씨앗 등은 넣지 않음 (필수 공사 재료를 뽑기에 묶지 않게, 기본 공급은 목공소 · 채석 작업소).

## 6. 장난감 삭제

- 장난감 아이템 · 꾸미기 카탈로그의 장난감 · 장난감 뽑기 표를 지움. **기존 세이브의 장난감은 보상 없이 사라짐** (가방 · 광장 배치 모두). 가구는 그대로 둠.
- 장난감 방문(`ToyVisitRules`): 장난감을 보고 오던 해달은 생활 진행 조건으로 확정 등장 (응원 동료 기획안 6장). 장난감으로만 오던 **영차 · 재잘이 · 꼼꼼이 · 두리번 · 살랑이**의 새 등장 조건은 그 표를 따름. 기록관 · 주거 구역의 "방문 간격 −%"는 다른 효과로 바꿔야 함 (6.1).
- 퀘스트: "장난감 N개 놓기"(메인 Lv.4 광장 놀이터, 도전 광장 꾸미기 체인 등)는 **가구 놓기**로 바꿈. 일일 · 도전도 같음.
- 도감: 장난감 칸을 지우고, 대신 장신구 · 특수 해달 칸을 둠 (6.1).

### 6.1 이 단계에서 정할 것

- 기록관 효과 대체안: 생활 의뢰 보상 +10% (응원 동료 기획안 6장 제안).
- 도감 장신구 탭을 둘지, 특수 해달만 둘지.

## 7. 저장

- `GachaSaveData`에 이어 붙임: 해달별 조각 수 · 해금 · 별, 편성 3칸, 장신구 목록(종류 · 등급 · 강화 · 낀 해달).
- 옛 세이브: 장난감 기록 삭제, 천장 기록 · 반짝 조각 · 뽑기권은 유지.

## 9. 진행 단계

| 단계 | 내용 | 끝나면 |
|---|---|---|
| 1 | 규칙 · 데이터 (순수 C#) — 조각 · 해금 · 별 승급 · 편성 · 장신구 · 강화 · 새 뽑기 표 · 저장 + EditMode 테스트 | 테스트로 뽑기 → 조각 → 해금 → 별, 장신구 → 강화가 확인됨 |
| 2 | 가챠 화면 연결 — 결과 카드(조각 · 장신구 · 재료), 확률 공개표, 교환소(반짝 조각 → 해달 조각) | 게임에서 새 결과가 나옴 |
| 3 | 명부 · 편성 · 장신구 장착 화면, 버프 적용(`KingdomBonus` · 해달별 효과) | 편성 · 장신구 효과가 실제로 걸림 |
| 4 | 장난감 삭제 — 아이템 · 카탈로그 · 방문 · 퀘스트 · 도감 정리, 장난감으로만 오던 해달 확정 등장 | 장난감 없이 끝까지 진행됨 |
| 5 | 밸런스 · 초상화 그림 · 문구 | 수치 확정 |

1 → 2 → 3은 순서대로, 4는 2가 끝난 뒤 따로 진행할 수 있음 (가챠에서 장난감이 빠진 뒤).

## 10. 1단계 작업 기록 (2026-10-22)

지금 뽑기(장난감)는 그대로 돌아가고, 새 규칙 · 데이터 · 저장만 옆에 붙였다. 화면 연결은 2단계.

| 무엇 | 파일 |
|---|---|
| 특수 해달 데이터 (등급 · 버프 · 1~5성 %) | `Assets/Scripts/Gacha/Data/SpecialOtterDefinition.cs` |
| 장신구 데이터 (등급 · 효과 · 강화 %) | `Assets/Scripts/Gacha/Data/AccessoryDefinition.cs` |
| 보상 설정 (확률 · 재료 꾸러미 · 조각 수 · 목록 → 배너별 표) | `Assets/Scripts/Gacha/Data/GachaRewardConfig.cs`, 에셋 `Assets/Scriptable Obejects/Gacha/GachaRewardConfig.asset` |
| 보상 표 · 뽑기 (칸 고르기 · 빈 칸 몫 · 천장 · 픽업 · 확률 공개값) | `Assets/Scripts/Gacha/Model/GachaRewardTable.cs`, `GachaRewardRules.cs` |
| 명부 · 별 · 편성 · 장신구 (순수 C#) | `Assets/Scripts/Gacha/Model/CompanionCollection.cs` |
| 저장 | `GachaSaveData.specialOtters · formation · accessories` (`GachaTypes.cs`), `GachaManager.Companions`가 함께 읽고 씀 |
| 버프 종류 추가 | `KingdomBonusKind.MoveSpeed`(9) · `WoodYield`(10) — 효과 적용은 3단계 |
| 데이터 만들기 | `Tools/Gacha/Create Companion Data` (`Assets/Editor/Gacha/GachaRewardSetup.cs`): 특수 해달 6 · 장신구 9(3종 × 3등급) · 보상 설정 |
| 테스트 | `Assets/Tests/EditMode/GachaRewardTests.cs` |

1단계에서 정한 세부 규칙 (기획 가안에 없던 것):

- 에픽 천장(80 · 60)은 **에픽 해달 조각을 얻을 때만** 다시 셈. 에픽 장신구로는 줄지 않음. 에픽 해달이 표에 없으면 천장을 걸지 않음.
- 나올 것이 없는 칸의 몫: 같은 등급의 다른 종류 → 아래 등급 → 위 등급 순으로 옮김 (확률 공개값도 옮긴 뒤 값).
- 조각은 5성까지 쓸 만큼만 쌓고, 넘는 몫은 바로 반짝 조각으로 (레어 1 · 에픽 2개씩). 교환소에서 조각 하나 = 반짝 조각 레어 3 · 에픽 5.
- 장신구는 종류(등급 포함)마다 하나만 가짐. 같은 것이 또 나오면 **자동으로 강화 +1** (뽑기 결과 카드에 "강화!"), +4 뒤에는 반짝 조각.
- 편성은 칸을 바꿔 넣거나 옮길 수 있음. 열린 칸 수(1~3)는 부르는 쪽이 넘김 (칸 해금 조건은 3단계에서 연결).
- 데이터에서 잠깐 빠진 해달 · 장신구의 저장 기록은 지우지 않음. 한 해달에 장신구 둘이 저장돼 있으면 앞의 것만 남김.
- 아직 `GachaManager`에 보상 설정 에셋을 연결하지 않음 (2단계에서 GlobalUI 프리팹과 함께). 연결 전에도 명부 저장은 그대로 지켜짐.
