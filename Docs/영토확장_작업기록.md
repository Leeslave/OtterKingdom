# 영토 확장 (서쪽·북쪽 숲 개간) — 작업기록

작성일: 2026-10-04 / 브랜치 `feature/MapExpansion` (기준 `5470488`)
문서 성격: 대화로 진행한 작업 로그. 다음 작업 재개 시 참고용.

> **광장은 큰 지도의 남동쪽 끝에서 시작한다.** Lv.6부터 레벨이 오를 때마다 숲 개간 기회가 1번씩 쌓이고, 광장 가장자리의 점선 원을 눌러 주민 해달을 보내 숲을 개간한다 (목재를 많이 얻음). 한 방향에서 3번 개간을 끝내면 마을회관에 영토 확장 미션이 생기고, 재료를 다 넣으면 그 땅이 열려 걸어 다닐 수 있고 카메라도 더 멀리 간다.

---

## 0. 바로 적용

데이터·씬·그림은 저장소에 모두 들어 있다. 다시 만들 때만:

| 할 일 | 방법 |
| --- | --- |
| 그림·배치 데이터 다시 만들기 | `python Tools/MapExpansion/build_territory_art.py` (Real-ESRGAN 업스케일은 `Tools/MapExpansion/cache/`에 캐시, `--no-upscale`이면 Lanczos) |
| 데이터 + 광장 배치 | Unity `Tools/Settlement/Apply Map Expansion` (= Apply P3 Projects: P3 그림 → 영토 그림 → 데이터 → 광장 P3 · 영토) |
| 광장만 | `Tools/Settlement/Setup P3 Plaza` (끝에서 영토도 다시 만듦) |
| 확인용 한 장 | `Tools/Settlement/Plaza Snapshot (all unlocked)` — 이제 전체 지도까지 찍음. 배치 모드는 `-snapshotRect x0,y0,x1,y1`(바닥 픽셀) · `-snapshotScale` 지원 |

필요한 파이썬 패키지: `pillow numpy opencv-python-headless` (+ 업스케일 `realesrgan-ncnn-py`, Vulkan GPU).

## 1. 지도

- 사용자가 준 1254×1254 지도(`Tools/MapExpansion/source/plaza_world_map.png`)의 오른쪽 아래가 지금 광장과 같은 곳이다. 랜드마크 8곳(조개 무늬·해안 바위·길 갈림목)으로 최소제곱 → **새 지도 px = (952.97, 667.72) + 기존 px × 0.3146** (같은 배율, 회전 없음).
- 기존 바닥 1px = 지도 1px가 되도록 Real-ESRGAN(x4plus-anime)으로 4배 키운 뒤 다시 맞춰 `Assets/Art/Plaza/Plaza_WorldMap.jpg` (4072×3984, PPU 40, JPG 92 — PNG는 22MB). 원본이 기존 광장 오른쪽 끝보다 28px(기존 67px) 짧아 오른쪽을 거울처럼 이어 붙였다.
- 좌표는 전부 **기존 바닥 픽셀** (plaza_layout.json과 같음, 서쪽·북쪽은 음수). 지도 범위 x −3029 ~ 1043, y −2122 ~ 1862.
- 광장 씬: `Settlement/Territory/WorldMap` 한 장이 바닥. 기존 `Background`(Plaza_Ground)는 픽셀 기준으로만 남기고 렌더러를 끔 → 에디터 코드는 `SettlementSetup.GroundBounds`(스프라이트 크기로 계산)로 바꿈.
- **화질**: 원본 해상도가 지금 광장 기준 약 3.2배 낮아 업스케일해도 기존 바닥보다 부드럽다(디테일 적음). 더 큰 원본을 같은 파일 이름으로 넣고 스크립트를 다시 돌리면 그대로 바뀜 (배율·위치 상수 S·U0·V0는 원본 해상도에 맞춰 다시 재야 함).

### 칸

```text
            열3(서쪽3)  열2(서쪽2)  열1(서쪽1)  열0(광장)
행2(북쪽2)   C3_2        C2_2        C1_2        N2
행1(북쪽1)   C3_1        C2_1        C1_1        N1        ← 가운데 큰 모래 광장은 C1_1 · C2_1
행0(광장)    W3          W2          W1          처음 광장 (0~1043, 0~1536)
```

- 열 경계 x: 0 / −1010 / −2020 / −3029, 행 경계 y: 0 / −1061 / −2122.
- 칸 (i, j)는 서쪽을 i단계, 북쪽을 j단계까지 넓히면 열림 (발전 `territory_cell_{i}_{j}`). 열린 땅은 늘 직사각형 → 카메라 범위도 직사각형.
- 칸마다 걷기 다각형(바다에서 32px 띄움, 옆 칸과 44px 겹침, 광장 쪽은 지금 걷기 영역 안쪽까지만).

## 2. 흐름 · 규칙

```text
Lv.6 → 개간 기회 1 (레벨이 오를 때마다 +1, 쌓임)
광장 서쪽 끝(길 y745) / 위쪽 끝(길 x760)에 점선 원 + 도끼 말풍선 "서쪽 숲 개간 1/3"
  → 누르면 기존 작업 화면: 쉬는 주민 1명 고르기 → 해달이 점선 원으로 걸어가 숲을 향해 일함 (시간, 꺼 둔 동안에도 흐름)
  → 끝: 목재 +30~80 (가방), 그 조각의 숲이 사라지고 그루터기
  ※ 개간은 한 번에 한 곳만: 북쪽을 개간하는 동안 서쪽 원은 숨음. 끝나면 기회가 남은 만큼 다시 방향을 고름
3번 끝 → 점선 원이 "영토 확장 미션"(망치 말풍선) · 마을회관에 영토 확장 카드 [가 보기]
  → 공동사업 화면에서 재료 납품 (부분 납품·되돌려 받지 않음 = 기존 규칙)
  → 다 넣으면: 땅 열림(칸 발전) · 걷기 영역 · 카메라 범위 넓어짐 · 카메라가 새 땅을 비춤 · 경험치 · 알림
  → 그 방향 다음 단계의 점선 원이 새 끝으로 옮겨 감
```

| 규칙 | 내용 |
| --- | --- |
| 기회 | `max(0, 레벨 − 5)` − (끝냈거나 하는 중인 개간 수). 레벨 조건은 `SettlementConfig._territoryStartLevel` (6) |
| 한 곳만 | 진행 중인 영토 개간이 있으면 어느 방향도 시작할 수 없음 (`TerritoryBlock.OtherClearing`) |
| 같은 방향 | 단계 순서대로. 다음 단계는 앞 단계 미션을 끝낸 뒤 (`TerritoryStage.Locked`) |
| 미션 | 단계 없는 공동사업 (`{영토}_mission`, 필요 발전 `{영토}_cleared`, 결과 발전 `{영토}`). 공동사업 순서와 따로 열림 |
| 새 이웃 | `p3_neighbor_01`의 필요 발전이 `plaza_expand_01` → `territory_first`. 집·화분·빨랫줄은 처음 넓힌 방향의 땅으로 (`territory_home_west` / `territory_home_north`, `TerritoryAnchor`) |

### 수치 (`SettlementSetup.Territory.TerritoryTable`)

| 단계 | 개간 시간 | 목재 | 미션 재료 | 경험치 |
| --- | --- | --- | --- | --- |
| 서쪽 1 · 북쪽 1 (숲) | 3분 · 4분 · 5분 | 30 · 35 · 40 | 골드 500 · 목재 40 · 돌 15 | 600 |
| 서쪽 2 · 북쪽 2 (깊은 숲) | 6분 · 8분 · 10분 | 45 · 50 · 60 | 골드 1,200 · 목재 70 · 돌 30 | 1,000 |
| 서쪽 3 (끝 숲) | 10분 · 13분 · 15분 | 60 · 70 · 80 | 골드 2,400 · 목재 110 · 돌 50 | 1,500 |

모두 5단계 × 개간 3번 = 기회 15번 (Lv.6 → 20). 실측 플레이 시간은 재지 않았다. 목재는 `ItemChangeReason.Clearing`으로 넣어 줍기 퀘스트에 세지 않는다. 가방이 가득하면 들어간 만큼만 받고 완료 창에 못 받은 개수를 알린다.

### 세이브

형식 그대로 (정착 세이브 version 3). 영토 진행은 발전·끝낸 작업 기록만 쓴다.

- **동쪽 확장(P3 `plaza_expand_01`)을 끝낸 세이브**: 그 땅이 지도에 없으므로 서쪽 1단계를 넓힌 것으로 옮김 (개간 3번 · 미션 완료 기록 · 보상 기록 — 경험치는 다시 주지 않음, 이웃집은 서쪽).
- 동쪽 확장 사업 도중(납품만 함)이던 세이브: 그 사업이 목록에서 빠져 넣은 재료는 돌려받지 못함. 정비 작업 중이던 세이브는 작업 데이터를 남겨 두어 이어서 끝남.

## 6. 추가 (같은 날)

- **영토 확장 미션 [가능한 만큼 넣기] 오류 수정**: 단계 없는 미션은 납품하는 순간 끝나 완료 알림이 화면을 닫는데(`_project = null`), 그 뒤 `FillProject()`가 다시 불려 `ArgumentNullException(project)`. `FillProject`가 닫힌 화면이면 바로 돌아감.
- **밭 강화 (곡괭이 강화와 같은 규칙)**: 밭 씬 왼쪽 아래 [밭 강화] 버튼 → 강화 창(현재/다음 레벨의 자라는 시간 %, 비용, 보유 코인). 비용 100 · 200 · 400 · 800 코인(곡괭이 표와 같음, 이전 기본값 30 · 150 · 500 · 1,200), 최대 Lv.5, 자라는 시간 100 → 90 → 80 → 70 → 60%, Lv.2부터 오프라인 농사(농사 NPC가 보임). 강화 퀘스트(`TransactionSource.FarmUpgrade`)는 원래 셈. 밭 튜토리얼에 "밭 강화" 단계 추가.
  - 지금까지 밭 강화는 개발용 디버그 화면에서만 할 수 있어서, 일반 플레이로는 오프라인 농사 NPC가 열리지 않았음.
  - Unity가 열려 있어 배치 테스트는 못 돌림 → `dotnet build OtterKingdom.csproj`로 컴파일만 확인.
