# 도감 해달 이야기 작업기록 (2026-10-24)

## 무엇
- 도감 해달 탭의 해달 22마리 모두, 등록되면 [이야기 보기]가 뜬다. 원래 이야기가 있던 건 농부·낚시꾼 해달뿐이라, 나머지 20마리에 이야기(대사 3줄 + 컷 2~3장)를 붙였다.
- 이야기 재생·N 표시·다시 보기 흐름은 기존 그대로 (`CollectionStory`, `CollectionPresenter`). 코드 변경 없음, 데이터와 그림만 추가.

## 대사
- 각 해달의 특성·광장 대사·방명록 문구를 바탕으로 한 1인칭 짧은 이야기. `{이름}` = 플레이어 이름.
- 문구 원본은 `Assets/Editor/Collection/CollectionSetup.cs`의 `Stories` 표 (에셋은 새로 만들 때만 대사를 채우므로, 에셋에서 고친 문구는 유지됨).
- 찰칵이는 컷 3장 (준비 → 플래시 → 눈 감은 사진). 나머지는 2장.

## 컷 그림 (`Tools/StoryCuts`)
- 이미지 생성 대신 **게임 그림으로 장면을 구성**: 해달은 광장 리그(`RiggedLookSetup` 매핑 그대로) 파츠를 `rig.py`가 `QuarterRigView`와 같은 계산으로 조립(서기·손 들기·앉아 졸기·잠든/웃는 얼굴·물건 들기), 배경은 리깅 그림체로 맞춘 광장 맵(`Plaza_WorldMap.jpg`)·광산 배경, 건물·소품·FX는 `Assets/Art/Settlement`·`Plaza/Props` 등.
- 게임에 그림이 없는 종이·공책·이젤만 리그 외곽선 색(#320a00)으로 단순하게 그림.
- 다시 그리기: `python Tools/StoryCuts/build.py` (특정 해달만: `build.py otter_toy_sallang`, 미리보기 시트: `--sheet out.png`). 출력은 `Assets/Art/Collection/Cutscenes/CUT_<entryId>_<A|B|C>.png` — 같은 이름이라 GUID 유지.
- 보들이·포근이·살랑이(꽃 카디건), 데굴이·재잘이·쿵쿵이(줄무늬 니트), 꼼꼼이·영차(케이블 니트)는 광장에서처럼 같은 리그 모습을 쓴다.
