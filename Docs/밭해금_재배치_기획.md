## 2. 새 흐름 (제안)

**밭 대신 초반 돈은 광산**(광석 · 다이아몬드 50골드)과 광장 줍기 · 장난감. **요정은 광부 배치 뒤**(Lv.3) 찾아옴 → 상점 · 뽑기 · 장난감은 오히려 빨라짐.

| Lv | 주제 | 메인 (바뀐 것 **굵게**) |
|---|---|---|
| 1~3 | (그대로) | 첫 집 · 의자 · 광산 · 깡깡이 · 새 이웃의 집 |
| 4 | **요정이 왔어요** | **요정 만나기** → **장난감 2개 놓기** → **광석 20개** → 판매 300골드 |
| 5 | 부탁이 많아졌어요 | **곡괭이 업그레이드 1회** → 게시판 보강(**조건: 광부가 일함**) → **광석 60개** |
| 6 | 함께 일하는 마을 | 또박이 배치 → 쉴 자리 → **장난감 뽑기 1회** → 길드 접수 창구 |
| 7 | 우리 마을의 길드 | 마을 길드 → 첫 비축 → 광석 50개 → **첫 구역 정하기 (중앙 = 주거)** |
| 8 | 영토 넓히기 | 첫 영토 → **판매 3,000골드** → **이사 지시서 1장 끝내기** |
| 9 | 새 이웃 | 이웃 맞이 → 환영 공간 → 일일 1개 → **광석 200개** |
| 10 | **먹거리를 길러요** | **농업 지역 정하기** → 농경지 개간 → 새싹이 배치 → 당근 3개 → 판매 10,000 |
| 11 | 고랑 넓히기 | 감자 모종 사기 → 고랑 열기 1 · 2 → 작물 60개 |
| 12 | 달콤한 밭 | 고랑 열기 3 · 4 → 고구마 30개 → 작물 300개 |
| 13 | 넓어진 밭 | 고랑 열기 5 · 6(마지막) → 딸기 모종 → 작물 500개 |
| 14~15 | (그대로) | 바다를 향해 · 선착장 |

- 예전 Lv.10 "첫 모임 · 업그레이드 · 장난감 · 작물 500"과 Lv.11~13의 딸기 · 광석 · 판매 목표는 Lv.11~13에 나눠 넣음 (경험치 총량은 비슷하게).

## 3. 밭이 열리는 법 (Lv.10)

1. 서쪽(또는 아무) 땅의 숲을 개간해 영토를 넓힘 (기존 영토 확장)
2. 그 땅을 **농업 지역**으로 정함 → 발전 `farm_discovered` (몽실이: "농업 지역 너머에 밭을 만들 땅이 있어요!")
3. 게시판 "먹거리를 길러요" (`req_farmland`, 조건 = `farm_discovered`) → 밭에 가서 치우기 → 주민 개간 → 새싹이 방문 → 배치

- 농업 구역은 처음부터 고를 수 있게 (지금 조건 `farmland` 삭제). 첫 구역은 그대로 중앙 = 주거.
- ~~왕국 레벨 묶음: 개간 부탁 `_kingdomLevel` = 10~~ → 이 칸은 "끝내면 그 레벨로 + 그 전 경험치 상한"이라 Lv.9에서 막힘. 대신 **밭 발견 레벨** `SettlementConfig._farmDiscoverLevel` = 10: 농업 지역을 일찍 정해도 Lv.10에 발견 (QA_Lv1-10).

## 4. 옛 세이브

- 이미 밭을 연 세이브(`farmland` 있음): 그대로 (밭 · 농부 · 요정 유지). 퀘스트는 진행 중인 메인을 새 표 기준으로 다시 맞춤(이미 한 목표는 완료 처리).
- 새 이웃의 집 뒤 · 밭 개간 전 세이브: 밭 발견 취소 → 새 흐름 (Lv.4 요정).

## 5. 확인할 것 (결정 필요)

1. Lv.4~9를 위 표처럼 광산 · 장난감 · 구역 · 이사로 채울지
2. 요정을 **광부 배치 뒤**로 당길지 (상점 · 뽑기가 Lv.3~4부터)
3. 밭 = 아무 블록이나 농업 지역으로 정하면 열림 (위치 강제 없음)
4. 경제: `Tools/Balance/p0_pacing.py`에 밭 없는 Lv.4~10을 넣어 Lv.10 도달 시간 확인 (구현 후)

→ 막히지는 않을 것으로 보지만, 새 게임으로 Lv.4~10을 실제로 해 보며 확인해야 함 (`p0_pacing.py`는 아직 밭 개간까지만 흉내 냄).
