# 특성 기반 사회 성장 — 우리 게임에 맞춘 반영안 (P4)

- 작성: 2026-10-06, `feature/OmissionFunction`

## 0. 확정 (2026-10-06, 사용자)

| 항목 | 결정 |
|---|---|
| 해달과 특성 | **특성 공유**. 해달은 저마다 다른 캐릭터지만 여러 해달이 같은 특성을 가질 수 있다. 한 해달 = 특성 1개, 바뀌지 않음 |

## 3. 장난감 방문 → 정착

```text
광장에 장난감을 놓음 (꾸미기)
→ 방문 시계가 돎 (첫 방문 7분, 그다음 12 · 20 · 30 · 45 · 60분, 이후 60분)
→ 장난감 해달 한 마리가 찾아옴 (Visitor) · 방명록
→ 광장 가장자리에서 걸어 들어옴 = 만남 (기존 방문 대기 줄 그대로)
→ 말을 걸면:
   빈 집이 있으면  "여기 살아도 될까요?" → [입주] → 주민 (특성 +1, 노동력 +1)
   빈 집이 없으면  "빈 집이 생기면 여기 살고 싶어요!" (광장에 머묾)
```

| 규칙 | 내용 |
|---|---|
| 장난감 등급 | **광장 격자**에 놓인 장난감 중 가장 높은 등급. 장난감이 없으면 방문 없음 (시계 멈춤·초기화) |
| 후보 | 아직 온 적 없는 장난감 해달 중 등급 ≤ 장난감 등급 |
| 고르기 | 가중치: 기본 1, 장난감 등급과 같은 등급 ×2, 왕국에 아직 없는 특성 ×3 (막힘 방지 — 4장 건물이 생기면 "다음 건물에 모자란 특성"으로 바꿈). 회차로 정하는 난수라 재접속해도 같음 |
| 기다리는 해달 | 집이 없어 광장에 머무는 장난감 해달이 2마리면 다음 방문을 멈춤 (`_maxWaitingVisitors`) |
| 시간 | 방문 예정 시각(UTC)을 저장 → 꺼 둔 동안에도 흐르고, 돌아오면 이미 와 있음 |
| 빈 집 | 입주민이 없고, 공동사업이 특정 해달에게 정해 둔 자리(이웃집)가 아닌 집 |
| 세이브 | `settlement.toyVisitDueUtcTicks`, `settlement.toyVisitSerial` (필드 추가만, 버전 그대로) |

빈 집은 **작은 집**을 지어 만든다 (8장: 자리를 골라 짓는 건물).

## 4. 특성 건물 (3단계, 1차 7개)

모두 주민 특성 수로 해금 → **꾸미기 모드의 건물 탭에서 자리를 골라 짓기**(8장, 작은 집과 같은 방식) → 완성하면 **보유 효과**(영구). 해금은 다시 잠기지 않음.

| 건물 | 조건 | 보유 효과 | 연결되는 지금 콘텐츠 |
|---|---|---|---|
| 목공소 | 나무캐기 2 | 영토 개간 목재 +20%, 건설 목재 −10% | 영토 확장 |
| 채석 작업소 | 채굴 2 | 바위·광산 돌 +20% | 광장 바위, 광산 |
| 농업 창고 | 농사 2 | 수확량 +10% | 밭 |
| 어업 작업소 | 낚시 2 | 고등어 확률 +5%p | 낚시터 (Lv.15) |
| 작은 장터 | 장사 2 | 판매가 +10% | 판매 · 골드 사용처(C7) |
| 건설소 | 건설 2 | 건설 시간 −15% | 게시판 건설 |
| 기록관 | 기록 2 | 도감 수집 보너스 | 도감 |

- 효과는 한 곳(`KingdomBonus`)에서 합산해 각 기능이 물어보게 한다 (지금 `CurrencyManager.ApplyGlobalModifiers`는 비어 있음).
- 복합 특성 건물(제재소 = 나무캐기+손재주, 지도 제작소 = 탐험+기록 …)은 4단계.

## 8. 자리를 골라 짓는 건물 (2a, 2026-10-06)

### 흐름

```text
꾸미기 모드 → [건물] 탭 (광장에서만)
  칸: 열렸으면 골드 비용, 아니면 "Lv.8" / "나무캐기 1/2" / "잠김" / "다 지음"
→ 건물 고르기 → 화면 가운데 근처 빈자리에 미리보기 (끌어서 옮김, 초록/빨강 칸)
→ [확인] → 자리 · 길 막힘 확인 → "작은 집 짓기 / 골드 600 · 목재 20 · 돌 10 / 이 자리에 지을까요?" → [예]
→ 비용을 내고 그 자리에 공사 시작: 공사 단계 그림(터 → 골조 → 벽 → 마무리) + 지붕 위 진행 막대 (꺼 둔 동안에도 흐름)
→ 완성: 완성 그림이 통 튀어나옴 · 알림 "작은 집 완성! 빈 집이 생겼어요" → 기다리던 장난감 해달에게 "!" → 입주
```

| 규칙 | 내용 |
|---|---|
| 자리 | 꾸미기 격자 규칙 그대로 (칸 크기 · 겹침 · 걷기 영역 밖 불가). 건물은 돌리지 않음 |
| 길 막힘 | 놓거나 옮긴 뒤 해달이 걷는 영역(12칸 이상 덩어리)이 늘어나면(= 길이 둘로 끊김) 거절 "해달이 지나갈 길이 막혀요" |
| 옮기기 | 다 지은 건물만 (공사 중이면 "공사가 끝나면 옮길 수 있어요 (남은 시간)"). 옮겨도 공사·입주 기록은 그대로 (같은 배치 ID) |
| 치우기 | 건물은 치울 수 없음 ([빼기] 없음, 보관함에 들어가지 않음) |
| 동시에 짓기 | 한 번에 한 채 (`BuildingRules.BaseSlots` — 건설소 효과는 3단계) |
| 조건 | 왕국 레벨 · 필요 발전 · 특성 수 · 최대 수 → 공사 자리 → 건설 해달 → 골드 → 재료 순서로 첫 이유 |
| 비용 | 같은 건물을 지었거나 짓는 중인 수만큼 `CostGrowth`씩 늘어남 |
| 해달 | 건물에서 놀지 않음. 건물은 걷기 장애물 (장난감과 같음) |
| 퀘스트 | 건물 놓기는 장난감 놓기 퀘스트에 세지 않음. 장난감 방문 등급도 건물은 빼고 셈 |

### 광장 격자 넓히기

- 광장 격자: 24 × 33칸 (-12, -14.4) → **101 × 90칸 (-89, -17.4)** — 전체 지도 중 영토 확장 땅(서쪽 3 · 북쪽 2단계)까지 덮음 (모든 영토를 연 걷기 영역이 격자 안에 들어오는지 씬에서 확인).
- 막힌 칸은 지금처럼 걷기 영역 밖 → **아직 개간하지 않은 땅은 저절로 막히고**, 영토가 열려 걷기 영역이 다시 만들어지면(`PlazaWalkableArea.StaticVersion`) 막힌 칸도 다시 계산.
- 세이브 좌표 기준 칸 `DecorBoardDefinition._saveOrigin = (77, 3)`: 세이브 = 칸 − 기준 → **넓히기 전 세이브의 장난감도 같은 자리**.

## 9. Lv.10~15 해달의 부탁 (2026-10-06, 사용자 확정: 레벨 잠금 + 아래 구성)
