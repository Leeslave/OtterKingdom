## 2. 진행 방법

1. **채팅방을 인물별로 나눈다.** 한 채팅 안에서는 앞 그림을 기억해서 얼굴·옷이 잘 유지된다.
   - 채팅 ① 농부 해달: 당근 A·B, 감자 A·B, 오이 A·B, 농부 해달 A·B (8장)
   - 채팅 ② 낚시꾼 해달: 고등어 A·B, 낚시꾼 해달 A·B (4장)
   - 채팅 ③ 둘 다: 고구마 A·B·C (3장) — 참고 이미지 두 장을 같이 올림
2. 채팅마다 **참고 이미지를 올리고 3장의 "시작 메시지"를 먼저 보낸다.**
3. 그다음 4장의 컷 프롬프트를 **한 번에 하나씩** 보낸다. 같은 이야기의 B컷은 "방금 그림과 같은 장면의 다음 컷"이라고 이어서 요청한다.
4. 마음에 안 들면 5장의 수정 문구로 고친다. 새로 뽑기보다 "이 그림에서 ○○만 고쳐줘"가 캐릭터 유지에 유리하다.
5. 6장 규칙대로 저장한다.

## 5. 수정 요청 문구

| 문제 | 보낼 문장 |
|---|---|
| 얼굴·옷이 참고 그림과 달라짐 | `첨부한 참고 그림과 얼굴·의상이 달라졌어. 자세와 장면은 그대로 두고 캐릭터만 참고 그림과 똑같이 다시 그려줘.` |
| 글자가 들어감 | `그림 안의 글자와 기호를 전부 지우고 나머지는 그대로 둬.` |
| 캐릭터가 너무 아래에 있음 | `캐릭터를 위로 올려서 얼굴과 손이 화면 위쪽 70% 안에 오게 해줘. 아래쪽은 바닥만 보이게.` |
| 외곽선이 얇음 / 사실적임 | `외곽선을 더 굵고 둥근 짙은 갈색으로, 더 단순하고 귀여운 스티커풍으로 바꿔줘.` |
| 손가락·꼬리 이상 | `손(또는 꼬리)이 이상해. 해달 손답게 둥글고 짧게 고쳐줘. 나머지는 그대로.` |
| 배경이 너무 화려함 | `배경의 채도를 낮추고 살짝 흐리게 해서 캐릭터가 더 눈에 띄게 해줘.` |
| 세로로 나옴 | `가로 1536×1024로 다시 만들어줘.` |

## 6. 저장하고 게임에 넣기

1. 파일 이름을 4장에 적힌 이름으로 저장한다 (예: `CUT_crop_carrot_A.png`). **대문자 A/B/C까지 정확히.**
2. `Assets/Art/Collection/Cutscenes/` 폴더에 넣는다 (폴더가 없으면 만든다).
3. Unity 메뉴 **Tools → Collection → Apply Stories And Cutscenes**를 실행하면 각 이야기 에셋의 빈 컷 칸에 자동으로 들어간다.
   (Build Global UI로도 들어가지만 정착 설정 데이터 일부를 지우므로 이 메뉴를 쓴다.)
   또는 `Assets/Scriptable Obejects/Collection/Stories/Story_Entry_*.asset`의 **Cuts** 칸에 직접 끌어 넣어도 된다.
4. 그림이 없는 컷은 그 항목의 아이콘이 크게 뜨는 임시 컷으로 나온다. 그림을 넣는 순서는 상관없다.
