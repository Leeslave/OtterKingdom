# 오프라인 자동 수확 작업 기록

- 작업일: 2026-09-29
- 브랜치: `feature/OfflineAutoPlay` (`develop`의 `b983bc5` 기준, 아직 커밋 안 함)
- 확인 상태
  - 아래 "테스트 방법" 1~9번과 EditMode 테스트를 확인함
  - **마지막에 추가한 해달 방문은 컴파일만 확인함.** 플레이 모드와 새 테스트 3개는 아직 안 돌림 (10번)

## 배경

기획 변경 명세와 이전 결정에서 오프라인 진행은 "밭은 마지막 작물을 계속 다시 심음"이었다. 이번에 채팅에서 규칙을 새로 정했다. 기존 규칙을 대신한다.

| 항목 | 규칙 |
|---|---|
| 조건 | 밭 레벨 2 이상이면 오프라인 농사, 낚싯대 레벨 2 이상이면 오프라인 낚시 |
| 밭에서 무엇이 자라나 | 밭 NPC에게 등록한 작물만. **실제 밭에 심어 둔 작물과는 무관** |
| 등록할 수 있는 수 | 해금된 슬롯(점선 타원) 수 = 해금된 밭고랑 수 × 3. 같은 작물을 여러 칸에 등록해도 됨 |
| 수확 1번 | 소모형 모종 1개 → 채소 1개 (`offlineYieldPerHarvest`, 온라인 수확량과 별개). 영구 모종(당근, 오이)은 모종을 쓰지 않음 |
| 모종이 떨어지면 | 그 칸은 멈추고, 복귀 팝업에 "모종이 떨어져서 멈춘 작물"로 표시 |
| 낚시 | 해달이 낚시 중이 아니어도 됨. 낚싯대 레벨 확률로 물고기/쓰레기 |
| 속도 | 온라인보다 4배 느림, 시간 상한 없음 |
| 심어 둔 슬롯 | 오프라인 동안 수확 대기까지 자라고 멈춤 (전과 같음) |
| 가방이 가득 차면 | 넘친 것은 잃고, 복귀 팝업에 따로 표시 |
| 해달 방문 | 레벨과 관계없이 오프라인 동안 확률적으로 해달이 다녀감. 지금은 팝업에만 표시 (아래 "해달 방문") |
| 다시 접속하면 | 다녀간 해달, 받은 것, 사용한 모종, 놓친 것, 멈춘 작물을 팝업으로 알려줌 |

밭 레벨을 올리는 UI는 이번 범위가 아니다. woohyck 쪽 상점이 만들어지면 거기에 넣는다. 그 전까지는 아래 개발용 창으로 레벨을 올려서 테스트한다.

## 동작

### 언제 계산하나

| 상황 | 오프라인 생산 | 심어 둔 슬롯 |
|---|---|---|
| 앱을 켤 때 | "앱 시작 시각 − 마지막 저장 시각"만큼. 앱 실행 한 번에 한 번만 | "지금 − 마지막 저장 시각"만큼 자람 |
| 앱을 내렸다 올릴 때 (모바일) | 내려가 있던 시간만큼 | 같은 시간만큼 자람 (**전에는 이 시간이 빠졌음**) |
| 다른 장소에서 들어올 때 | 계산 안 함 (플레이 중이었으므로) | 다른 장소에 있던 시간만큼 자람 |

- 앱 시작 시각은 `[RuntimeInitializeOnLoadMethod(SubsystemRegistration)]`에서 기록한다. 그래서 `GameManager`가 없는 씬에서 시작해도, 나중에 처음 생기는 `GameManager`가 앱을 켜기 전까지의 시간만 오프라인으로 계산한다.
- 계산 직후 바로 저장한다. 도중에 튕겨도 같은 결과를 두 번 받지 않는다.
- 다 채우지 못한 시간은 세이브에 남긴다 (`OfflineFarmSlotSaveData.progressSec`, `offlineFishingProgressSec`). 짧게 여러 번 꺼도 누적된다.

### 계산 방식 (`OfflineProductionService`)

씬, 애니메이션, 해달과 무관한 C# 코드다. 가방은 `IOfflineBag` 인터페이스로 받아서, 테스트에서는 가짜 가방을 쓴다.

- **밭**
  - 한 칸의 주기 = `ceil(작물 기본 시간 × 밭 레벨 배율) × offlineSlowdown`
  - 여러 칸의 수확을 **끝나는 시간 순서로** 처리한다. 같은 모종을 쓰는 칸끼리는 먼저 다 자란 칸이 모종을 가져간다.
  - 레벨이 올라 주기가 짧아졌는데 남은 진행 시간이 새 주기보다 길면, 바로 수확할 차례로 본다.
  - 해금된 칸 수보다 많은 등록은 무시한다 (밭을 다시 잠근 경우).
- **낚시**
  - 한 마리 시간 = `(입질 대기 평균 + onlineAnimationSecPerCatch) × offlineSlowdown`. 기본값이면 `(20 + 5) × 4 = 100초`
  - 한 마리마다 `FishChanceAt(낚싯대 레벨)`로 물고기/쓰레기를 뽑는다.

- **해달 방문** (`OtterVisitBalanceData`)
  - 오프라인 `rollIntervalSec`(30분)마다 `visitChancePerRoll`(30%) 확률로 1마리가 다녀간다. 8시간이면 평균 약 5마리다.
  - 누가 오는지는 임시 이름 10개(도깨비 해달, 산적 해달, 선장 해달 등)에서 무작위로 고른다. 나중에 마을 레벨과 섬에 놓인 장난감 종류로 정하는 로직으로 바꿀 자리다.
  - 팝업에 "도깨비 해달이 다녀갔어요!"로 한 줄씩 뜬다. 같은 해달이 여러 번 오면 "(2번)"을 붙인다.
  - **누가 다녀갔는지는 저장하지 않는다.** 해달 데이터와 아트가 생기면 도감 "방문 흔적"용으로 저장을 추가한다. 30분을 못 채운 시간만 저장한다 (`offlineOtterVisitProgressSec`).

예시 (레벨 2, 성장 배율 0.9): 당근 한 칸의 주기는 `ceil(30 × 0.9) × 4 = 108초`다. 1시간이면 33번 수확해서 당근 33개를 받는다. 낚시는 1시간에 36마리를 낚고, 그중 물고기가 약 55%다.

### 밭 NPC와 등록 팝업

- `OfflineFarmNpc`는 밭 레벨 2 이상일 때만 보이고 눌린다. 레벨이 바뀌면 바로 나타나거나 사라진다.
- NPC를 누르면 "오프라인 농사" 팝업이 뜬다. 해금된 칸 수만큼 `칸 N : 작물 [변경]` 줄이 있다.
- [변경]을 누르면 작물 목록이 뜬다. 소모형 작물에는 남은 모종 수가 함께 표시된다. 이미 등록된 칸에는 [등록 해제]도 있다.
- 작물을 바꾸면 그 칸의 진행 시간은 0부터 다시 시작한다. 바꾸는 즉시 저장한다.
- 아트가 생기기 전까지 NPC는 농부 해달 걷기 첫 프레임(`FarmerOtter_Sheet_Walk_0`)을 파란빛으로 칠해 임시로 쓴다. 아트가 생기면 `SpriteRenderer`의 스프라이트를 바꾸고 색을 흰색으로 돌린다.

### 광장에도 `GameManager` 배치

시작 씬이 광장인데 광장에 `GameManager`가 없어서, 오프라인 결과가 밭이나 낚시터에 처음 들어갈 때에야 계산되고 팝업이 떴다. 이를 고치려고 세 장소 씬이 같은 `GameManager` 프리팹을 쓰게 했다.

- 씬마다 `GameManager`를 따로 두면 설정이 어긋난다. 실제로 밭 씬은 `Fishing Balance`가 비어 있어 코드 기본값을 썼고, 낚시터 씬은 `FishingBalanceData` 에셋을 썼다. 프리팹을 만들 때 에셋으로 채웠다.
- 광장 인스턴스는 `Show Sell Button`을 끈다.
- 광장에서도 밭 시간은 흐르지만, 수확은 밭 씬의 해달이 해야 해서 수확 대기에서 멈춘다. 낚시터에 있을 때와 같고, 이대로 두기로 했다.

### 이 과정에서 같이 고친 것

- **장소를 옮기기 전에 저장:** `GameManager`가 `SceneNavigator.BeforeLeave`에 `SaveNow`를 연결한다. 네비게이션 연동 요청 문서의 부탁 (2)다. 전에는 앱이 일시정지되거나 종료될 때만 저장해서, 장소를 옮기면 밭 슬롯이나 낚시 상태가 저장되지 않았다.
- **코인 HUD 중복:** `CurrencyHud.Show`가 `GameManager`가 생길 때마다 `DontDestroyOnLoad` HUD를 새로 만들어서, 장소를 옮길 때마다 HUD가 하나씩 쌓였다. 이미 있으면 만들지 않게 했다.

### 개발용 창 (`Offline Test`)

플레이 중에는 실행 중인 `GameManager`의 세이브를 고치고 바로 저장한다. 플레이 중이 아니면 세이브 파일을 직접 고친다. 코인은 건드리지 않는다.

- **레벨:** 밭과 낚싯대 레벨 `-` / `+`, 오프라인이 켜졌는지 표시
- **초기화 (밭·낚싯대 Lv.1)**
- **밭 2·3 다시 잠그기:** 거기 심어 둔 작물은 사라진다. 모종과 코인은 돌려주지 않는다
- **자리 비운 시간 만들기 (플레이 중이 아닐 때만):** 마지막 저장 시각을 `-10분` / `-1시간` / `-8시간`만큼 과거로 돌린다

## 남은 일

- **밭 레벨을 올리는 UI가 없다.** 지금은 열 수 없는 디버그 패널에만 있어서, 실제 플레이어는 오프라인 농사를 열 수 없다. woohyck 쪽 상점이 만들어지면 거기에 넣는다.
- **기기 시계 조작 (보류, 논의 후 결정):** 시간 상한이 없어서, 기기 시계를 앞으로 돌리면 그만큼 받는다. 막는 것은 확정이고 방식만 정하지 않았다. 검토한 안:
  - 인터넷 시간: 켜거나 돌아올 때 HTTPS 응답의 `Date` 헤더로 실제 시각을 확인한다. 우리 서버가 없으므로 처음에는 공개 사이트를 쓰고 나중에 바꾼다.
  - 인터넷이 없을 때: 보상을 연결될 때까지 **보류**(추천)하거나, 기기 시계로 계산하되 **상한**을 둔다.
  - 공통: 지금까지 인정한 가장 늦은 시각을 저장해서, 그보다 이전 시간은 다시 인정하지 않는다. 시계를 앞으로 돌렸다가 되돌리는 방식을 막는다.
- **해달 방문 저장과 풀:** 누가 다녀갔는지 저장하는 일(도감 "방문 흔적"), 마을 레벨과 장난감에 따라 오는 해달을 정하는 일, 광장에서 해달을 눌러 등록하는 일이 남았다.
- **임시 버튼:** 판매 버튼과 낚싯대 강화 버튼은 `GameUI`의 임시 버튼이다 (보류). `GameUI` 캔버스 `sortingOrder`가 200이라 네비게이션 바(100) 위에 그려지고, 오른쪽 아래 판매 버튼이 네비게이션 바와 겹칠 수 있다. 판매는 가방 상세 화면으로, 낚싯대 강화는 밭 강화와 같은 곳으로 옮기는 것이 후보다.
- **밭 NPC 아트:** 지금은 임시 이미지다.
- **도감 연동:** 도감은 woohyck 쪽이 만든다. 오프라인 수확물도 가방에 `Harvest` / `Fishing` 사유로 들어가므로, 도감이 가방 변경 이벤트로 등록하면 오프라인에서 처음 얻은 것도 등록된다. 해달 "방문 흔적"은 위의 방문 저장이 생긴 뒤에 연결한다.
