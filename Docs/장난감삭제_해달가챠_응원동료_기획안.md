# 장난감 삭제와 해달 가챠 — 응원 동료 기획안

- 작성일: 2026-10-21
- 상태: 검토용 제안. 이번 작업은 문서 작성이며 게임 코드·데이터 삭제는 하지 않는다.
- 사용자 방향: 장난감 삭제, 관련 퀘스트·해달 출현 조건 변경, 가챠 보상을 해달로 변경, 획득한 해달이 게임에 유용한 버프 제공.
- 후속 사용자 방향: 쿵쿵이 등 기존 특수 해달은 유지한다. 가챠는 음유시인처럼 별도 직업의 신규 해달을 추가하고, 직업에 맞는 생활 버프를 준다.

## 1. 추천 구조

**이야기로 만나는 주민은 마을의 기능을 열고, 가챠로 만나는 응원 동료는 그 생활을 더 편하게 만든다.**

| 구분 | 주민 해달 | 응원 동료 해달 |
|---|---|---|
| 만나는 방법 | 생활 목표·시설·이야기 조건으로 확정 등장 | 가챠·선택 교환 |
| 역할 | 집에 입주, 특성 인원수 충족, 건설·생산 담당 | 응원 편성으로 왕국 버프 제공 |
| 집·부지 | 기존 정착 규칙 사용 | 필요 없음 |
| 외형 작업 | 현재 주민의 기존 리깅 활용 | 첫 버전은 초상화·소개·표정 중심 |
| 메인 진행과 관계 | 필수 진행 경로 | 진행을 빠르고 편하게 하는 선택 경로 |

기존 주민·특수 해달은 이름·역할·리깅을 유지한다. 장난감에 의존하던 출현 조건만 생활 진행 조건으로 바꾼다. 가챠에는 별도 직업을 가진 신규 해달을 추가한다. 응원 동료를 뽑아도 주민 수·나무 특성 수가 늘지 않는다. 같은 캐릭터를 주민과 별도 응원 카드로 중복 판매하지 않는다.

주민을 전부 가챠에 넣으면 필요한 특성의 해달을 못 뽑아 시설이 막힐 수 있다. 반대로 획득한 동료마다 집과 광장 리깅을 요구하면 장난감을 없앤 제작상 이점이 줄어든다. 이 두 문제를 피하면서 ‘해달을 모아 왕국을 돕는다’는 경험을 만드는 제안이다.

## 2. 플레이 흐름

`새 이웃 정착 → 요정의 동료 소개 → 첫 무료 초대 → 해달 획득 → 응원 편성 → 생산·공사에서 효과 확인 → 필요한 분야의 동료 수집`

- 기존 조개 연출은 ‘초대장을 담은 보물 조개’로 설명을 바꾼다. 조개를 열면 초대장과 해달 초상화가 나타난다.
- 결과는 즉시 동료 명부에 등록한다. 방문 대기·빈 집·광장 배치를 추가로 요구하지 않는다.
- 처음에는 응원 1칸, 첫 개간 뒤 2칸, 농업 시작 뒤 3칸을 무료로 연다. 슬롯 해금은 뽑기 횟수와 연결하지 않는다.
- 첫 무료 동료는 음유시인으로 확정해 주민들이 움직이는 광장에서 바로 효과를 확인하게 한다. 이후 유료 확률표와 다른 튜토리얼 보상임을 분리해 표시한다.
- 획득 화면에 `첫 만남! / 주민 이동속도 +5% / [응원 맡기기]`처럼 다음 행동을 바로 보여 준다.

## 3. 버프는 ‘선택한 3마리의 응원’

보유한 모든 해달의 효과를 무한 합산하지 않고, 명부에서 최대 3마리를 선택한다. 집·생산 작업 배치와 별개의 응원 편성이다.

- 첫 버전: **해달 한 마리당 효과 하나**. 스킬 트리·장비·전용 자원·자동 발동 스킬은 넣지 않는다.
- 같은 계열의 응원은 한 마리만 편성한다. 예: 목재 획득 담당 2마리를 동시에 넣을 수 없다.
- 편성 교체는 무료다. 이미 시작된 공사·작업의 완료 시각은 다시 계산하지 않는다.
- 버프는 자원 획득·작업 시작 등 정해진 시점에 한 번 적용한다. 상자에서 받을 때 다시 적용해 이중 보상하지 않는다.
- 판매 버프는 판매 시점, 생산량 버프는 생산 시점에 적용한다. 획득 화면과 생산 화면에 이 규칙을 짧게 설명한다.
- 진행 중 공사의 교체를 강요하지 않도록 공사 버튼에 예상 시간과 적용 중인 응원을 보여 준다.
- 해금 전 콘텐츠를 돕는 동료도 획득할 수 있지만 `낚시터가 열리면 활약해요`라고 표시한다. 시설을 대신 열어 주지는 않는다.

### 첫 버전 버프 예시

아래 직업·수치는 신규 동료의 가안이다. 기존 주민 이름·역할을 변경하는 제안은 아니다. 단순 자원별 수치 차이보다 직업의 성격이 생활 개선으로 드러나는 구성을 우선한다.

| 동료 가안 | 분야 | 효과 가안 | 체감되는 곳 |
|---|---|---|---|
| 음유시인 해달 | 활기 | 주민 이동속도 +5% | 광장 산책·농부 운반·건설 현장 이동. 연주·전용 동작은 필수 아님 |
| 정원사 해달 | 재배 | 작물 성장 시간 -5% | 새로 심는 작물. 기존 농부는 수확·운반을 계속 담당 |
| 창고지기 해달 | 보관 | 농장 상자 용량 +15% | 더 오래 자리를 비워도 농부가 계속 일함 |
| 건축가 해달 | 설계 | 새 공사 시간 -5% | 설계로 뚝딱이·콩콩이의 건설을 도움. 실제 시공 역할은 유지 |
| 회계사 해달 | 살림 | 판매가 +3% | 판매 창의 실제 수입. 짤랑이의 상점 운영은 유지 |
| 기상관측사 해달 | 어업 | 물고기 획득 +5% | 좋은 조업 때를 알려 준다는 설정. 날씨 시스템 신설은 요구하지 않음 |
| 산림관리사 해달 | 목재 | 목재 획득 +5% | 기존 나무·개간·향후 목공소 작업. 구매·퀘스트 보상 제외 |
| 지질학자 해달 | 채석 | 건축용 돌 획득 +5% | 기존 바위·광산의 돌·향후 채석 작업. 광석·보석 제외 |

첫 출시 권장 규모는 **실제로 효과가 작동하는 6~8종**이다. 수급 기능이 아직 없는 버프를 채우려고 동료를 먼저 늘리지 않는다. 6종 미만이면 픽업·다단계 희귀도를 서두르기보다 수집과 편성의 재미부터 확인한다.

### 상황별 편성 예

- 새 집·목공소 준비: 목재 + 돌 + 건설.
- 농장을 오래 비우기: 수확량 + 상자 용량 + 판매.
- 선착장 완공 뒤: 낚시 + 판매 + 현재 필요한 재료.

편성마다 강점은 달라도, 아무 편성이 없어도 메인 공사와 생산을 완료할 수 있어야 한다.

### 음유시인 상세 규칙

음악으로 마을에 활기를 준다는 설정으로, 편성 중 왕국의 주민 이동속도를 +5% 올린다. 광장 산책과 실제 농부·건설 해달의 이동에 적용하고, 플레이어 조작·광산 탐험·카메라·생산 대기시간에는 적용하지 않는다. 범위 내에 있어야 하는 오라 방식은 피한다. 건설 타이머를 줄이는 건축가 효과와도 구분한다.

농부 이동이 빨라져도 작물 성장·수확 동작은 그대로이므로 최종 생산량이 그대로 5% 늘어나는 것은 아니다. 오프라인 생산에 걷는 시간이 포함된다면 같은 배율을 해당 시간에만 적용하고, 별도의 전체 생산 +5%를 덧붙이지 않는다. 흙길·돌길과의 중첩 및 각 이동 컨트롤러의 실제 적용 여부를 확인한다.

화면에는 작은 음표 아이콘과 `음유시인의 응원 · 이동속도 +5%`를 표시한다. 첫 버전은 초상화만으로 성립하게 하고, 광장 공연·악기 연주 리깅·상시 음악 재생은 후속 표현으로 둔다.

## 4. 건물과 동료의 관계

**건물은 새 행동을 열고, 동료는 그 행동의 효율을 올린다.**

| 건물 보상 | 동료의 도움 |
|---|---|
| 목공소: 반복 목재 작업, 이후 스프링클러 | 목재 획득량 증가 |
| 채석 작업소: 반복 돌 작업, 이후 돌길 | 돌 획득량 증가 |
| 농업 창고: 큰 상자·흙길·흙 개선 | 수확량 또는 상자 용량 보완 |
| 건설소: 수레·공사 편의 | 공사 시간 추가 단축 |
| 선착장·어업 작업소: 낚시와 어업 개선 | 물고기 획득량 증가 |

수레·스프링클러·생산 슬롯·새 지역은 가챠 전용 효과로 주지 않는다. 시설을 지을 이유를 유지한다.

건물·구역·동료가 같은 수치를 바꾸면 같은 종류끼리 합산하고 공통 상한을 둔다. 가안으로 동료의 수량 버프는 계열당 최대 +15%, 판매는 +10%, 공사 시간 감소는 동료 몫 최대 15%로 시작한다. 전체 상한은 기존 건물·구역을 포함한 수급표로 정한다. 건물 보너스보다 큰 버프를 무조건 희귀 동료에 배정하지 않는다.

현재 `KingdomBonus` 설명에는 오프라인 미적용이 남아 있다. 새 동료는 지원하는 생산에 온라인·오프라인 같은 기준으로 적용하도록 별도 점검한다. 기존 보너스 경로에 더하기만 하면 된다고 가정하지 않는다.

상자 용량 담당을 해제해 용량이 줄어도 이미 쌓인 내용물은 보존한다. 초과 상태에서는 추가 적재만 멈추고, 수령·저장된 작물은 사라지지 않는다.

## 5. 중복 획득과 희귀도

### 중복은 공용 반짝 조각으로

동일 해달이 여러 마리 생기거나 집을 더 요구하지 않는다. 신규면 동료 등록, 중복이면 기존 반짝 조각을 지급한다.

- 반짝 조각은 아직 없는 동료를 골라 초대하는 데 사용한다. 단순히 중복을 다시 무작위 뽑기로 돌리지 않는다.
- 첫 버전은 중복 돌파·별 등급·동료별 조각을 넣지 않는다. 그래야 가챠·편성·주민·특성 네 구조를 먼저 이해할 수 있다.
- 중복이 쌓였을 때의 장기 사용처는 신규 동료 추가와 선택 교환으로 시작한다. 전체 수집 이후 조각 사용처가 부족하면 외형 보상 등을 후속 검토한다.

### 희귀도는 효과의 강도와 개성

핵심 분야는 기본 등급으로도 이용 가능하게 한다. 에픽이 있어야 낚시·자동 수거가 되는 식의 독점 기능은 만들지 않는다. 같은 계열의 기본 +8%, 레어 +10%, 에픽 +12% 정도를 가설로 삼되, 첫 6~8종만으로 여러 등급을 억지로 채우지 않는다.

초기에는 상시 동료 초대 하나를 우선한다. 충분한 명단과 밸런스가 준비된 뒤 픽업을 운영한다. 기존 확률·가격·천장·교환비는 장난감 기준이므로 그대로 확정하지 않는다. 동료 수, 신규 획득 기대 횟수, 무료 지급량, 선택 교환까지 걸리는 횟수를 계산한 뒤 정한다.

가구가 섞인 기존 골드 가챠는 동료 전용 보상으로 바꾸거나 통합한다. 초기 권장은 상시 초대에서 하루 1회 골드 이용 경로를 두고 독립 골드 배너는 정리하는 것이다. 가격은 필수 공사 재료비와 경쟁시키지 않도록 플레이 수입으로 검증한다.

## 6. 장난감 해달 출현 조건 변경

기존 주민의 성격과 특성은 유지하고 등장 조건만 생활 진행으로 옮긴다. 아래 조건은 앞선 진행안과 함께 적용하는 제안이다.

| 해달 | 새 확정 등장 조건 | 이유·후속 역할 |
|---|---|---|
| 꾸벅이 | 기존 초반 방문 유지, 목재 일터 이야기에서 입주 안내 | 초반 익숙한 해달이 목공소와 연결 |
| 쿵쿵이 | 첫 개간 체험·목재 일터 부탁 시작 | 꾸벅이와 나무 특성 2명 충족 |
| 데굴이 | 목공소 첫 생산·다음 영토 준비 | 깡깡이와 채굴 특성 2명 충족 |
| 보들이 | 첫 농장 수확 | 창고를 지을 농사 특성 충족 |
| 짤랑이 | 농업 창고 이후 잉여 작물 판매 이야기 | 해달 상점 개업 |
| 콩콩이 | 농장 설비 개선 이후 선착장 준비 | 건설소를 지을 특성 충족 |
| 퐁당이 | 선착장 복구와 첫 낚시 | 어업 작업소와 연결 |
| 끄적이 | 마을의 생산·어업 일터 정비 완료 | 기록관으로 연결 |
| 영차 | 농장 수확 상자에서 첫 수령 | 운반을 좋아하는 새 이웃, 수레 이야기 보조 |
| 재잘이 | 해달 상점 완공 | 장사하는 이웃으로 상업 구역 생활 보강 |
| 꼼꼼이 | 첫 스프링클러 설치 | 손재주 특성과 설비 이야기 연결 |
| 두리번 | 첫 영토 확장 완료 | 탐험하는 이웃으로 확장 안내 |
| 살랑이 | 해달 상점 완공 뒤 주민 교류 부탁 완료로 확정 등장 | 기존 특수 해달로 유지. 기존 보유자는 상태 유지, 장난감 조건만 제거 |

스토리 주민은 조건 충족 후 한 번 등장해 명부에 대기한다. 빈 집이 없어도 사라지지 않고, 다른 필수 방문을 막지 않는다. 여러 조건이 동시에 충족되면 대표 목표에 필요한 해달부터 소개 연출을 하고 나머지는 명부에서 확인한다.

밤·낮·의자·가로등 같은 기존 부가 방문 조건은 필수 등장 판정에서 제거한다. 성격 대사·생활 연출에 활용할 수는 있지만 이야기를 막는 조건으로 남기지 않는다.

기록관의 ‘장난감 해달 방문 간격 감소’는 **주민 생활 의뢰 보상 +10%** 같은 현재 생활에 쓰이는 효과로 교체를 검토한다. 가챠 무료 횟수 증가와 묶지는 않는다. 주거 구역의 방문 속도 보너스도 폐기되는 기능이므로 주민 작업 휴식·생활 의뢰 등 실제 남는 기능으로 함께 재설계해야 한다. 이번 표에서는 대체 효과를 확정하지 않는다.

## 7. 관련 퀘스트 변경

| 기존 목표 | 새 목표 제안 |
|---|---|
| Lv.4 장난감 2개 배치 | 무료 동료 초대 → 응원 1마리 편성. 조개 소비 요구 없음 |
| Lv.13 장난감 3개 배치 | 스프링클러 설치·지원받는 밭 확인 |
| 장난감 구매·보유 수·등급 목표 | 시설 준비·새 주민 만나기·동료 명부 확인 등 해당 시점 행동으로 대체 |
| 장난감 해달 방문 대기 | 해당 주민의 확정 등장 기록으로 완료 |
| 장난감을 보고 찾아왔어요 | 주민은 생활 진행에 맞는 초대 대사, 가챠는 동료 소개 문구 |
| 장난감 도감 | 동료 도감으로 대체하되, 기존 기록은 이관용으로 보존 |

일일 퀘스트에 조개 뽑기·특정 동료 획득·특정 희귀도 보유를 넣지 않는다. 동료 튜토리얼도 첫 무료 초대와 지급 동료만으로 끝나야 한다. 이미 배치한 장난감 목표가 있는 세이브는 새 목표로 갈아타며 이전 완료·보상을 중복 지급하지 않는다.

## 8. 리깅 제작 범위

첫 버전의 동료 필수 자산은 초상화 1장, 설명·대사, 공통 카드 연출이다. 새 작업 동작이나 장난감 상호작용 리깅은 요구하지 않는다.

- 동료 화면: 초상화와 적용 효과, 응원 중 표시.
- 생산 화면: 담당 동료 작은 얼굴 + `목재 +8%`.
- 효과 연출: 첫 적용 때 아이콘이 짧게 뜨고 실제 증가량 확인. 매 수확마다 팝업을 띄우지는 않는다.
- 광장 등장: 기존 호환 리깅이 있는 동료만 후속으로 공통 걷기·대기 동작을 쓸 수 있다. 출시 필수 조건에서 제외한다.
- 리깅 준비가 끝나지 않은 해달은 화면에 임시로 같은 몸을 여러 번 찍어 내기보다 초상화 표현으로 완성한다.

살랑이를 포함한 기존 특수 해달은 가챠 동료로 전환하지 않는다. 추가 동료 수는 기존 리깅 수가 아니라 신규 초상화와 실제 버프 구현이 준비된 수로 결정한다.

## 9. 기존 이용 기록 이관

장난감을 제거할 때는 판매·배치·연출부터 끄고, 보상 이관과 참조 제거 후 데이터를 정리한다. 이름에 Toy가 있다고 저장 필드와 주민 ID를 먼저 삭제하지 않는다.

1. 배치된 장난감은 격자에서 제거해 공간을 돌려준다. 가방·보관함·판매·상점·가챠·교환소 목록에서도 퇴출한다.
2. 장난감으로 만났거나 입주한 주민은 유지한다. 특성·집 배정·작업·시설 해금 기록도 보존한다.
3. 보유·배치·보관 상태의 장난감을 한 번만 합산해 등급별 반짝 조각 또는 전환권으로 보상한다. 과거 소비량까지 추정한 전액 환급으로 설명하지 않는다.
4. 한정 장난감 보유 또는 기존 한정 해달 만남 기록이 있으면 대응 기존 특수 해달의 만남 자격을 유지한다. 살랑이는 기존 특수 해달로 남기며 응원 동료로 전환하지 않는다. 기존 입주자는 그대로 유지하고, 입주 전이면 집 준비 경로로 연결한다. 보유 장난감의 전환 보상은 별도로 한 번만 지급한다.
5. 뽑기권·반짝 조각·천장·픽업 확정 상태를 보존한다. 배너 통합 시 이미 쌓은 확정까지 남은 횟수를 불리하게 바꾸지 않도록 변환표를 만든다. 별빛 포인트도 별도 교환·보존 정책을 명시한다.
6. 저장에 전환 버전을 기록해 재접속·저장 실패 복구 시 중복 지급을 막는다. 전환 전 백업을 남긴다.

정확한 보상 수량은 현재 배너 확률과 동료 명단을 확정한 뒤 산정한다. 퀘스트·상점으로 얻은 장난감과 뽑기로 얻은 장난감을 구분할 기록이 없으면 구매 출처를 임의로 추정하지 않는다.

## 10. 구현 순서와 확인 범위

### 먼저: 최소 기능으로 체감 확인

1. 응원 동료 데이터·소유 명부·편성 3칸·저장 설계.
2. 목재·돌·수확·낚시·건설·판매 등 현재 동작하는 버프부터 연결.
3. 기존 가챠의 장난감 ItemDefinition 결과를 동료 ID 결과로 전환. 가방 용량과 동료 획득을 분리.
4. 첫 무료 동료와 편성 안내, 결과 카드·확률·교환 화면 변경.
5. 장난감 퀘스트와 주민 출현을 이야기 조건으로 전환.
6. 저장 이관 구현 후 장난감 구매·배치·반응·방문 타이머 참조 제거.

### 완료 기준

- 장난감 없이 새 게임부터 목공소·채석 작업소·농사·선착장까지 진행 가능.
- 필수 주민·특성·시설이 특정 가챠 결과를 요구하지 않음.
- 첫 무료 동료를 편성하면 실제 생산·시간·판매 수치에서 효과 확인 가능.
- 집·가방·광장 공간이 가득해도 뽑은 동료를 잃지 않음.
- 같은 10회 내 중복, 교환 획득, 연출 중 종료, 재접속에서 등록·조각·천장 일치.
- 편성 변경·상자 용량 감소·오프라인 복귀에서 자원 유실·이중 버프 없음.
- 기존 주민·장난감·한정·진행 중 퀘스트·천장이 있는 세이브 각각 이관 검증.
- 신규 동료 한 명 추가에 전용 작업 리깅 제작이 필요하지 않음.
