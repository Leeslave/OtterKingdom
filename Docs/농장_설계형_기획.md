## 0. 요약

- **지금**: 밭 씬에 밭 3개 × 고랑 3칸이 정해진 자리에 있고, 골드로 고랑을 열고, 농부가 다 자란 칸을 10초마다 알아서 수확 → **가방으로 바로**. 플레이어가 할 일 = 씨앗 고르기 · 버튼 누르기 ("딸깍").
- **바꿈**: 밭이 광장의 **농업 지역 블록 안**으로 들어오고, 플레이어가 그 땅에 **농장 부품을 놓아 설계**한다.
  - **밭 칸**을 하나씩 지음 (격자에 놓기)
  - **흙길**을 깔면 농부가 그 위에서 빨리 걷는다
  - **스프링클러** 둘레 밭은 빨리 자란다
  - 수확물은 농부가 **수확 상자**까지 들고 가서 넣는다 → 상자가 차면 플레이어가 거둬 간다 (가득 차면 농부가 쉰다)
- 농부가 **실제로 걸어 다니며** 일하므로 생산량 = 성장 시간 + **걷는 거리**. 밭 · 길 · 상자 · 스프링클러를 어디에 놓느냐가 효율을 바꾼다 = 설계의 재미.

```
 [밭][밭][밭]          농부: 다 자란 밭 → 수확 → 들고 → 가까운 상자 → 내려놓음 → 다시 심음 → 다음 밭
 [밭](💧)[밭]  ═══길═══ [상자]   💧 스프링클러 둘레 밭은 +25% 빨리 자람
 [밭][밭][밭]          ═ 흙길 위에선 1.6배 빨리 걸음
```

## 1. 농장 부품

| 부품 | 크기 (격자 칸) | 짓기 (임시) | 하는 일 |
|---|---|---|---|
| **밭 칸** | 2 × 2 | 골드 + 목재 · 30초 (건설 해달) | 작물 하나를 심는 단위. 레벨마다 지을 수 있는 수가 늘어남 (Lv.10 3칸 → Lv.13 9칸 → 이후 더) |
| **수확 상자** | 1 × 1 | 목재 | 농부가 수확물을 넣는 곳. 용량 20. 탭하면 가방으로. 가득 차면 농부가 그 상자엔 못 넣음 |
| **흙길** | 1 × 1 (이어 깔기) | 돌 조금 | 길 위에서 농부 걷기 1.6배 |
| **스프링클러** | 1 × 1 | 골드 + 돌 (+ 물결 철, 광산 개편 뒤) | 둘레 3×3 밭 칸 성장 +25% (겹치면 최대 +50%). 물 뿌리는 연출 |
| (2단계) 수레 · 창고 | 2 × 2 | | 상자를 자동으로 비워 가방 · 판매로 (수거 자동화 = 중반 보상) |
| (2단계) 허수아비 · 퇴비 · 벌통 | 1 × 1 | | 새 쫓기(수확 손실 방지) · 수확량 + · 꽃 · 꿀 |

- 부품은 **농업 지역 블록 안에만** 놓을 수 있다 (특성 건물 구역 제한과 같은 규칙).
- 놓는 방식은 꾸미기 모드 그대로 (격자 · 미리보기 · 회전 · 옮기기). 하단 바 "꾸미기"에 **농장** 탭.

## 2. 농부 (걸어서 일함)

1. 다 자란 밭 중 **가장 가까운 것**으로 걸어감 (길을 따라)
2. 수확 동작 (지금 리그 해달 수확 동작) → 작물을 들고
3. **가장 가까운 빈 자리 있는 상자**로 걸어가 넣음
4. 그 밭으로 돌아가 같은 작물을 다시 심음 (씨앗이 필요한 작물은 가방의 씨앗을 씀)
5. 할 일이 없으면 길 위를 거닐거나 쉼

- 상자가 모두 가득 → 농부 머리 위 "상자가 가득해요!" → 플레이어가 상자를 거두면 다시 일함.
- 걷는 속도: 흙 1.0 · 흙길 1.6. 밭 한 칸 순환 = 성장 시간 + 왕복 시간 → 상자에서 먼 밭은 손해.
- (2단계) 농부를 둘 이상 (주민 배치), 농부마다 맡을 밭 지정.

## 3. 수확 상자 · 거두기

- 상자 위에 작물 아이콘과 `12/20`. 탭하면 작물이 가방으로 날아감 (광산 개편과 같은 연출).
- 오프라인: 상자 용량까지만 쌓임 → "자주 와서 거두면 더 많이" (방치형 리듬). 상자를 늘리거나 2단계 창고로 해결.
- 가방이 가득하면 상자에 남음 (지금 밭의 "가방이 가득" 알림 대신).

## 7. 정할 것

1. **테스트 씬에서 먼저** 재미를 확인할지, 바로 본 게임 광장에 넣을지 (추천: 테스트 씬 → 본 게임)
2. 밭 칸 크기: 2 × 2 (작물 하나) 추천 / 1 × 1 (더 잘게)
3. 상자 거두기: 처음엔 손으로 탭 (추천), 자동 수거는 2단계 창고 보상
4. 밭 강화(지금 골드 강화): 스프링클러로 대체 (추천) / 둘 다 유지
5. 지을 때 시간: 밭 칸도 건설 해달이 짓는 시간 (추천, 30초) / 바로 생김

### 바뀌는 곳 (팀원 파일)

`FarmService` · `PlotRuntime` · `SaveData.PlotSaveData` · `FarmerOtterController` · `PlotView` · `FurrowSlotView` · `GameManager` 밭 부분 · `OfflineProductionService` · `Farm.unity` → 본 게임 단계에서 팀원과 먼저 이야기. 테스트 씬 단계는 팀원 파일을 건드리지 않음.

## 10. QA 고침 (2026-10-18, Claude)

| 문제 | 고침 |
|---|---|
