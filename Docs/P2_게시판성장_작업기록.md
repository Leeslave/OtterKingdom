## 3. 구조

### 부탁 (`BoardRequestDefinition`)

| 칸 | 뜻 |
| --- | --- |
| `_category` | `Main`(늘 보임) / `Resident`(선택. 관리 해달이 맡은 뒤 `ResidentRequestSlots`(2)만큼) |
| `_contentVersion` | 0 = P0·P1, 2 = P2. 정착 진행 전 세이브(`CompleteAll`)는 `LegacyContentVersion`(1) 이하만 완료로 옮김 |
| `_assignRole` | 역할 부탁: 이 관리 역할을 맡기면 완료 |
| `_completionTask` | 주민 작업 부탁: 이 작업의 실제 완료 기록으로 완료 (비용 0 가짜 건설 아님) |
| `Action` | 건설 / 전문 해달 배치 / 역할 / 주민 작업 — 채운 칸으로 정해짐. 둘 이상 채우면 `None` + 경고 (`IsValidAction`) |

기존 에셋은 새 칸이 없어도 기본값(메인 · 0 · 비움)이라 행동이 바뀌지 않는다.

### 새 데이터

| 에셋 | 내용 |
| --- | --- |
| `ManagementRoleDefinition` (`Roles/Role_board_manager`) | 역할 ID, 맡을 해달(또박이), 근무 자리 ID `station_board`, 필요 발전 `board_upgraded`, 결과 발전 `receptionist_assigned`, 대사 |
| `MilestoneGroupDefinition` (`Groups/Group_town_council`) | 큰 부탁: 보이는 발전 `guild_office_built`, 단계 = 부탁 5개 (따로 저장하지 않고 부탁 기록에서 계산) |
| `SettlementConfig` P2 칸 | 게시판 발전 3개, 회관 발전, 주민 부탁 칸 수, 역할·큰 부탁 목록 |

### 규칙 (순수 C#, `Settlement/Model`)

| 클래스 | 하는 일 |
| --- | --- |
| `SettlementRoleRules` | 역할을 맡길 수 있는지(만남 + 앞선 발전 + 빈 역할 + 해달이 다른 역할 없음), 맡기기(한 번만) |
| `SettlementBoardRules` | 게시판 등급(기본·보강·관리·길드), 부탁 탭 구역·칸 규칙(진행 중·메인은 늘 보임, order → ID 고정 정렬), 큰 부탁 단계 |
| `SettlementMigration` | 버전 옮기기(한 번만), 기록 맞추기(끝낸 작업·맡긴 역할은 있는데 부탁이 안 끝났으면 조용히 끝냄) |
| `SettlementRules` | 주민 작업 부탁은 작업 중이면 "진행 중", 완료 발전 = 건설 결과 / 역할 결과 / 작업 결과, `FindCurrent`는 메인만 |
| `SettlementRegionRules.CanWork` | 역할을 맡은 해달은 주민 작업에서 빠짐 (건설·전문 해달과 같이) |

### 조율 (`SettlementManager`)

- `TryAssignRole`: 역할 저장 → 도감 등록(한 번) → `OnRoleAssigned` → 역할 부탁 완료(팝업) → 저장
- 주민 작업이 끝나면 그 작업의 부탁을 완료 (`OnTaskFinished`의 둘째 인자 = 다른 팝업이 대신 알림)
- `GetLaborSummary`: 정착 주민 / 보낼 수 있는 후보 / 지금 보낼 수 있음 / 작업 중. "보낼 수 있음"은 작업 화면과 같은 `CanAssign`으로 셈
- `RequestOpen` · `RequestMilestone` · `RequestTownHall`: 화면 요청만 알림 (UI는 presenter가 엶). GameManager에는 UI·역할 분기를 넣지 않음
- 관리 해달은 `SpecialNpc` 그대로 → 주민 수·노동력이 저절로 늘지 않음. 만남은 정상으로 셈

### 광장 (`SettlementPlazaView`)

- 방문 대기 줄 `VisitQueue` (G0-A). 이미 만난 해달·아무도 만난 적 없는 새 게임·옛 세이브는 바로 복원
- 역할을 맡은 해달: 근무 자리(`ManagementStationView`)로 걸어가 머묾, 씬을 열면 그 자리에서 시작 (`OtterWanderAgent.WarpToTask`)
- 광장 주민 작업(`PlazaTaskSiteView`)에 보낸 해달은 광장을 떠나지 않고 현장에서 일함 (개간 지역 작업은 예전처럼 길 끝으로 나감)
- 게시판 보강 = 같은 게시판 오브젝트의 그림 교체(`DevelopmentSpriteSwap`) → 탭·발자국·공사 중 사용 그대로
- 접수소 → 마을회관: 같은 부지, `DevelopmentGate._supersededBy`로 접수소는 회관이 생기면 숨김
- 시설 탭(`SettlementFacilityPropView`): 접수소 → 큰 부탁, 회관 → 발전 현황

### 화면

| 화면 | 내용 |
| --- | --- |
| 게시판 부탁 탭 | 기본·보강 등급은 예전처럼 한 목록. 관리 해달 뒤: "지금 할 부탁 / 주민들의 부탁 / 완료한 부탁" 구역. 접수소 뒤 맨 위 "마을 발전" 카드(큰 부탁 n/5, 회관 뒤 발전 현황) |
| 큰 부탁 (`MilestonePopupView`) | 단계 5줄(완료·진행 중·다음·아직), [가 보기] = 그 부탁의 기존 화면. 보상·수령 버튼 없음 |
| 마을회관 (`TownHallPopupView`) | 정착 단계, 마을 발전 n/m, 주민 현황 칩 3개, 지금 하는 일(건설 1 + 주민 작업 · 남은 시간), 다음 목표 [가 보기], 완료한 발전. 왕국 레벨과 섞지 않음 |
| 역할·주민 작업 부탁 카드 | 광장 밖이면 [광장으로], 광장이면 해달 비춤 / 작업 화면 |

## 4. 세이브

```text
SettlementSaveData
 ├ version   (P2 = 2. 없던 세이브 = 0 → 불러올 때 한 번 옮김)
 └ roles     roleId · otterId · stationId (깨진 줄·같은 역할 두 번·한 해달 두 역할은 버림)
```

- 게시판 등급·큰 부탁 단계·회관 여부는 저장하지 않음: 발전(`board_upgraded` · `receptionist_assigned` · `common_space_ready` · `guild_office_built` · `town_hall_built`)·끝낸 부탁·역할 기록에서 계산
- 옛 세이브: P0·P1 진행·생산·보상 그대로. `farm_working`이 있으면 P2 첫 부탁만 열림. 게시판·관리 해달·회관을 대신 주지 않음
- 정착 진행 전 세이브(`legacyComplete`): 콘텐츠 버전 1 이하 부탁만 완료 → P2는 처음부터
- 불러올 때 기록 맞추기는 팝업·보상 없이. 회관을 지은 뒤 다시 불러와도 완료 팝업이 다시 뜨지 않음
- 오프라인: 건설·주민 작업은 기존 UTC 완료 시각 그대로 (돌아옴 팝업 소식 한 번). 게시판·회관은 재화를 만들지 않음
- 요정 안내: `tutorialsDone`에 `FairyShop.Intro`(소개를 끝까지 봄, 완료 아님) 추가. 없는 세이브 = 안 봄

## 6. 아트 · 미실행 · 보류

- 그림: 또박이 얼굴·걷기 시트, 보강 게시판, 접수소, 마을회관, 아이콘 4개(보강·공동 공간·주변 정리·회관)는 GPT 그림 (`Tools/UIGen/p2_sources`).
  접수소 아이콘은 접수소 그림을 줄여 씀. 바닷가 벤치·공동 공간 의자는 기존 광장 소품. 접수소·회관 공사 단계 그림은 없음 (주춧돌 + 먼지)
- 또박이 광장 동작: 기본 걷기 + "Write"(클립보드에 쓰기) · "Wave". `OtterVisualController` 놀이 목록에 `Write` 추가
- 실행하지 않음: 새 게임부터 P0·P1·P2 끝까지 한 번에, 건설 중·역할 이동 중 앱 종료, 실기기 터치 영역(배치 모드 화면이 640×480 가로라 강조 위치는 캡처에서 어긋나 보임)
- 밸런스: 비용·시간은 지시서 6.1 제안값. 회관까지 메인 합계 2,200G · 목재 72 · 돌 42 (+ 선택 200G · 8 · 4). 반복 획득: 목재 = 광장 나뭇가지·사과나무, 돌 = 광장 바위·채굴, 골드 = 판매. 실측 플레이 시간은 재지 않음
- 기본 등급 게시판은 예전처럼 끝낸 부탁이 위에 쌓이는 한 목록 (지시서 표의 "기본: 기존 유지")
