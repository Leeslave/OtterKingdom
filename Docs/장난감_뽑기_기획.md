# 보물 조개 뽑기 (장난감 뽑기)

- 작성: choiwoohyck (+ Claude), 2026-10-07, `feature/Settlement`
- 한 줄: 요정이 바다에 띄워 보낸 **보물 조개**를 해달이 배 위에 올려 돌로 깨면 장난감이 나온다. 장난감을 광장에 두면 그걸 좋아하는 해달이 놀러 온다 (P4 "해달 얻기는 장난감으로" 그대로).
- 열리는 때: 요정이 광장에 온 뒤 (요정 상점과 같은 조건, `FairyAccess.IsShopOpen`). HUD 오른쪽(안내 띠 아래)에 뽑기 버튼.
- 수치는 모두 **임시**. 플레이 실측(분석 로그 `gacha_pull`) 뒤 조정한다.

## 1. 배너

| | 픽업 "봄바람 픽업" | 상시 "바닷가 보물 조개" |
|---|---|---|
| 기간 | 2주 (지금 2026-10-07 ~ 10-20, 기기 날짜) | 늘 |
| 나오는 것 | 상시 12종 + 픽업 3종 (벚꽃 바람개비 에픽 · 꽃잎 연 · 나비 모빌 레어) | 흔함 6 · 레어 4 · 에픽 2 |
| 확률 | 에픽 3% (픽업 1.5%) · 레어 15% (픽업 7.5%) · 흔함 82% | 에픽 2.5% · 레어 15% · 흔함 82.5% |
| 레어 확정 | 10회 안에 레어 이상 1개 | 같음 |
| 에픽 확정 | 60회째. 픽업이 아니었으면 다음 에픽은 픽업 확정 | 80회째 |
| 천장 이월 | 다음 픽업으로 이어짐 | 상시끼리 |
| 별빛 포인트 | 1회 1점, 100점 → 벚꽃 바람개비. 픽업이 끝나면 남은 점수는 반짝 조각으로 | — |
| 값 | 조개 30 / 10회 300, 별빛 조개권 1장 = 1회 | 조개 30 / 300, 보물 조개권 1장 = 1회, **하루 한 번 골드 뽑기** (1,000 + 800 × 왕국 레벨) |

- 뽑기권이 있으면 뽑기권부터 쓴다 (버튼 색: 뽑기권 초록, 조개 연보라, 골드 겨자). 골드 조개는 늘 골드 (위 뽑기권 칸에 가진 골드가 보임).
- 처음 열면 요정의 선물: 별빛 조개권 1장 + 보물 조개권 1장 (한 번).
- 확률 공개(확률형 아이템): 화면의 [확률 정보]에 장난감별 확률과 확정 규칙. 표의 확률은 천장 없이 한 번 뽑을 때 값.

### 골드 조개 (골드 소모처, 2026-10-09 추가)

늘 열려 있는 세 번째 탭. 조개 · 뽑기권 없이 **골드로만**, 하루 제한 없이 1회 · 10회.

| | 골드 조개 |
|---|---|
| 나오는 것 | 상시의 흔함 6 · 레어 4 (에픽 2종은 뺌) + **가구 6** (작은 덤불 · 그루터기 의자 · 통나무 의자 · 나무 벤치 · 가로등 · 피크닉 매트, 흔함) |
| 확률 | 레어 10% (각 2.5%) · 흔함 90% (12종 각 7.5%, 가구 합 45%) · **에픽 없음** |
| 레어 확정 | 10회 안에 레어 이상 1개 (10회 뽑기에 레어 1개). 천장은 골드 조개끼리 |
| 값 | 1회 = **500 + 250 × 왕국 레벨**, 10회 = 1회 × **9** (한 번 공짜) |

| 왕국 레벨 | 1회 | 10회 |
|---|---|---|
| 5 | 1,750 | 15,750 |
| 10 | 3,000 | 27,000 |
| 15 | 4,250 | 38,250 |
| 19 | 5,250 | 47,250 |

값을 이렇게 잡은 이유 (임시):
- **레벨에 따라 오름**: 수입이 레벨과 함께 늘어서 고정 값이면 후반엔 소모처가 안 됨. 하루 한 번 골드 뽑기(1,000 + 800 × Lv)와 같은 방식이고, 그보다 싸게 (그쪽은 에픽 2.5%가 있는 조개 뽑기 확률)
- **1회 기대값보다 조금 비쌈**: 가구 평균 상점 값 ≈ 1,100, 흔함 장난감 ≈ 800(축구공), 레어 10% (조개 30 ≈ 하루 골드 뽑기 값으로 치면 수천 골드). 골드를 "모아 두는 것보다 쓰는 게 즐거운" 정도로, 상점에서 바로 사는 것보다는 비싸게
- **레어 장난감을 골드로 얻는 길**: 지금 레어 장난감(작은 북 · 비눗방울 · 다이아몬드 연 · 퍼즐)은 조개로만 얻음. 골드 10회 = 레어 하나 확정 → 레어 해달 방문 조건을 골드로 채울 수 있음
- **에픽은 빼서** 조개 뽑기의 값이 떨어지지 않게
- 10회 = ×9: 한 번에 많이 쓰게 (조개 뽑기는 ×10 그대로)
- 겹친 장난감 · 가구도 가방에 들어가고 반짝 조각 덤 (흔함 1 · 레어 5)은 같음. 별빛 포인트 · 교환소 목록에는 넣지 않음

## 2. 겹친 장난감 · 교환소

- 겹친 장난감도 가방에 들어간다 (광장에 여러 개 둘 수 있음) + **반짝 조각 덤**: 흔함 1 · 레어 5 · 에픽 30.
- 최대 보유 수(99)에 걸려 못 넣으면 그 몫까지 조각으로.
- 교환소: 상시 레어 60 · 상시 에픽 300 · 지난 픽업 장난감 600 (기간이 끝난 픽업 배너 에셋을 남겨 두면 자동으로 나옴). 지금 픽업 장난감은 별빛 포인트로만.

## 3. 연출

| 순서 | 1회 |
|---|---|
| ① | 파도가 조개를 오른쪽에서 실어 와 해달 배 위로 퐁 (쉬던 해달 → 돌을 든 해달) |
| ② | 톡톡 세 번 (화면 아무 데나) → 금이 한 단계씩 길어지고 그 사이로 빛이 샘. 빛 색 = 등급 (하양 · 파랑 · 금, 픽업 에픽은 벚꽃 금빛) |
| ③ | 승급: 빛이 한 단계 오르면 번쩍 + 조개가 그 등급 조개로 바뀜. 에픽 = 밤바다(별), 픽업 에픽 = 벚꽃잎. 에픽 30% 하양→파랑→금 · 50% 파랑→금 · 20% 처음부터 금, 레어 35% 하양→파랑 |
| ④ | 쩍: 떨림 → 번쩍 · 빛 고리 → 금을 따라 반쪽이 양옆으로 → 장난감이 빛살과 함께 튀어 오름 (놀란 해달) |
| ⑤ | 결과 카드: 등급 · NEW · 픽업, 설명, "광장에 두면 ○○이 놀러 와요" (한정 해달은 얼굴), 겹치면 조각 +n, [확인] [한 번 더] |

- 10회: 해달 10마리 뗏목(3-4-3) → 한 번 톡 → 차례로 열림 (가장 좋은 것은 마지막) → 에픽이 나왔으면 그 조개를 1회 연출로 한 번 더 (두드리기는 저절로) → 결과 10칸 + [10회 더].
- 결과는 **연출 전에** 값을 치르고 가방에 넣고 저장한다 (연출 중 앱을 꺼도 다시 뽑을 수 없음).
- [건너뛰기]·Android 뒤로 가기 = 결과로 바로. 연출 중에는 알림·방문 연출이 기다림 (`PresentationGate`).

## 4. 한정 해달 살랑이

- `SettlementOtterDefinition._favoriteToy` = 벚꽃 바람개비. 좋아하는 장난감이 **광장 격자에 놓여 있을 때만** 장난감 방문 후보가 되고, 가중치 ×20이라 거의 먼저 온다 (장난감 등급은 보지 않음). 나머지 장난감 해달 규칙은 그대로.
- 얼굴 그림은 새것(`Assets/Art/Otter/ICON_Otter_Sallang.png`), 광장 모습은 임시 (기존 해달 프리팹 + 분홍 색).

## 7. 만들기 · 주의

- Build Global UI 한 번이면 데이터 + 화면이 만들어진다.
- 뽑기 화면만 고쳤을 때는 `Tools/Gacha/Rebuild Gacha Screens`: 전역 UI 프리팹 안의 뽑기 화면 · 확률 · 교환소 · 연출 · HUD 버튼만 새로 만들어 바꾼다 (정착 데이터는 건드리지 않음).
- **주의**: Build Global UI는 정착 설정을 처음 상태로 다시 만들어 P3·P4 데이터(장난감 해달 · 영토 · Lv.10~15 부탁)가 빠진다 (원래 있던 동작). 돌린 뒤에는 `Tools/Settlement/Apply P3 Projects`를 다시 실행하거나 정착 설정 에셋을 되돌리고 `Tools/Gacha/Add Limited Otters To Settlement`.
