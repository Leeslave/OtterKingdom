## 0. 요약

하단 네비게이션 바(도감 · 퀘스트 · 꾸미기 · 가방 · 이동), "어디로 갈까?" 이동 팝업, 씬 전환(화면이 어두워졌다 밝아지는 페이드)을 만들었다. **광장 · 밭 · 낚시터 어느 씬에서든 자동으로 뜬다.** 가방 화면도 이 전역 UI 안에 들어 있어서, 지난번 부탁(가방 UI를 게임 씬에 붙이기)도 같이 해결된다.

**부탁할 것은 2장이다.** 꼭 필요한 건 (1) 광장에 매니저 배치, (2) 이동 전 저장 두 가지다.

---

## 1. 동작 방식

### 1.1 전역 UI를 띄우는 두 가지 방법

`Assets/Resources/GlobalUI.prefab` 하나를 `GlobalUIRoot`가 `DontDestroyOnLoad`로 유지한다. 씬을 옮겨도 하나만 남는다.

1. **씬에 프리팹을 직접 배치** (편집 모드에서도 보임)
   - 씬을 옮겨 두 번째 `GlobalUI`가 깨어나면, 자식들이 깨어나기 전에 스스로 꺼지고 사라진다 (`[DefaultExecutionOrder(-300)]`). EventSystem이 겹치지 않는다.
   - 지금은 `InventoryTestScene`에만 배치되어 있다.
   - **장소 씬(`Plaza`, `Farm`, `Fishing`)에도 나중에 배치할 예정이다.** 지금 그쪽이 씬을 수정 중이라 충돌을 피하려고 이번에는 넣지 않았다. 작업이 끝나면 어느 쪽이 넣을지 따로 이야기하자.
2. **배치하지 않은 장소 씬 → 자동 생성** (안전장치)
   - 씬이 열릴 때 전역 UI가 아직 없으면 프리팹을 만든다. 조건:
     1. 지금 씬이 장소로 등록되어 있다 (`Zone_*.asset`의 씬 이름과 같다).
     2. `InventoryManager.Instance`, `CurrencyManager.Instance`가 있다. 없으면 경고 로그를 한 번 남기고 만들지 않는다.
   - 첫 씬의 `Awake`가 모두 끝난 뒤(`RuntimeInitializeLoadType.AfterSceneLoad`)에 만든다.

**이번 작업에서 장소 씬 파일(`Plaza.unity`, `Farm.unity`, `Fishing.unity`)은 건드리지 않았다.**

### 1.2 씬 이동 순서 (`SceneNavigator`)

```
이동 버튼 → 장소 카드 선택
→ 화면을 검게 (0.25초)
→ SceneNavigator.BeforeLeave        ← 옛 씬이 아직 살아 있음. 저장은 여기서
→ SceneManager.LoadSceneAsync(씬 이름)
→ SceneNavigator.Arrived(zone)      ← 새 씬의 Awake/OnEnable 이후
→ 화면을 밝게 (0.3초)
```

- 둘 다 `static event`라서 게임 쪽은 **`SceneNavigator`를 찾거나 부를 필요 없이 구독만** 하면 된다.
- 구독한 쪽에서 예외가 나도 이동은 계속된다 (예외는 로그로만 남김). 화면이 검은 채로 멈추지 않게 하기 위해서다.
- 이동 중에는 화면을 덮은 검은 막이 입력을 막는다.

### 1.3 장소 데이터

`Assets/Scriptable Obejects/Navigation/`

| 에셋 | 이름 | 씬 | 상태 |
|---|---|---|---|
| `Zone_Plaza` | 광장 | `Plaza` | 이용 가능 (기획대로 "마을" → "광장"으로 표기) |
| `Zone_Farm` | 밭 | `Farm` | 이용 가능 |
| `Zone_Fishing` | 낚시터 | `Fishing` | 이용 가능 |
| `Zone_Mine` | 광산 | (없음) | 잠김, "준비 중" 표시 |

광산 씬이 생기면 `Zone_Mine`에 씬 이름을 넣고 "이용 가능"을 켜면 된다. 코드는 바꿀 필요 없다.

### 1.4 Build Settings (합의된 내용)

`Plaza`(0번, 게임 시작 씬), `Farm`, `Fishing` 순서로 등록했고, 기존 `SampleScene`은 맨 뒤에 남겨 두었다.

## 2. 부탁할 것

### (1) 광장 씬에 매니저 배치 — 필수

`Plaza.unity`에는 `CurrencyManager`, `InventoryManager`가 없다. **이게 없으면 광장에서 네비게이션 바가 안 뜨고**, 광장이 시작 씬이라 다른 곳으로 이동할 방법이 없다.

- `Farm`, `Fishing`과 같은 방식으로 두 매니저를 배치해 달라.
- `InventoryManager`의 설정은 `Assets/Scriptable Obejects/Inventory/InventoryConfig.asset`.

### (2) 이동 전에 저장 — 필수

지금 `GameManager`는 앱 일시정지·종료 때만 저장한다. 씬을 옮기면 저장 없이 `GameManager`가 사라진다.

```csharp
private void OnEnable()  => SceneNavigator.BeforeLeave += SaveNow;
private void OnDisable() => SceneNavigator.BeforeLeave -= SaveNow;
```

- `BeforeLeave`는 화면이 완전히 어두워진 뒤, 옛 씬이 살아 있을 때 불린다.
- `InventoryManager`, `CurrencyManager`는 씬이 바뀌어도 남으므로 가방·재화 값은 그대로 이어진다. 저장이 필요한 건 씬에 묶인 상태(밭 슬롯, 낚시 진행 등)다.

### (3) 다른 장소에 있는 동안의 생산 — 담당 확인

`Docs/미구현기능_정리.md`에 적힌 대로, `GameManager`가 씬마다 있어서 **광장에 가 있는 동안 밭의 시간 진행과 자동 저장이 멈춘다.** 이제 씬을 오갈 수 있으니 생산 로직을 씬에서 분리하는 작업이 필요하다. 이 부분은 그쪽 설계에 맡긴다.

### (4) 화면 아래쪽 겹침 확인

- 네비게이션 바는 화면 아래쪽을 차지한다: 1080×1920 기준 바닥에서 약 **214**, 가운데 꾸미기 버튼은 약 **270**까지 올라온다 (Safe Area 여백은 별도).
- 이 영역의 터치는 네비게이션 바가 먼저 받는다. 게임 쪽 `OnGUI` 임시 창이나 화면 아래쪽 월드 오브젝트(밭 슬롯 등)가 가려지지 않는지 확인해 달라. 필요하면 카메라 위치나 배치를 조정해야 한다.

### (5) EventSystem과 캔버스 순서

- 장소 씬에는 EventSystem이 없어서 **GlobalUI가 EventSystem(`InputSystemUIInputModule`)을 가지고 다닌다.** 장소 씬에 EventSystem을 추가하지 말아 달라 (두 개가 되면 경고가 뜨고 입력이 꼬인다).
- GlobalUI 캔버스의 `sortingOrder`는 **100**이다. 장소 씬에 uGUI 캔버스를 추가한다면 100보다 작게 두어야 네비게이션 바 아래에 그려진다.

## 3. 참고 (지난 답변에 대한 회신)

- **감자 판매가**: `ItemDefinition` 값(15)을 따르는 것으로 확정. `CropDefinition`의 판매가 필드는 더 이상 판매에 쓰이지 않으니 정리해도 된다.
- **판매 불가 아이템**: `ItemDefinition.IsSellable`을 추가했다 (`feature/Inventory` `9621aaa`). 모종 3종은 `false`다.
  - `TrySell`, `SellAll`은 판매 불가 아이템을 이미 걸러낸다 (`TrySell`은 `false` 반환).
  - 게임 쪽의 `seed_` 접두어 필터는 지금도 같은 결과를 내지만, `item.IsSellable`로 바꾸면 데이터만으로 판매 여부를 정할 수 있다.
- **아이템 3개 추가**(오이, 고구마, 쓰레기)는 이쪽에서 따로 작업한다.
