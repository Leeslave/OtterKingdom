# 광산 심층과 마을 연동 구현

2026-10-20

## 플레이 흐름

1. 선착장 수리(`fishing_dock`) 후 기존 3층 관문을 통과하면 4층에 진입할 수 있다.
2. 처음 4층에 들어가면 주민 건강 사건이 시작된다. 광장 농장 성장 속도가 10% 감소한다. 접속하지 않아도 증상이 추가로 악화되지 않는다.
3. 마을로 돌아오면 또박이 알림과 게시판·마을회관의 부탁에서 사건을 이어간다.
4. 부탁 수락 후 요정 상인의 첫 지원 약초 10개를 무료로 받는다. 가방에 공간이 필요하다. 추가 약초는 요정 상점에서 10개에 100G로 판매한다.
5. 약초 10개를 납품하면 의사 다온이가 주민으로 합류하고 임시 진료를 시작한다. 성장 속도 감소가 5%로 완화된다.
6. 왕국 Lv.18, 해님 금 곡괭이로 4층 관문을 열고 5층에 진입한다. 5층 상자에서 최종 곡괭이 재료를 얻을 수 있으므로 최종 곡괭이가 없어도 진입과 재료 수집이 가능하다.
7. 임시 진료를 시작한 상태에서 왕국 Lv.20, 별빛 다이아 곡괭이로 5층 발생 돌을 파괴한다. 성장 속도는 정상화되고 발생원은 다시 생기지 않는다. 5층 자동 채굴도 열린다.
8. 광장 꾸미기 건물 목록에서 마을 병원(2,000G·돌 30개·2분)을 건설한다. 이어 마을 길드(3,000G·돌 40개·3분)를 건설한다.
9. 부탁 화면에서 밀봉된 조각을 요정 나라에 인도하면 사건이 끝난다. 조각은 별도 가방 아이템이 아닌 일회성 이야기 인도 상태로 관리한다.

## 구현 범위

- 4·5층 지도, 광맥, 상자, 층별 관문과 최종 발생 돌.
- 각 층 클리어 시 해당 층의 일반 광맥이 자동 채굴 대상에 추가된다. 일반 광맥은 희귀도와 무관하게 포함하며 유물·별도 희귀 드롭은 제외한다.
- 건강 효과는 광장 농장 성장 속도에만 적용한다.
- 게시판과 회관에서 같은 진행 상태를 사용한다.
- 병원과 길드는 실제 배치·공사 가능한 별도 건물이다. 기존 회관을 대체하지 않는다.
- 상태는 통합 저장의 `mineMaze.community`에 보관한다. 약초 수령·납품·발생원 제거·답례를 반복 처리하지 않는다.
- 기존 광산 저장 파일은 통합 저장에 광산 상태가 없을 때 처음 방문하며 이관한다.

## 검증

- 격리된 Unity 6000.3.8f1 프로젝트에서 `MineMazeTests` EditMode 테스트 **57개 통과**.
- 검사 범위: 지도 연결, 층 해금, 최종 재료 접근, 발생원 파괴 조건, 약초 정확한 소비, 중복 처리 방지, 저장 복원, 오프라인 비악화, 자동 채굴, 인벤토리 이관.
- 런타임 및 테스트 C# 프로젝트 빌드 통과.
- 실제 전체 게임 화면에서 시작부터 건설 완료까지의 수동 플레이 검증은 아직 하지 않았다.

## 임시 표현

- 병원·길드 건물, 의사 초상화, 약초 아이콘은 기존 아트를 재사용한다. 전용 아트는 후속 작업이다.
- 주민 개별 기침 애니메이션이나 신규 대화 연출은 없으며, 알림·부탁 화면·농장 상태 문구로 표현한다.
