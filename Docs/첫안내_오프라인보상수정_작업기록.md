## 1. 첫 안내와 밭 강조

기획서 4.2 "첫 안내는 '당근을 심어 볼까?' 한 문장과 해당 밭 강조"를 구현했다.

### 동작

| 항목 | 내용 |
|---|---|
| 언제 뜨나 | 농장 씬에서, 아직 한 번도 심은 적이 없을 때 |
| 말풍선 | 화면 위쪽(높이 75%)에 "당근을 심어 볼까?"가 위아래로 살짝 흔들림 |
| 밭 강조 | 밭 1(`PlotView`)과 그 위의 빈 칸(`FurrowSlotView`)이 노란빛으로 깜빡임 |
| 입력 | 말풍선은 클릭을 막지 않음. 떠 있어도 밭을 누를 수 있음. 팝업이 열리면 말풍선은 그 아래로 가려짐 |
| 언제 끝나나 | 작물 선택 창에서 무엇이든 처음 심는 순간. 말풍선과 강조가 사라지고 저장됨 |
| 다른 씬 | 낚시·광산 씬에서는 뜨지 않음. 밭 1의 `PlotView.Start`가 `GameManager.ShowFirstPlantGuide()`를 부르는 구조라 밭이 있는 씬에서만 뜸 (낚싯대 강화 버튼과 같은 방식) |

- 문구는 "당근"이지만 다른 작물을 심어도 안내가 끝난다. 당근만 인정해야 하면 `GameManager.PlantFromPrompt`의 조건을 바꾸면 된다.
- 해달이 자동으로 다시 심는 것(`HarvestSlot`)은 안내를 끝내지 않는다. 플레이어가 직접 심어야 끝난다.

### 저장

- `SaveData.firstPlantGuideDone`: 처음 심으면 `true`.
- **옛 세이브 처리**: 이 필드가 없던 세이브는 불러올 때 한 번만 검사한다. 이미 심긴 칸이 있거나 판매 기록(`lifetimeSales > 0`)이 있으면 안내를 건너뛴다.
  - 처음에는 이 검사를 로드할 때마다 해서, 개발용 창에서 값을 꺼도 다시 `true`가 됐다. 그래서 `schemaVersion`을 도입해 한 번만 검사하게 바꿨다 (1 → 2. 이후 존 튜토리얼 작업에서 3으로 올라감).
  - 새 세이브는 처음부터 최신 버전이라 검사하지 않는다.

### 테스트 방법

메뉴 **OtterKingdom > Dev > Offline Test** 창의 "튜토리얼" 항목에서 **첫 안내 다시 보기**를 누른다.

- Play 중: 바로 말풍선이 뜨고 밭이 깜빡임
- Play 밖: 세이브 파일의 값을 바꿔서 다음 Play 때 뜸

## 2. 오프라인 보상 수정

### 보상 창이 겹치던 문제

- 증상: 오프라인 보상 창이 떠 있는 상태에서 다시 자리를 비웠다 돌아오면 창이 하나 더 떴다.
- 수정: 새 보상 창을 띄울 때 먼저 떠 있던 보상 창을 닫는다. 가장 최근 창 하나만 남는다 (`GameUI.ShowOfflineReport`).
- 다른 팝업(작물 선택 등) 위에 보상 창이 뜨는 동작은 그대로다.

### 3분 이상 비웠을 때만 오프라인 생산

- 자리를 비운 시간이 3분(180초)보다 짧으면 오프라인 생산을 돌리지 않고 보상 창도 띄우지 않는다 (`GameManager.RunOfflineProduction`).
- 앱을 껐다 켤 때와 백그라운드에서 돌아올 때 모두 적용된다.
- 기준은 GameManager 인스펙터의 **Offline > Min Offline Absence Sec**(기본 180)에서 바꾼다.
- **바뀐 규칙**: `오프라인자동수확_작업기록.md`에는 "다 채우지 못한 시간은 세이브에 남아 짧게 여러 번 꺼도 누적된다"고 되어 있다. 이제 3분 미만의 부재는 오프라인 생산에서 아예 빠지고 누적되지 않는다. 3분 이상이면 전처럼 남은 시간이 이월된다.
- 밭에 직접 심은 작물은 전처럼 비운 시간만큼 자란다. 3분 기준은 오프라인 농사 등록 작물, 낚시, 광산, 해달 방문에만 해당한다.

### 테스트 방법 (아직 안 함)

1. 오프라인 농사나 낚시가 켜진 상태(레벨 2 이상)로 Play한다.
2. 1~2분만 백그라운드에 두고 돌아온다 → 보상 창이 뜨지 않아야 한다.
3. 3분 넘게 두고 돌아온다 → 보상 창이 뜬다. 닫지 않고 다시 3분 넘게 두고 돌아온다 → 창이 하나만 있어야 한다.
4. 앱 종료 후 재실행은 Offline Test 창의 "-10분" 버튼으로 확인한다.

## 4. 아직 안 한 것

- 기획서 4.2의 "첫 튜토리얼 작물 1회만 10초 생산"
- 3분 기준과 보상 창 교체의 플레이 모드 확인
- 작업 트리에 커밋 안 된 존 튜토리얼(`Assets/Scripts/Tutorial/`, 씬별 첫 방문 안내)이 있다. 농장 존 튜토리얼이 남아 있으면 첫 안내는 그 튜토리얼이 끝난 뒤에 뜨도록 연결되어 있다. 이 문서의 범위는 아니다.
