# 밭 해금 / 재파종 / 작물 변경 / 작물 추가 / 판매 UI 작업기록 (2026-09-28)

> 이후 낚시터 작업에서 이름이 바뀐 것: `FarmUI` → `GameUI`, `GameManager.SellCrop/GetCropQuantity` → `SellItem/GetItemQuantity`, 판매 버튼 "작물 판매" → "판매", 목록 제목 "[현재 작물]" → "[보유 아이템]". 아래는 현재 이름 기준으로 적음.

## 결정 사항
- **밭 해금**: 밭 1은 기본 오픈, 밭 2·3은 잠김. 잠긴 밭을 누르면 "밭 N 해금에 100 코인이 필요해요" 팝업이 뜨고, 확인을 눌렀을 때 코인이 100 이상이면 차감하고 활성화함. 모자라면 "코인이 부족해요!". 밭 2·3도 슬롯은 3칸.
- **씨앗**: 당근·오이는 무제한(Permanent). 감자·고구마는 소모형(Consumable)이고 테스트용으로 **5개씩** 지급. 슬롯 1칸을 심을 때마다 1개 차감(플레이어가 심든 해달이 다시 심든 동일).
- **재파종**: 해달이 수확 애니메이션을 마치면 같은 작물을 그 자리에 바로 다시 심음. 씨앗이 없으면 빈칸으로 두고 "감자의 모종이 없습니다!" 팝업을 띄움(같은 문구는 동시에 1개만).
- **플레이어가 직접 심을 때**: 작물 선택 팝업에 "감자 (남은 씨앗 3)"처럼 표시. 0개인 작물을 누르면 같은 "모종이 없습니다!" 팝업.
- **해달 담당 범위**: 해달 1마리가 해금된 모든 밭을 돌봄. 플레이 중에 해금된 밭도 이벤트로 자동 등록(인스펙터 목록에 바로 보임).
- **작물 변경**: 심어진 칸(성장 중·수확 대기 모두)을 누르면 "작물을 변경하시겠습니까?" 팝업. 수확 대기 칸이면 주황색 경고 문구 추가. "예"를 누르면 칸만 비움(씨앗 환불 없음). 새 작물은 플레이어가 빈칸을 다시 눌러서 심음.
- **판매 UI**: 화면 오른쪽 아래 판매 버튼 → 보유 목록(이름 : n개 [판매]) → 판매 창(가격, 보유 개수, `판매할 개수 ▼ [입력칸] ▲ [전체]`, 합계). 개수는 1~보유 개수로 제한, 보유 0이면 [판매] 비활성화. 판매 대금은 재화 시스템(Gold)으로 들어감.
- **디버그 패널의 "전체 판매"**: 새 판매 UI와 별개로 일단 유지("나중에 생각").

## 사용자가 할 일
1. Farm.unity를 열고 `OtterKingdom > Tools > Setup Plot Unlock` 실행 → 씬 저장. 밭 3개에 `PlotView` + 트리거 콜라이더가 붙고, 밭 2·3 아래에 Plot_1과 같은 배치·크기로 `Slot_0/1/2`가 생김. (이걸 안 하면 밭 2·3을 해금해도 해달이 돌볼 슬롯이 없음.)
2. 새 작물 3종은 GameManager의 `cropDefinitions`에 **Farm.unity 텍스트를 직접 수정해서** 등록해 둠. 씬이 열려 있었다면 Reload.

### 세부 동작
- **잔액 체크**: Gold 에셋의 `MinCapacity`가 `int.MinValue`라서 `CurrencyManager.TrySpend`만으로는 잔액이 마이너스로 내려감. `TryUnlockPlot`은 잔액을 먼저 직접 확인함. 기존 `TryUpgrade`(농사 강화)에는 아직 이 확인이 없음.
- **옛 세이브 호환**: 밭이 1개뿐인 세이브는 불러올 때 잠긴 밭 2·3이 추가됨. 소모형 작물은 세이브에 항목이 없을 때만 초기 씨앗을 지급하고, 0개가 된 항목은 그대로 두므로 다시 지급되지 않음.
- **해달 앵커 등록**
  - `Start`: 해금된 밭 중 목록에 없는 밭은 씬의 `FurrowSlotView`(plotIndex가 같은 것)를 찾아 등록.
  - 플레이 중 해금: `FarmService.PlotUnlocked` → 같은 방식으로 등록.
  - 기존에 손으로 연결한 `slotAnchors`(밭 1)는 `FormerlySerializedAs`로 읽어서 새 목록의 밭 0 항목으로 옮김. 손으로 만든 항목은 덮어쓰지 않음.
- **수확 중 작물 변경**: 해달이 걸어가는 중이거나 수확 애니메이션 중에 플레이어가 칸을 비우면, `HarvestSlot`이 아무것도 수확하지 못하고 끝나며 재파종도 하지 않음.
- **팝업/클릭 충돌**: 팝업은 화면 전체를 덮는 반투명 블로커 위에 뜸. 팝업이 열려 있거나 포인터가 uGUI 위에 있으면 밭·슬롯 클릭을 무시함(`GameUI.IsBlocking`). Farm.unity에 EventSystem이 없어서 GameUI가 `InputSystemUIInputModule`로 하나 만듦.
- **판매 입력칸**: TMP InputField(숫자만, 6자리). 입력 중에는 합계만 갱신하고, 입력이 끝나면 1~보유 개수로 보정해서 칸에 다시 씀.

## 작물 그림 (오이·감자·고구마)
- 원본: 사용자가 준 AI 이미지 9장. 한 장에 같은 단계의 변형 3개, 검정 배경 + 초록 글로우.
  - 1 감자 새싹 · 2 고구마 씨앗 · 3 고구마 새싹 · 4 오이 다 자람 · 5 고구마 다 자람 · 6 감자 다 자람 · 7 감자 씨앗 · 8 오이 씨앗 · 9 오이 새싹
- 배경 제거: 처음엔 OpenCV(GrabCut + 매끈한 영역 제거)로 시도했지만 잎 사이 글로우 조각·잎 안쪽 구멍이 남아서, **rembg `isnet-general-use`** 모델로 교체. 임시 가상환경에서 돌렸고 프로젝트에 스크립트는 넣지 않음.
  - Windows 경로 길이 제한 때문에 `NUMBA_CACHE_DIR`를 짧은 경로로 지정해야 rembg가 import됨.
  - 남는 반투명 글로우를 없애려고 알파를 90~230 구간으로 다시 늘리고, 40px 미만 조각은 제거.
- 3개로 나누는 위치: 1/3 지점 ±80px 안에서 가장 빈 세로줄. 다 자란 그루는 잎이 1/3 경계를 넘어서 고정 3등분으로 자르면 잘림.
- 크기: 당근과 같은 기준으로 가로 폭 통일(씨앗 440 / 새싹 390 / 다 자람 512px). 임포트 설정은 당근 메타를 복사(PPU 104.5, 하단 중앙 피벗 등).
- 결과: `Assets/Art/Farm/Crop/crop_{cucumber|potato|sweet_potato}_{seed|sprout|grown}_{0|1|2}.png` 27장.
