## 0. 요약

도감 항목을 해금하면 그 항목의 **이야기(컷씬)** 를 볼 수 있게 된다. 아직 보지 않은 이야기는 **하단 바 도감 버튼과 도감 화면 곳곳에 N**으로 표시해서 보러 오게 만든다. 도감에서 그 항목을 누르면 **일러스트 컷 위에 대사가 한 줄씩** 나온다.

- 컷씬 1개 = 일러스트 1~3컷 + 대사 3줄, 약 10~15초. 언제든 건너뛸 수 있다.
- 말하는 해달의 얼굴이나 이름표는 띄우지 않는다. **일러스트 위에 대사만** 나온다.
- 해달들은 플레이어를 **플레이어 이름 + "님"** 으로 부른다 (기본 이름이면 "해달왕님").
- 지금 도감 항목 7개(채소 4, 어류 1, 해달 2)에 컷씬 7개를 만든다 (4장).
- 게임이 "해달을 구경하는 재미"를 목표로 하므로(상세기획서 2.1), 컷씬은 **해달의 성격과 습관**을 보여 주는 데 집중한다. 설명·튜토리얼 역할은 하지 않는다.

## 1. 흐름

### 1.1 해금 조건

| 항목 | 해금 조건 | 지금 코드와 다른 점 |
|---|---|---|
| 채소 (당근·감자·고구마·오이) | **밭에서 수확해서** 처음 얻었을 때 | 지금은 개수가 늘기만 하면 해금됨 (세이브 복원, 지급 등 포함) → 수확으로 한정 |
| 어류 (고등어) | **낚시로** 처음 얻었을 때 | 위와 같음 → 낚시로 한정 |
| 농부 해달 | **2레벨 달성** (첫 밭이 열리는 시점) | 지금은 해달을 도감에 등록하는 곳이 없음 |
| 낚시꾼 해달 | **10레벨 달성** | 위와 같음 |

- 모종을 사거나 받은 것은 해금 조건이 아니다 (모종은 작물이 아님).
- 이미 해금된 항목은 그대로 둔다. 해금 후 아이템을 팔거나 써도 다시 잠기지 않는다.

### 1.2 재생

```
항목 해금
   └─ 새 이야기 생김 (N)
        ├─ 하단 바 도감 버튼에 N
        └─ 도감 화면: 탭 · 슬롯 · 상세 화면에 N과 [이야기 보기 ▶]
             └─ 도감에서 그 항목을 누름 → 컷씬 재생
                  └─ 끝나면 상세 화면으로 돌아옴, N 사라짐, [다시 보기] 버튼 생김
```

- **재생은 도감에서 항목을 누를 때만** 일어난다. 해금되는 순간 게임 화면에 끼어들지 않는다 (상세기획서 9.2 "긴 연출을 기다려야 다음 행동을 할 수 없도록 만들지 않는다").
- 아이템을 팔거나 써도 이야기는 남는다. 해금과 이야기는 가방 상태와 무관하다.

### 1.3 보러 오게 만드는 표시

| 위치 | 표시 |
|---|---|
| 하단 바 도감 버튼 | 빨간 **N** 뱃지 (가방 버튼의 N과 같은 모양) |
| 도감 탭 (채소·어류·해달) | 안 본 이야기가 있는 탭에 작은 **N** |
| 도감 슬롯 | 오른쪽 위 **N** + 슬롯이 반짝이며 살짝 통통 튐 |
| 상세 화면 | 안 봤으면 설명 박스 아래 **[이야기 보기 ▶]** 버튼이 천천히 커졌다 작아짐. 봤으면 조용한 **[다시 보기]** |

- 해금된 항목을 도감에서 처음 누르면 상세 화면을 거치지 않고 바로 재생한다. 끝나면 그 항목의 상세 화면이 보인다.
- 컷씬을 끝까지 보거나 건너뛰면 **본 것으로 처리**한다.

## 2. 연출

### 2.1 화면 구성 (1080×1920)

```
┌──────────────────────────┐
│                  [건너뛰기 ▶▶]│  ← 오른쪽 위
│                            │
│  ┌──────────────────────┐  │
│  │                      │  │
│  │                      │  │
│  │     일러스트 컷        │  │  ← 960×640 (3:2), 크림 테두리 스티커 카드
│  │                      │  │     컷이 바뀔 때 부드럽게 넘어감
│  │ ┌──────────────────┐ │  │
│  │ │해달왕님! 이것 좀  │ │  │  ← 대사창: 일러스트 아래쪽에 겹친 반투명 크림 상자
│  │ │보세요!          ▼│ │  │     이름표·얼굴 없음, 글자가 한 글자씩 나옴
│  │ └──────────────────┘ │  │
│  └──────────────────────┘  │
│                            │
│          ● ● ○             │  ← 대사 진행 점 (3줄 중 몇 번째)
└──────────────────────────┘
```

### 2.2 조작

| 조작 | 동작 |
|---|---|
| 화면 아무 곳이나 탭 (글자 나오는 중) | 그 줄을 바로 끝까지 보여 줌 |
| 화면 아무 곳이나 탭 (줄이 다 나옴) | 다음 줄 (컷이 바뀌면 그림도 넘어감) |
| 마지막 줄에서 탭 | 컷씬 종료 → 상세 화면 |
| [건너뛰기] | 즉시 종료. 본 것으로 처리 |

### 2.3 연출 규칙

- 시작: 배경 딤 → 첫 컷 카드가 작게 시작해 살짝 튀며 커짐 (0.3초) + 효과음.
- 컷 전환: 0.25초 동안 겹쳐서 넘어감 (크로스페이드).
- 글자 속도: 초당 약 20자. 줄 끝에 ▼가 위아래로 까딱.
- 배경음은 끄지 않고 그대로 둔다 (소리 크기만 설정을 따름).
- 컷씬이 없는 항목은 지금처럼 상세 화면만 보인다.

### 2.4 대사 작성 규칙

- **한 컷씬에 3줄.** 한 줄은 대사창에 두 줄 이내 (약 30자, 이름이 들어가는 줄은 이름 길이만큼 여유).
- 1줄: 상황 → 2줄: 해달다운 행동이나 생각 → 3줄: **귀여운 마무리** (엉뚱함, 먹을 것 욕심, 졸림 등).
- 이름표가 없으므로 **누가 말하는지는 그림과 말투로** 알 수 있게 한다. 말하는 해달이 바뀌면 그 해달이 가운데 오는 컷으로 넘긴다.
- 플레이어는 말하지 않는다. 해달들은 플레이어를 **`{이름}님`** 이라고 부른다 (프로필 이름을 넣음).
- 실제 해달의 습성을 하나씩 넣는다 (배 위에 음식 올리고 먹기, 겨드랑이 주머니에 좋아하는 돌 보관, 손잡고 자기, 털 고르기 등).
- 게임 규칙 설명, 숫자, 보상 안내는 넣지 않는다.

## 5. 일러스트 제작 가이드 (AI 생성)

| 항목 | 기준 |
|---|---|
| 크기 | **1536×1024** (GPT 이미지 생성의 가로 크기 그대로. 화면에는 960×640으로 표시) |
| 비율 | 3:2 가로. **아래쪽 30%에 대사창이 겹친다** → 얼굴·손·중요한 물건은 위쪽 70% 안에 |
| 스타일 | 게임 UI와 같은 스티커풍: 코코아색(#4B2E22) 굵은 외곽선, 파스텔, 부드러운 명암. 배경은 인물보다 흐리고 채도 낮게 |
| 캐릭터 고정 | 3장 참고 그림을 **매번 참고 이미지로 넣어** 얼굴·몸 비율·의상을 맞춘다 (상세기획서 10.1). 한 컷씬의 컷끼리 옷·소품이 바뀌지 않게 같은 시드/참고로 연속 생성 |
| 글자 | 그림 안에 글자를 넣지 않는다 (AI가 만든 가짜 글자는 지움) |
| 파일 | `Assets/Art/Collection/Cutscenes/CUT_{항목ID}_{컷}.png` (예: `CUT_crop_carrot_A.png`) |
| 검수 | 손가락 수·꼬리·귀 위치 이상, 컷 사이 의상 차이, 외곽선 두께 통일 |

## 7. 구현 설계

| 부분 | 내용 |
|---|---|
| 데이터 | `CollectionStory` (ScriptableObject): 컷 목록(`Sprite`), 대사 목록(문장, 컷 번호). `CollectionEntry`에 `_story` 칸 추가 (비우면 이야기 없음) |
| 이름 넣기 | 대사의 `{이름}`을 재생할 때 `ProfileManager` 프로필 이름으로 바꿈 |
| 해금 — 채소·어류 | `CollectionAutoCollector`가 **수확(`Harvest`)·낚시(`Fishing`)로 늘어난 경우만** 해금 (테스트 지급 `Test`는 개발용으로 허용). 세이브 복원·모종 지급·구매로는 해금하지 않음 |
| 해금 — 해달 | `CollectionEntry`에 `_unlockLevel` 칸 추가 (0이면 레벨 해금 아님). 레벨이 오르면(`ProfileManager`) 조건을 채운 항목을 등록. 게임을 켤 때도 한 번 확인 (이미 레벨이 높은 세이브) |
| 저장 | 본 이야기의 항목 ID 목록을 도감 세이브에 추가 (`CollectionSaveConverter`). 옛 세이브는 "안 본 것"으로 시작 |
| 모델 | `Collection`에 `HasUnwatchedStory`, `IsStoryWatched(entry)`, `MarkStoryWatched(entry)`, 변경 이벤트 |
| 재생 화면 | `StoryPlayerView`: 전역 UI의 도감 화면 위 전체 화면. 컷 크로스페이드, 한 글자씩 출력, 탭 진행, 건너뛰기, 진행 점 |
| 도감 화면 | 탭·슬롯의 N, 슬롯 반짝임, 상세 화면 [이야기 보기 ▶] / [다시 보기], 안 본 항목을 누르면 바로 재생 |
| 하단 바 | 도감 버튼의 기존 뱃지(지금 꺼져 있음)에 `CollectionStoryBadgeView` 연결 (가방 N과 같은 방식) |
| 소리 | 시작 시 효과음 (`AudioManager.PlaySfx`, 지금은 임시 "띵") |
