# 통합 점검과 진행 흐름 개편 — 2026-10-24

최신 로컬 작업 기준. 이 기록은 9~10월 초의 `구현현황_정리.md`, `미구현기능_정리.md`보다 우선한다. **코드·데이터 반영과 자동 검증을 진행했으며, 실제 화면 플레이는 아직 완료하지 못했다.**

## 반영한 것

### 웹 저장

- 기존 작업 중이던 `WebFileSync` 연결을 보강했다. `FS.syncfs`가 실행 중이면 다음 요청을 합치고, 진행 중 추가 저장이 생기면 끝난 뒤 한 번 더 동기화한다.
- IndexedDB 비동기 오류가 발생해도 다음 저장 요청을 처리한다. 브라우저를 즉시 닫는 상황의 영속성까지 보장하는 검사는 아니다.
- 기존 폰트·패키지·빌드 설정 변경은 유지했다.

### 시설 진행 2차

기존 ID·건물·주민·완료 기록은 유지한다. 레벨·비용의 단일 조정 표는 `Tools/Progression/flow.json`이다. 에디터 생성 메뉴도 이 표를 적용한다.

| 시설 | 건설 가능 레벨 | 골드 | 목재 / 돌 | 공사 |
|---|---:|---:|---:|---:|
| 목공소 | 6 | 700 | 12 / 8 | 90초 |
| 채석 작업소 | 8 | 1,200 | 20 / 12 | 120초 |
| 농업 창고 | 11 | 2,000 | 40 / 20 | 180초 |
| 해달 상점 | 12 | 2,000 | 40 / 20 | 180초 |
| 건설소 | 14 | 4,000 | 70 / 40 | 240초 |
| 어업 작업소 | 16 | 6,000 | 80 / 60 | 360초 |
| 기록관 | 17 | 8,000 | 100 / 80 | 480초 |

- 작은 집 부탁을 회관 이후로, 꾸벅이·쿵쿵이 입주를 첫 영토 이후로 옮겼다. 목공소의 첫 실제 생산 기록이 데굴이 입주로 이어진다.
- 보들이는 농사 시작에 찾아오고 첫 수확 상자 수거 뒤 입주 부탁이 열린다. 콩콩이는 상점 이후, 퐁당이는 낚시 시작 이후에 연결한다.
- 시설 생산은 기존 자동 생산을 유지하되 **한가한 해당 특성 주민만** 참여한다. 전문 역할에 배치된 해달·관리 해달·다른 주민 작업·정찰·공사 중인 주민은 중복으로 생산하지 않는다.
- 목재·돌은 주민 한 마리당 시간당 60개. 첫 재료까지 약 1분, 한 마리의 8시간 생산량은 480개다. 정찰 파견으로 일손이 줄어도 이미 보관한 재료는 지우지 않는다.
- 스프링클러와 돌길은 건물 완공만으로 바로 열리지 않는다. 회관의 **일터 · 농장 설비**에서 Lv.13 이후 확장한다. 돌길은 흙길을 놓아 본 기록도 요구한다. 기존 세이브에서 이미 해금됐던 설비는 보존한다.
- 메인 체인 ID·경험치 합은 유지했다. Lv.7의 기존 광석 목표 하나를 지도 해달 회관 합류 목표로 바꿨다. 먼저 완료한 시설은 기존 기록 기반 목표로 인정한다.

### 섬 지도와 정찰

- 회관에 **섬 지도 · 정찰** 화면을 추가했다. 갱도에서 지도 해달을 얻고 회관을 마련하면 합류 기록이 열린다.
- 기존 첫 개간은 정찰을 기다리지 않는다. 그 이후 새로운 땅은 정찰 → 발견 → 기존 개간 → 영토 확장 미션 순서다.
- 동시에 한 정찰대, 정착 일반 주민 1~2명. 첫 깊이 90초, 이후 깊이 ×180초이며 재료 비용은 없다. 같은 방향의 이전 영토를 실제로 연 뒤 다음 깊이를 정찰한다.
- 정찰 주민은 기존 작업 상태에서도 바쁘므로 개간·쓸기·관리 역할 등과 중복 배정되지 않는다. 주민 수·특성·집은 유지한다.
- 정찰 시각·배정·발견·미확인 보고를 저장한다. 귀환 시 보고서를 열기 전에 주민을 해제한다. 재접속·보고 재열기로 발견을 중복 지급하지 않는다. 중도 회수는 발견 없이 종료한다.
- 남쪽 1단계 정찰로 바닷가를 발견하고 해당 땅의 개간·확장 미션을 마치면 기존 선착장 복구 부탁이 열린다. 새 흐름은 Lv.15 자동 발견을 사용하지 않는다. 회관에서 남쪽 경로를 안내한다.
- 기존 열린 땅·진행 중 개간은 발견 처리하고, 기존 낚시와 설비를 다시 잠그지 않는다. 레벨별 소모성 개간 기회 제한은 새 정찰 흐름에서 제거했다. 기존 레벨·개간 완료·납품 기록은 수정하지 않는다.
- 오프라인의 정찰·주민 작업·건물·게시판 공사 완료는 시간순으로 처리한다. 완료 직전까지 이전 노동 상태로 생산을 계산한 뒤 다음 구간을 계산한다. 생산 시간은 전체 복귀 구간에서 최대 8시간만 인정한다.
- 긴 화면은 안전 영역 안에서 스크롤하고 닫기 버튼을 고정한다. 뒤로 가기로도 닫힌다.

## 자동 검증

- 런타임, 에디터 도구, 전체 테스트 소스 C# 컴파일 확인. Unity Editor의 실제 임포트·실행을 뜻하지 않는다.
- 정찰 NUnit 규칙 11개: 귀환 한 번, 오프라인 복귀, 취소·재출발, 중복/바쁜 주민, 시간 역행·손상 기록·저장 복사 등.
- 실제 게임 어셈블리의 정착·정찰·생산 통합 NUnit 7개: 기존 작업 점유, 손상된 중복 배정 복구, 역할·방문객 제외, 저장 왕복, 생산 상한과 기존 재료 보존.
- 웹 동기화: 연속 100회 요청 합치기, 동시에 `syncfs` 하나만 실행, 마지막 변경 후속 동기화, 비동기 오류 후 재시도.
- 데이터 에셋 891개 참조 검사, 등록 퀘스트 284개 ID 중복·선행 조건 순환 검사, Lv.16~49 메인 존재 확인, 새 이야기 14단계·시설 7종과 진행표 일치, 사진관 도감 50% 조건 확인.
- 데이터 적용 도구를 다시 실행하면 변경 0건으로 유지된다.

재실행 방법: `Tools/Verification/README.md`.

## 아직 끝나지 않은 것

1. **Unity 실행 및 실제 플레이 QA**: 전체 EditMode 실행 시 현재 설치된 Unity 6000.3.8f1이 `No valid Unity Editor license found`로 종료했다. 라이선스 활성화 뒤 새 게임 → 첫 집 → 갱도·지도 → 목공소·채석 → 농사 → 설비 → 남쪽 정찰·선착장 → 낚시를 화면으로 검증해야 한다. UI 배치·터치·연출·동선은 미확인이다.
2. **실제 웹 빌드 저장 QA**: 새 빌드에서 연속 저장 → 새로고침 → 브라우저 재실행, 저장 직후 페이지 전환, 데이터 초기화·복구를 확인해야 한다. JS 모의 테스트 통과만으로 실브라우저 영속성을 확인한 것은 아니다.
3. **장시간 밸런스**: Lv.20~50 경험치·골드·조개 수입, 손낚시 대비 방치 수확, 가방 포화, 정찰·개간·생산을 함께 운영하는 체감 시간을 측정해야 한다.
4. **아트·사운드**: 특수 해달 전용 초상화와 정식 BGM·효과음은 이번에 교체하지 않았다.

변경은 로컬 작업 파일에 반영했다. 배포·머지는 하지 않았다.
