# 장소 튜토리얼 · 세이브 관리 구현 작업기록 (2026-09-30)

## 결정 사항
- **장소 튜토리얼**: 새 게임에서 광장·밭·낚시터·광산에 **처음 들어갈 때 한 번씩** 나온다. 본 곳(건너뛴 곳 포함)은 세이브에 기록하고 다시 나오지 않는다.
  - 화면 전체를 어둡게 덮고 설명할 대상만 뚫어서 반짝이는 테두리로 강조 + 말풍선에 설명.
  - 화면 아무 곳이나 탭하거나 [다음] → 다음 장. [건너뛰기] → 바로 끝(본 것으로 기록).
  - 튜토리얼 동안 월드·버튼 입력은 막지만 월드는 멈추지 않는다(해달이 돌아다니면 테두리가 따라감).
  - 가리킬 대상이 씬에 없으면 그 장은 자동으로 빠진다(예: 밭 Lv.2 전의 오프라인 농사 NPC, 잠긴 밭이 없을 때).
  - 밭은 튜토리얼이 끝난 뒤 기존 "당근을 심어 볼까?" 안내가 이어서 나온다.
- **기존 세이브는 튜토리얼을 보지 않는다**: 세이브 버전을 2 → 3으로 올리고, 버전 2 이하 세이브는 네 장소를 전부 본 것으로 처리. 요청이 "세이브가 없는 상황에서 시작하면"이었기 때문.
- **세이브 날리기/복구 (개발용)**: 파일을 지우지 않는다. 날리기 = 세이브 파일을 보관함으로 옮기기, 복구 = 보관본을 복사해 오기. 기존 저장 흐름의 "읽을 수 없는 파일은 지우지 않고 옮겨 둔다" 원칙을 그대로 따름.
  - 복구할 때 지금 세이브가 있으면 먼저 그것도 보관한다 → 어느 쪽으로 가도 진행 상황이 사라지지 않음.
  - 보관본은 복구해도 남는다 → 같은 상태로 몇 번이고 되돌릴 수 있음. 지우는 건 [삭제]를 눌렀을 때뿐.
  - 플레이 중에는 쓸 수 없음. 실행 중인 게임이 메모리의 상태를 30초마다/씬 이동 때 다시 저장해서 날린 게 바로 덮이기 때문.

## 사용법
- **세이브 날리기/복구**: `OtterKingdom > Dev > Save Files` (플레이를 멈춘 상태에서)
  - [세이브 날리기 (보관함에 보관)] → 다음 실행 때 새 게임(튜토리얼부터).
  - 보관함 목록의 [복구] / [삭제]. 목록마다 마지막 저장 시각, 왕국·밭·낚싯대 레벨, 누적 판매, 첫 안내 완료 여부를 보여 줌.
  - [세이브 폴더 열기]로 탐색기에서 확인 가능.
- **튜토리얼 다시 보기**: `OtterKingdom > Dev > Offline Test` → 튜토리얼 칸의 [장소 튜토리얼 다시 보기]
  - 플레이 중: 기록을 지우고 지금 장소의 튜토리얼을 바로 다시 보여 줌.
  - 플레이 밖: 세이브 파일의 기록만 지움(버전도 3으로 맞춰서, 불러올 때 다시 "전부 봄"으로 바뀌지 않게).
- 튜토리얼 문구·순서 수정은 `Scripts/Tutorial/ZoneTutorials.cs` 한 곳에서.

- 대상 위치를 읽으려고 접근자만 추가: `NavBarView`(버튼 5개), `TopBarView.ProfileArea`, `GameUI.RodUpgradeButton/PickaxeUpgradeButton`, `PlotView.PlotIndex`, `GameManager.GoldCurrency`.
- 입력 차단: 투명한 전체 화면 버튼이 뚫린 곳까지 포함해 모든 탭을 받는다. 밭 칸·요정·카메라는 원래 "UI 위를 눌렀으면 무시" 검사를 하고 있어서 따로 막는 코드가 필요 없었음.

### 시작 시점
1. `GameManager.Awake`: 세이브를 불러온 뒤 `zoneTutorialPending` 결정. 뷰들의 `Start`보다 먼저라서 밭의 `PlotView`가 첫 안내를 요청해도 튜토리얼 뒤로 미뤄짐.
2. `GameManager.Start` → 코루틴: 두 프레임 기다림(전역 UI 생성·첫 레이아웃) → 화면 밝아지기(`SceneNavigator.IsTraveling`)와 팝업(오프라인 보상, 세이브 손상 안내)이 끝날 때까지 기다림 → 시작.
3. 끝나거나 건너뛰면 `tutorialsDone`에 씬 이름 추가 → 저장 → 미뤄 둔 밭 첫 안내 표시.

### 보관함 구조
```
persistentDataPath/
  save.json, save.json.bak, ...            ← 지금 세이브
  save.json.snapshots/
    20260930-155900-wipe/                  ← [세이브 날리기]
    20260930-161200-before-restore/        ← 복구하면서 보관한 그때의 세이브
```
- `save.json`, `.bak`, `.tmp`, `.corrupt-*`를 전부 옮긴다. 손상된 세이브를 보관하면 손상 상태 그대로 되살아나서 세이브 오류 안내 흐름을 다시 테스트할 수 있음.

## 장소별 내용
| 장소 | 순서 |
|---|---|
| 광장 | 환영 → 왕국 정보(프로필) → 코인 → 조개 → 도감 → 퀘스트 → 꾸미기 → 가방 → 이동 → 요정 상점 → 해달 친구들(시작할 때 화면 가운데에 가장 가까운 해달) → 화면 끌기·확대 축소 → "밭으로 가 볼까요?"(이동 버튼) |
| 밭 | 밭 소개 → 밭고랑(밭 1, 심기·작물 바꾸기) → 농부 해달 → 잠긴 밭(번호가 가장 작은 것) → 오프라인 농사 NPC → 가방에서 팔기 → (이어서 "당근을 심어 볼까?") |
| 낚시터 | 낚시터 소개 → 낚시 자리 → 낚시 해달(멈추는 법) → 낚싯대 강화 버튼 |
| 광산 | 광산 소개 → 광산 입구 → 광부 해달(말풍선을 눌러 멈추기) → 곡괭이 강화 버튼 |

## 겪은 문제
- **세이브 창을 열면 `get_persistentDataPath is not allowed to be called from a ScriptableObject constructor`** → `SaveService`를 필드 초기화에서 만들고 있었음. 필드 초기화는 EditorWindow(ScriptableObject) 생성자 단계에서 실행되는데, 이때는 `persistentDataPath`를 부를 수 없음. `OnEnable`에서 만들도록 수정. 같은 에러 뒤에 나온 `Refresh`/`OnDisable`의 NullReference는 이 에러에서 이어진 것.
- **Gold의 `CurrencyID`가 `"Gold"`가 아니라 `"1"`** → 코인 칸을 ID로 찾지 않고 GameManager가 쓰는 Gold 에셋과 직접 비교. 조개는 `"Gem"`으로 찾음.
- 같은 때 콘솔에 뜬 `Invalid antiAliasing value (must be at least 1)`는 이번 작업과 무관(Game 뷰/카메라 렌더 설정 쪽 경고로 보임).

## 미확인 / 남은 일
- Unity 에디터가 열려 있어서 배치 모드 테스트가 막혔음. 튜토리얼 코드는 컴파일·플레이 확인이 필요하고, `SaveSnapshotTests`도 Test Runner에서 돌려 봐야 함.
- 대상이 화면 밖에 있으면(광장 카메라를 움직여 둔 경우) 강조 없이 가운데에 설명만 나옴. 카메라를 대상 쪽으로 옮겨 주는 기능은 없음.
- 튜토리얼은 설명만 한다. "직접 눌러 보세요"처럼 실제 버튼을 누르게 하는 단계는 없음.
- 설정 버튼은 아직 연결된 화면이 없어서 설명에서 뺐음.
- 글꼴은 GameUI와 같은 내장 `LegacyRuntime.ttf`. 실제 UI 아트가 생기면 교체.
- 세이브 날리기/복구는 에디터 전용. 플레이어용 "데이터 초기화"(설정 화면)는 없음.
