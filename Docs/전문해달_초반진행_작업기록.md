# 전문 해달 · 초반 진행 8개 피드백 작업기록

기준: `해달왕국_초반진행_8개피드백_구현지시서.md` / 브랜치 `feature/ContentFix`

> **내가 지역을 개척했기 때문에 새 해달이 찾아왔고, 내가 역할을 맡겼기 때문에 그 지역이 돌아가기 시작한다.**

## 0. 데이터·씬 (메뉴 실행 없이 바로 적용)

처음 버전은 데이터·씬을 에디터 메뉴로 만들게 되어 있어서, 메뉴를 실행하지 않으면 **새 코드 + 옛 데이터**로 돌았다
(밭이 새 이웃의 집 직후 바로 열리고, 농경지 개간은 광장 공사로 남음). 2차 수정에서 에셋·씬 파일을 저장소에 직접 넣었다.

| 종류 | 파일 |
| --- | --- |
| 새 에셋 | 해달 `Otter_Miner`(깡깡이)·`Otter_Farmer`(새싹이), 방명록 4개, 부탁 `req_assign_miner`·`req_assign_farmer`, 작업 `task_farm_till`, 지역 `Region_farm`, 도감 `Entry_OtterMiner`, 퀘스트 `Main_FirstCarrots`·`Main_Build_1~3` |
| 새 프리팹 | `Prefabs/Plaza/PlazaOtter_Miner` (광산 광부 클립(SpriteFrameAnimator)을 그대로 씀) |
| 고친 에셋 | 부탁 `req_mine_path`(광부 방문)·`req_neighbor_house`(밭 발견 문구)·`req_farmland`(밭 현장 개간, 농부 방문), 건설 `con_farmland`(비용 0·즉시), `Region_mine`, `task_mine_tidy`, `SettlementConfig`, 도감·퀘스트 DB, `Zone_Farm`(필요 발전 `house_2`), `Main_Otter_1·2`, 광부 아이콘 가져오기 설정(단일 스프라이트) |
| 씬 | `Farm.unity`에 `FarmClearing` (잡목 2·바위 2, 주민 정비 현장, 개간+농부 배치 전 밭·농부·오프라인 농사 해달 숨김). `Mine.unity` 광부 숨김 |

`Tools/Settlement/Apply Specialist Progression` 메뉴는 표를 고친 뒤 다시 만들 때만 쓴다 (같은 값으로 다시 씀).

확인할 때: 기존 세이브는 이미 진행된 것을 이어서 보여 주므로 새 게임으로 본다 (`OtterKingdom/Dev/Save Files`에서 세이브를 비움).

참고: 작업 화면의 안내 글이 비용 때문에 두 줄(비용 + 안내)이 될 수 있다. 자동 크기 조정으로 들어가지만, 좁아 보이면 `SettlementSetup.Tasks.cs`의 Note 높이를 늘리고 `Tools/Navigation/Build Global UI`를 다시 실행한다.

## 1. 바뀐 흐름

```text
[광산]
의자 완료 (Lv.2, 광산 발견) → 광산에서 나무·돌 직접 치움 → 주민 1명 "광산 주변 정리"(30초)
→ 광산 운영 · Lv.3 · 완료 팝업 "광부 해달이 광장에 찾아왔어요"
→ 광장: 팝업이 끝난 뒤 깡깡이가 광장 가장자리에서 걸어 들어옴 (= 처음 만남) · 카메라가 비춤 · 머리 위 "!"
→ 깡깡이를 누름: "광산에서 일하고 싶어요!" + [광산에 배치] 확인
→ 배치: 부탁 "광산에서 일할 친구" 완료 · 도감 등록 · 물감이·뚝딱이 방문 · 깡깡이는 길 끝으로 걸어 나감
→ 안내 띠 "광산에 가서 깡깡이의 일을 시작해요" → 광산: 입구·깡깡이 등장 → 광산 튜토리얼 → 끝(또는 건너뛰기) = 채굴 시작

[밭]
새 이웃의 집 완료 → 완료 팝업 "새 이웃의 집 완성! 몽실이가 마을 옆에서 밭을 만들 만한 땅을 발견했어요." (광산 발견과 같은 방식)
→ 부탁 "먹거리를 길러요" · 이동 메뉴 "개간되지 않은 밭" (그 전에는 잠김: "새 이웃의 집을 지으면 열려요")
→ 밭: 고랑·농부 없이 잡목·바위만 있음 → 직접 치움
→ 밭의 망치 표지판에서 주민 2명 "농경지 개간"(45초, 골드 200 · 목재 16 · 돌 10). 광장·게시판에서는 시작하지 않고 [가 보기]로 밭에 보냄
→ 밭 운영 · 완료 팝업 "농부 해달이 광장에 찾아왔어요"
→ 부탁 "농사를 지을 해달이 필요해요" (바로 생김) → 광장에서 새싹이와 대화 → [밭에 배치]
→ 밭: 고랑·새싹이 등장 → 밭 튜토리얼 → 끝 = 농사 시작 → 퀘스트 "첫 수확을 해봐요"(당근 3개)
```

## 3. 구조

### 전문 해달 상태 (`SpecialistState`, 세이브에 숫자로 저장)

| 상태 | 뜻 | 광장 | 일하는 곳 | 생산 |
| --- | --- | --- | --- | --- |
| NotArrived | 기록 없음. 찾아왔어도(주민 목록에 있음) 광장에 아직 안 나타남 = 방문 예약 | 다음 광장 방문 때 등장 | 없음 | 불가 |
| AtPlaza | 광장에서 처음 나타남 (만남 기록) | "!" + 배치 대화 | 없음 | 불가 |
| Assigned | 배치 저장됨 (주민 수에 들어감) | 걸어 나감 → 없음 | 보임 | 불가 (안내 전) |
| Working | 그 장소의 튜토리얼을 끝냄(건너뛰기 포함) | 없음 | 일함 | 가능 |

- 원본은 `SettlementSaveData.specialists` (otterId, state, regionId, workingSinceUtcTicks). 화면의 해달 오브젝트가 아님
- 상태는 앞으로만 감 (`Settlement.AdvanceSpecialist`): 배치 버튼 연타·씬 전환에도 한 번만
- 배치된 전문 해달은 주민 작업 후보에서 빠짐 (`SettlementRegionRules.CanWork`)

### 생산 조건 (`SettlementRegionRules.CanProduce` / `GameManager.CanProduceIn(zoneId)`)

지역이 운영 중 **그리고** 그 지역의 전문 해달이 거기서 Working. 아래가 모두 이것을 본다:
- 채굴: `TickMining`, `SetMiningActive(true)`, 오프라인 채굴
- 밭: 심기(`PlantFromPrompt`), 농부 수확(`FarmerOtterController`, `HarvestSlot`), 오프라인 농사·오프라인 농사 해달 표시
- 낚시터는 개간 지역이 없어 그대로 (늘 가능)

퀘스트: 수확은 `farm_working`, 채굴은 `mine_working` 발전이 열려야 보임 (지역의 `_productionDevelopment`. 일하기 시작할 때 열림).

### 데이터

| 에셋 | 바뀐 것 |
| --- | --- |
| `SettlementOtterDefinition` | `_workRegion`(있으면 전문 해달), `_collectionEntry`(배치하면 도감 등록), `_assignLine` |
| `DevelopableRegionDefinition` | `_productionDevelopment` (mine_working / farm_working) |
| `BoardRequestDefinition` | `_assignSpecialist` (배치 부탁: 건설 없이, 배치하면 완료) |
| `SettlementTaskDefinition` | `_requiredGold`, `_requiredItems` (시작할 때 냄. 작업 화면에 비용·모자란 것 표시) |
| `QuestDefinition` | `_item`(그 아이템만), `_constructions`(그 건물만), `_builderOnly` |

### 부탁 순서

`req_first_house` → `req_chair`(Lv.2) → `req_mine_path`(Lv.3, 광부 방문) → **`req_assign_miner`**(물감이·뚝딱이 방문) → `req_neighbor_house` → `req_farmland`(밭 현장 개간, 농부 방문) → **`req_assign_farmer`**

### 새 퀘스트

| ID | 제목 | 조건 | 레벨 | 보상 |
| --- | --- | --- | --- | --- |
| main_build_1 | 첫 보금자리 | 집 1채 (con_house_1·2) | 1 | 50골드 · 40exp |
| main_build_2 | 왕국을 가꾸는 손 | 건축물 2개 (집·의자) | 2 | 100골드 · 60exp |
| main_build_3 | 뚝딱뚝딱 | 건설 해달 참여 공사 1번 | 3 | 150골드 · 80exp |
| quest_first_carrots | 첫 수확을 해봐요 | 당근 3개 수확 (농부가 일해야 보임) | 1 | 30골드 · 30exp |

보상은 같은 레벨의 기존 퀘스트 수준. 기존 퀘스트 수치는 바꾸지 않음.

### 기록으로 세는 퀘스트 (소급)

`QuestManager.RefreshRecordGoals`: 새 해달 만나기 = 만난 해달 수(처음부터 함께한 첫 해달 몽실 제외), 건설 완료 = 끝낸 부탁의 건물 수.
불러오기·레벨업·보상 받기·정착 변화 때 다시 세어 `QuestLog.SetProgressAtLeast`로 **맞춤**(더하지 않음, 줄이지 않음, 받은 퀘스트는 그대로) → 퀘스트를 늦게 받아도 앞서 만난 해달·지은 집이 들어가고, 같은 기록을 두 번 세지 않으며 보상을 다시 주지 않는다.

### 만남 판정

광장(`SettlementPlazaView`)이 그 해달을 **처음 내보낼 때** = 만남 (`SettlementManager.Meet`). 찾아오기만 한 상태(다른 장소에 있음)는 만남이 아님. 도감은 바꾸지 않음 (도감 등록은 전문 해달을 배치할 때만).
새 해달은 완료 팝업·레벨업이 다 닫힌 뒤 광장 가장자리에서 걸어 들어온다.

## 4. 세이브 · 옛 세이브

- 새 필드: `settlement.specialists`, `settlement.metOtters` (옛 세이브는 빈 목록). 스키마 번호는 그대로
- 불러올 때(`SettlementManager.MigrateSpecialists`, 꺼 둔 동안 끝난 작업 처리 전):
  - 지역은 운영 중인데 그 전문 해달이 온 적 없음(이번 업데이트 전 세이브) → 바로 **Working** + 주민 + 만남 기록 + 배치 부탁 조용히 완료 (팝업·보상 없음). 하던 채굴·농사·오프라인 생산이 멈추지 않음
  - 정착 진행 전 세이브(모든 부탁을 끝낸 것으로 불러옴) → 배치 부탁이 끝나 있으므로 같은 처리
  - 새 흐름에서 찾아왔지만 아직 만나지 않은 해달은 그대로 (광장에서 만나야 함)
  - 옮긴 해달의 도감 등록은 도감을 불러온 뒤(`SyncSpecialistCollection`)
- 예전 방식의 농경지 개간 공사(뚝딱이)가 진행 중이던 세이브: 그 공사가 끝나면 부탁이 끝나고 농부가 찾아오는 새 흐름으로 이어짐
- 옛 세이브의 광산·밭은 하나하나 치운 기록이 없어도 장소 개척이 끝났으면 장애물을 보이지 않음 (`ClearingObstacleView.ZoneCleared`)
- 만남 기록: 옛 세이브는 비어 있음 → 다음 광장 방문 때 광장에 있는 해달이 모두 "처음 만남"으로 기록됨 (실제로 광장에 나타난 해달만. 오프라인 방문 흔적은 세지 않음)
- 요정 안내: 스키마 3 이전 세이브는 완료로 처리. 그 뒤 세이브는 광장에 요정이 있으면 한 번 보임 (상점을 먼저 열면 완료로 처리)

## 5. 확인한 것 / 못 한 것

- 주민 작업(광산 주변 정리·농경지 개간)은 그 장소의 망치 표지판에서만 시작한다. 게시판 카드·안내 띠는 그 장소에 있지 않으면 [가 보기]로 보낸다 (정비 중에는 남은 시간만 보여 줌)
- 직접 넣은 에셋·씬 검사: 새·고친 파일이 가리키는 GUID가 모두 프로젝트에 있음, `Farm.unity`의 내부 참조가 모두 이어짐, fileID 중복 없음
- 컴파일: 게임·에디터·테스트 어셈블리 모두 `dotnet build` 통과
- EditMode 테스트 `SpecialistTests` 18개 추가, `SettlementQuestTests` 갱신 — **Unity에서 아직 실행하지 않음** (에디터가 열려 있어 배치 모드로 돌릴 수 없었음)
- **플레이 모드 검증(A01~A15, B01~B13)은 아직 하지 않음.** 메뉴 실행 후 새 게임으로 광산 → 밭 순서 확인 필요
- 밭 장애물·정비 현장 좌표는 씬 좌표로 정함 (고랑 위). 화면에서 보고 `SettlementSetup.Specialists.cs`의 표를 고쳐 다시 실행

## 6. 보류

- 낚시 해달: 같은 구조(`_workRegion`)로 붙일 수 있게 했지만 이번에는 그대로 (처음부터 있음)
- 배치 확인은 기존 예/아니오 팝업을 씀 (전용 대화 화면 없음)
- 광부 광장 애니메이션은 걷기 그림만 (가지고 노는 동작 없음)
