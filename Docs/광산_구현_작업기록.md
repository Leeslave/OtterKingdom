# 광산 구현 작업기록 (2026-09-30)

## 흐름
- 평소: 광부 해달이 광산 앞 모래길을 돌아다님 (Idle ⇄ Walk, 낚시터와 같은 A* 이동).
- 입구 점선 타원 탭 → "채굴을 진행하시겠습니까?" → 예 → 해달이 타원까지 걸어감 → 터널 안쪽으로 걸어 들어가며 서서히 사라짐 → 해달은 숨고 입구 왼쪽에 **채굴 말풍선**(꼬리가 터널을 가리킴, 안에서 광부 해달 채굴 애니메이션 반복)만 표시.
- 말풍선 탭 → "채굴을 중단하시겠습니까?" → 예 → 말풍선이 사라지고 해달이 터널에서 서서히 나타나 타원까지 걸어나온 뒤 다시 배회.
- 걸어나오는 도중에 다시 채굴을 켜면 그 자리에서 되돌아 들어감.
- `SaveData.miningActive`에 저장. 채굴 중으로 저장됐으면 다음 진입 시 해달은 이미 안에 있고 말풍선부터 보임.

## 채굴 보상 (수치는 전부 임시, `MiningBalanceData`에서 조절)
- 해달이 안에 있는 동안 **15~30초마다 1개** 캠. 결과는 **다이아몬드 30% / 돌 70%**.
- 캔 것은 바로 가방에 들어가고, 말풍선 위로 그 아이템 아이콘이 튀어나와 올라가며 사라짐.
- 가방이 가득 차면 버리고 "가방이 가득 차서 캔 광석을 두고 왔어요." 알림 (가득 찬 동안 한 번만, 낚시와 같음).
- 다음 캐기까지 남은 시간은 저장하지 않음. 씬을 나가거나 중단하면 버려짐 (낚시 중이던 것과 같음).
- **곡괭이 강화** (광산 씬 왼쪽 아래 버튼): Lv.1 30%, 레벨당 +5%p, 최대 Lv.5(50%). 비용 100/200/400/800 코인. 저장: `SaveData.pickaxeLevel`. 퀘스트의 "업그레이드" 목표에도 셈 (`TransactionSource.PickaxeUpgrade`).
- **오프라인 채굴**: 곡괭이 Lv.2부터. 해달이 광산 안에 있지 않아도 됨 (낚시와 같은 규칙). 평균 간격 22.5초 × 4배 느림 = **90초마다 1개**, 확률은 곡괭이 레벨 그대로. 남은 시간은 `SaveData.offlineMiningProgressSec`에 이어서 쌓임. 복귀 팝업 "받은 것"에 같이 표시.
- 아이템: 다이아몬드 `ore_diamond` (희귀, 50코인), 돌 `ore_stone` (흔함, 1코인). 가방에 **광산** 탭 → **광석** 칩으로 들어감. 기존 판매 UI에서 같이 팔림.
- 가방 변화 사유 `ItemChangeReason.Mining` 추가. 퀘스트 "낚시" 목표(Catch)에는 세지 않음 — 채굴 전용 퀘스트 목표는 아직 없음.
- 도감에는 광석 탭이 없어서 등록되지 않음.

## 사용자가 할 일
1. `OtterKingdom > Tools > Setup Mine Scene` 실행 →
   - 채굴 데이터 생성(`MiningDataSetup`): `Assets/Data/Mining/MiningBalanceData.asset` (GameManager 프리팹에 연결), 카테고리 `Mining`(광산 탭)·`Ore`(광석 칩) → GlobalUI 프리팹과 InventoryTestScene의 가방 카테고리 목록에 추가, 아이템 `Items/Mining/다이아몬드`·`돌` → ItemDatabase에 등록. 이미 있는 에셋은 그대로 둠(가격 등 수정한 값 유지).
   - 광부 해달 시트 슬라이스 → `Assets/Prefabs/Mine/MinerOtter.prefab`, `Assets/Scenes/Mine.unity` 생성, Build Settings에 등록.
2. 이동 팝업의 광산 카드: `Zone_Mine.asset`을 씬 `Mine` / 이용 가능으로 바꿔 둠. 전역 UI를 다시 빌드할 때도 유지되도록 `GlobalUISetup`의 표도 같이 바꿨음.

## 구조
| 파일 | 역할 |
|---|---|
| `Scripts/View/MinerOtterController.cs` | 배회 + 입구 이동 → 터널 진입(페이드 아웃) → 숨김 / 중단 시 페이드 인하며 걸어나옴 |
| `Scripts/View/MineEntranceView.cs` | 점선 타원. 탭하면 시작 팝업, 채굴 중엔 숨김. `Inside` 자식 = 해달이 사라지는 지점 |
| `Scripts/View/MineEmoteView.cs` | 채굴 중 말풍선. 안의 해달은 SpriteFrameAnimator로 `Mine` 클립 반복, 말풍선은 등장 시 팝 + 위아래 흔들림. 탭하면 중단 팝업 |
| `Scripts/Data/MiningBalanceData.cs` | 광석 id, 캐기 간격, 다이아몬드 확률, 곡괭이 강화 비용, 오프라인 설정 (SO) |
| `Scripts/Mining/MiningService.cs` | 곡괭이 레벨/강화, 다이아몬드·돌 판정, 캐기 간격, 채굴 중 여부 (plain C#) |
| `GameManager.IsMiningActive / SetMiningActive` | 유일한 기준 플래그 (낚시의 `SetFishingActive`와 같은 방식) |
| `GameManager.AddMiningFind / TryUpgradePickaxe` | 캔 것 가방에 넣기(가득 차면 알림), 곡괭이 강화 |
| `Scripts/UI/GameUI.cs` | "곡괭이 강화" 버튼·팝업 추가 |
| `Scripts/Offline/OfflineProductionService.cs` | 오프라인 채굴 (`RunMining`) |
| `Editor/MineSceneSetup.cs` | 프리팹/씬 생성 메뉴 |
| `Editor/MiningDataSetup.cs` | 채굴 밸런스·카테고리·아이템 에셋 생성과 연결 (셋업 메뉴에서 호출) |
| `Tools/MineItems/make_stone_icon.py` | 임시 돌 아이콘 생성 (`Assets/Art/Item/Ore/Stone.png`) |
| `Tools/SpriteRepack/repack_miner_otter.py` | 원본 AI 시트 재패킹 (시트마다 셀 크기 따로) |

## 애니메이션
| 클립 | 시트 | 프레임 | fps |
|---|---|---|---|
| Idle | Mine | 0 | - |
| WalkRight/Left/Down/Up | Walk 행 0/1/2/3 | 0~7 | 10 |
| Mine (말풍선 안) | Mine | 0~7 | 8 |

- 전용 Idle 시트가 없어서 채굴 시트 0번(곡괭이 들고 선 옆모습)을 Idle로 씀. 왼쪽으로 걷다 멈추면 flipX.
- 재패킹: 낚시 해달과 같은 방식, 헬멧 노란색(≈250,190,80)으로 중심 검출, 높이(헬멧 위→발) 220px로 통일 → PPU 145에서 약 1.52유닛(낚시 해달과 같은 크기).
  - Walk 셀 212×272, 발 기준선 위에서 263px / Mine 셀 308×276, 기준선 265px (곡괭이 휘두르는 폭 때문에 따로 잡음).
  - 원본을 다시 받으면: `python Tools/SpriteRepack/repack_miner_otter.py <폴더(walk.png, mine.png)> <출력폴더>` 후 `Assets/Sprites/Characters/MinerOtter/`에 덮어쓰기. 셀 크기가 바뀌면 `MineSceneSetup.Sheets`도 수정.
- 말풍선 `mine_emote_bubble.png`: 받은 이미지를 테두리에 맞춰 자름(1231×858). 몸통 중심 (550,429), 꼬리 끝 (1226,433) — 그림을 바꾸면 `MineSceneSetup`의 `BubbleBodyCentrePx/BubbleTailTipSrcPx`도 맞출 것. 몸통 폭 2.4유닛, 안의 해달은 0.85배.

## 씬 배치 (배경 픽셀 기준, 원점 왼쪽 위)
- 배경 1024×1536, PPU 96, 카메라 ortho 8 (낚시터와 동일).
- 입구 타원(해달 발 위치): (585, 400), 폭 1.2유닛. 터널 안 사라지는 지점: (600, 325). 말풍선 꼬리 끝: (525, 265) — 말풍선은 입구 왼쪽 바위 위에 놓임.
- 이동 영역: 광산 앞 모래길 다각형 (`MineSceneSetup.WalkablePx`), 광차·울타리·바위를 피하고 아래로는 y=1150까지. clearance 0.25.
- 정렬 순서: 배경 0 / 타원 1 / 해달 2 / 말풍선 3 / 말풍선 안 해달 4.

## 미확인 / 남은 일
- Unity 에디터에서 셋업 메뉴 실행과 플레이 확인은 못 했음 (런타임·에디터·테스트 어셈블리 dotnet 빌드만 통과 확인). EditMode 테스트(`OfflineProductionTests`의 Mining_*, `QuestTests` 업그레이드)는 Unity Test Runner로 돌려야 함.
- 돌 아이콘은 임시 그림. 진짜 그림이 오면 `Assets/Art/Item/Ore/Stone.png`만 덮어쓰면 됨.
- 채굴 전용 퀘스트 목표, 광석 도감, 광석 종류 추가.
- `GameManagerPrefabSetup`의 씬 목록에는 광산을 넣지 않았음 (씬이 없을 때 열다가 실패하므로). 광산 씬은 셋업에서 GameManager 프리팹을 직접 배치함.
