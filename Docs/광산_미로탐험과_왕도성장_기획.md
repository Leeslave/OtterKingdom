- 표현 원칙: 장편 스토리나 대사집을 만들지 않는다. 주민 행동, 환경, 짧은 알림과 기능 해금으로 사건의 흐름을 암시한다.
- 표기: **확정**은 사용자가 명시한 방향, **제안**은 이를 성립시키기 위한 설계안, **미정**은 후속 결정이 필요한 항목이다.

## 1. 기획 목적과 분석

광산은 왕국 2레벨에, 밭은 10레벨에 열린다. 그 사이에 직접 할 거리를 제공하고, 밭이 열린 뒤에도 광산을 계속 탐험할 이유를 만든다. 첫 미로 발견 시점은 **5레벨**이다. 광산 사건 전체를 10레벨 이전에 끝낸다는 뜻은 아니며, 최하층 도달과 사건 해결 레벨은 미정이다.

**가스 이벤트는 낚시터 개방 이후에 시작한다.** 5레벨의 미로 발견과 질병 시작은 별개의 진행 단계다. 초기 미로에서는 탐험·직접 채광·곡괭이 성장에 익숙해지고, 낚시터가 열린 뒤 심층 개척 과정에서 마을의 질병 사건으로 이어진다. 낚시터 개방은 필수 선행 조건이며, 개방 즉시 가스 이벤트가 자동 발생한다는 의미는 아니다. 낚시터 개방은 **현재 게임의 흐름을 그대로 따른다**(왕국 Lv.15에 몽실이가 낡은 선착장 발견 → 선착장 수리 → 낚시꾼 해달 방문). 따라서 Lv.5~15는 미로 탐험·직접 채광·곡괭이 성장에 익숙해지는 구간이 된다.

**확정 — 게임 방향: 방치 + 상호작용.** 미로·돌·층 돌파가 들어오면서 100% 방치형 게임으로 두기는 어렵다. 앞으로는 **방치가 기본 수입을 맡고, 성장은 직접 하는 상호작용이 맡는** 방식으로 간다.

| 맡는 쪽 | 무엇 |
|---|---|
| 방치 (자동 · 오프라인) | 광부 자동 채굴, 밭 · 낚시 오프라인 생산, 꺼 둔 동안 정산. 돌파한 층이 늘수록 자동 채굴이 넓어짐 (4.9) |
| 상호작용 (직접) | 미로 길 찾기, 길을 막는 돌 · 층 돌파 거대한 돌 부수기, 보물 상자, 곡괭이 제작, 지금 개척 중인 층의 광석 |

- 방치만으로도 수입은 계속 들어오지만, 새 층 · 새 광석 · 다음 곡괭이 같은 **진행은 직접 해야** 열린다.
- 직접 한 결과(층 돌파)가 방치 수입을 키우는 쪽으로 돌아온다. 손으로 한 일이 꺼 둔 동안에도 남는다.
- 직접 하지 않는다고 불이익을 주지는 않는다 (질병도 가벼운 분위기, 5장). 한 번 들어와 2~5분 안에 끝나는 목표(돌 몇 개, 상자 하나, 계단 찾기)를 늘 하나 둔다.

기존 자동 채굴은 일상적인 생산을 맡고, 미로는 플레이어가 직접 개척하는 활동을 맡는다. 광맥 재료를 모아 곡괭이를 제작하는 성장과 왕국 레벨 성장이 함께 지하 진입을 결정한다.

광산 개척은 마을에도 영향을 준다. 지하에서 나온 가스 때문에 주민이 병들고, 이에 대응하며 약초 공급·의사·병원이 필요해진다. 원인을 제거한 뒤에는 의료 시설과 요정 나라와의 교역이 남는다. 이 과정을 통해 작은 마을이 주민을 돌보고 외부와 교류하는 왕도로 발전한다.

**이 기획의 핵심은 채광 보상을 늘리는 것뿐 아니라, 탐험 결과가 마을의 기능과 모습에 남도록 만드는 데 있다.**

## 2. 확정된 방향

| 구분 | 확정 내용 |
|---|---|
| 기존 해금 흐름 | 왕국 2레벨 광산, 10레벨 밭 |
| 첫 발견 조건 | 왕국 5레벨 이상 + 광산 업그레이드 1회 이상 + 광부해달이 채굴 중 |
| 광산 업그레이드 1회 | 곡괭이 강화 1회 = 광산 자동화(오프라인 채굴)가 열리는 곡괭이 Lv.2 (`MiningBalanceData.offlineUnlockPickaxeLevel`) |
| 돌 타격 수·재료 양 | MineRework 씬 규칙을 따름 (바위 체력 ÷ 곡괭이 힘, 콤보·치명타·반짝 광맥·희귀·화석, 광석 개수) |
| 구현 순서 | 지하 1층부터 테스트 씬으로 만들고, 테스트 후 이후 층을 다시 기획 |
| 발견 계기 | 광부해달이 채굴하다가 이미 개발된 광산 구역을 발견하고 알림·퀘스트 발생 |
| 발견된 구역 | 광산 카트와 채굴 흔적 등 누군가 먼저 사용했던 증거가 있음 |
| 미로 조작 | 플레이어가 직접 탐험하고 직접 채광. 자동사냥·자동 탐험 콘텐츠가 아님 |
| 미로 시점 | 일인칭 시점의 던전 탐험 맵. 참고: 「마법학교 아스티넬」 탐험 영상 (https://www.youtube.com/watch?v=odles77wNdI) |
| 광맥 배치 | 참고 영상에서 몬스터가 나오는 자리에 광맥이 나옴. 전투는 없음 |
| 광맥 형태 | MineRework 씬처럼 거대한 돌이 앞을 가로막고, 플레이어가 클릭해서 부숨 |
| 미로 이동 | 플레이어가 매번 앞·뒤·왼쪽·오른쪽 중 갈 방향을 선택하여 한 칸씩 이동 |
| 맵 구조 | 「마법학교 아스티넬」의 수정 광산·왕성 지하 던전 지도처럼 통로 칸으로 이루어진 격자 미로. 시작점·도착지가 있고, 지정된 자리에 돌(광맥)과 보물 상자가 놓임 |
| 보물 상자 | 채택. 참고 지도의 보물 상자 자리처럼 미로 곳곳에 배치 |
| 돌 재생 | 부순 돌은 약 1분 뒤 같은 자리에 다시 생김 |
| 층 돌파 | 계단을 내려가면 거대한 돌이 길을 막고 있음. 아주 많이 클릭해 부숴야 다음 층이 열림. **일회성** (한 번 부수면 다시 생기지 않음) |
| 자동 채굴 확장 | 층을 돌파할 때마다 그 층에서 나오는 광석이 광부 자동 채굴에 추가됨 |
| 게임 방향 | 완전 방치형이 아니라 방치 + 상호작용. 방치는 기본 수입, 진행은 직접 (1장) |
| 뚫은 길 | 한 번 부숴서 뚫은 자리는 돌이 다시 생겨도 무시하고 지나갈 수 있음. 재생된 돌은 길을 막지 않고 캘거리로만 남음 |
| 나가기 | UI의 나가기 버튼을 누르면 미로 어디서든 바로 밖으로 나감 |
| 탐험 중 마을 | 미로 체류 생산은 퇴장 시 일괄 정산하고 기존 오프라인 보고 화면으로 표시. 실제 미접속 감속과는 별도 검토 (4.5) |
| 재입장 | 나갔다가 다시 들어오면 층 입구에서 시작 |
| 층 수 | 약 5층 |
| 게임 안 지도 | 처음 1~2번은 지도 없이 탐험. 이후 지도 해달이 자동 해금되어 마을에 정착하고, 탐험에 따라와 지도를 만들어 줌 |
| 채광 방식 | 현재 MineRework 방식처럼 광맥을 두드려 재료 획득 |
| 장비 성장 | 미로에서 재료 수집 → 상위 등급 곡괭이 제작 → 특수 광맥 채굴 |
| 지하 확장 | 왕국 레벨과 곡괭이 등급을 모두 충족해야 더 깊은 층 진입 |
| 가스 | 깊이 내려갈수록 광산에서 나오기 시작하여 마을로 퍼짐. 가스 자체는 시각적으로 보이지 않음 |
| 가스 이벤트 시점 | 낚시터 개방 이후. 낚시터가 열리기 전에는 가스로 인한 발병·능력치 하락이 시작되지 않음 |
| 낚시터 개방 | 현재 게임 그대로: 왕국 Lv.15 선착장 발견 → 수리 → 낚시꾼 해달 방문 |
| 질병 | 환각이 아니라 가스 노출로 병듦. 주민 간 전염은 아님 |
| 마을 영향 | 아픈 주민이 늘어나고 능력치가 다소 떨어지지만, 생산 감소는 치명적이지 않음 |
| 질병 체감 | 마을회관에서 또박이가 "요즘 아픈 해달들이 많아졌네요" 하고 걱정하는 정도. 플레이에 큰 영향을 주지 않음 (마을 길드는 아직 없음, 14장) |
| 대응 기능 | 상인 해달이 요정 상인에게 부탁 → 요정 상점 약초 해금, 마을회관 게시판에 약초 채집 부탁 추가, 의사 해달 등장 |
| 근본 해결 | 최종 단계 곡괭이로 최하층의 가스 발생 돌을 파괴하여 가스 생성 중단 |
| 사건의 유산 | 가스 발생원 제거 후 정식 병원 설립과 함께 마을회관이 **마을 길드**로 커짐, 약초 지원에 대한 보상으로 요정 나라에 가스 블록 수출 |
| 게시판 성장 | 게시판 → 마을회관(접수 창구 합침) → (가스 질환 해결 뒤) 마을 길드. 마을 길드가 열던 것은 마을회관이 엶 (14장) |
| 장기 방향 | 광산을 계속 확장하고 플레이할 이유를 제공하며, 마을이 서서히 왕도의 모습을 갖추게 함 |

이전 대화에서 제시한 3~4레벨 첫 미로 개방안은 채택하지 않는다. 이후 사용자가 정한 **5레벨 발견 조건**을 기준으로 한다.

## 3. 전체 진행 구조

| 단계 | 플레이어의 행동·조건 | 마을에서 드러나는 변화 | 상태 |
|---|---|---|---|
| 광산 생활 | 2레벨 광산 해금, 채굴과 업그레이드 | 광부의 일상적인 채굴 | 확정 |
| 오래된 갱도 발견 | 5레벨·업그레이드·채굴 조건 충족, 조사 퀘스트 | 광부 발견 알림, 미로 입구 개방 | 확정 |
| 미로 개척 | 일인칭으로 이동, 길을 막는 돌을 클릭해 부숨, 재료 수집·곡괭이 제작 | 새로운 광물과 사용 흔적 발견 | 확정 |
| 심층 진입과 가스 사건 | 낚시터 개방(Lv.15 선착장 수리) 이후, 왕국 레벨·곡괭이 등급을 갖추고 사건 대상 심층 구역 개척 | 아픈 주민 증가, 마을회관의 걱정. 가벼운 능력치 저하 | 선행 조건 확정, 발생 층·세부 계기 미정 |
| 치료 준비 | 약초 확보와 관련 퀘스트 | 요정 상점 상품, 마을회관 게시판 부탁, 의사 등장 | 확정, 세부 순서 미정 |
| 발생원 제거 | 최종 곡괭이 제작, 최하층 돌 파괴 | 가스 생성 중단 | 확정 |
| 마을 회복 | 남아 있는 환자 치료, 주민 일상 복귀 | 건강과 작업 효율 회복 | 방향 확정, 절차 제안 |
| 왕도 기반 정착 | 병원 설립, 마을 길드로 넓히기, 가스 블록 인도 | 의료·교역 기능이 남고 마을회관이 마을 길드가 됨 | 확정, 설립 시점·운영 미정 |

발견 퀘스트는 세 조건을 처음 함께 충족했을 때 발생하도록 제안한다. 5레벨이 되는 순간에 채굴 중이 아니어도, 이후 조건을 갖추면 받을 수 있어야 한다. 최초 발생 이후 채굴을 중단했다고 이미 받은 퀘스트나 미로 접근을 취소하지 않는 방향을 제안한다.

## 4. 미로 탐험과 곡괭이 성장

### 4.1 두 가지 광산 플레이

| 활동 | 역할 | 자동화 범위 |
|---|---|---|
| 기존 광부 채굴 | 평소의 자원 생산과 광부 활동. 돌파한 층의 광석이 차례로 더해짐 (4.9) | 방치 (자동 · 오프라인) |
| 미로 탐험 | 길 개척, 광맥 발견, 직접 채광, 심층 진입 | 플레이어가 직접 수행 |

미로를 열었다고 기존 광부 채굴을 없애는 기획은 아니다. 자동 채굴에는 **이미 돌파한 층**의 광석만 들어가고, **지금 개척 중인 층**의 광석은 직접 캐야 한다 (4.9). 그래서 다음 곡괭이 재료는 늘 미로에서 직접 얻게 되고, 자동 채굴은 지나온 층의 재료를 꾸준히 대 준다.

### 4.2 반복 플레이의 기본 순환

**길 탐색 → 채굴 가능한 광맥 발견 → 직접 두드려 재료 수집 → 상위 곡괭이 제작 → 이전에 못 캐던 광맥 채굴 → 진입 조건을 갖춘 다음 층 개척**

- 특수 광맥은 현재 곡괭이로 캐지 못하더라도 발견할 수 있게 하여 다음 목표를 보여주는 방향을 제안한다.
- 채굴 가능 여부는 곡괭이 등급으로, 다음 층 진입은 왕국 레벨과 곡괭이 등급의 동시 충족으로 판단한다.
- 다음 곡괭이에 필요한 필수 재료는 현재 접근 가능한 층과 현재 곡괭이로 얻을 수 있어야 한다. 제작할 장비가 있어야만 그 장비 재료를 캘 수 있는 순환 잠금을 금지한다.
- 왕국 레벨 조건을 기다리는 동안에도 기존 층에서 재료 수집·미탐색 구역 탐험의 의미가 남도록 설계한다.
- 시점(일인칭), 이동(전·후·좌·우 선택), 맵 구조(아스티넬식 격자 미로), 약 5층 구성은 확정했다(4.4, 4.7). 게임 안 지도는 지도 해달이 맡는다(4.6). 층별 크기와 탐험 시간은 미정이다.
- 미로에는 전투가 없다. 참고 영상의 몬스터 자리를 광맥(길을 막는 돌)이 대신한다. 보물 상자는 채택한다(4.4).

### 4.3 기존 MineRework에서 가져올 부분

기존 테스트 씬에는 광맥 타격, 광석 종류, 재료 기반 곡괭이 제작, 층별 채굴 등급과 손맛 연출이 정리되어 있다. 이번 기획은 그 **광맥 타격과 재료 수집 방식을 미로 안의 직접 활동으로 옮기는 방향**이다.

층 수는 이번 논의에서도 약 5층으로 정했지만(4.7), 기존 문서의 층별 구성, 곡괭이 이름, 제작 비용, 광맥 재생 시간, 콤보·대박 수치는 이번 기획의 확정 수치가 아니다. 특히 기존의 곡괭이 중심 층 해금에 왕국 레벨 조건을 함께 적용하도록 재검토해야 한다.

### 4.4 일인칭 미로와 길을 막는 돌

**확정:** 미로는 일인칭 시점의 던전 탐험 맵이다. 참고 영상(「마법학교 아스티넬」)처럼 통로를 따라 앞으로 나아가며 탐험한다. 영상에서 몬스터가 나오는 자리에 **광맥이 나온다.** 광맥은 MineRework 씬처럼 **거대한 돌이 앞을 가로막는 형태**이고, 플레이어가 클릭해서 부숴야 지나갈 수 있다.

즉 미로의 한 번의 조우는 "적과 싸운다"가 아니라 **"앞을 막은 돌을 두드려 부수고 재료를 얻은 뒤 길을 연다"**이다. 채광과 길 개척이 같은 행동이 된다.

**확정 — 이동:** 플레이어가 매 칸마다 **앞·뒤·왼쪽·오른쪽** 중 갈 방향을 선택해 한 칸씩 나아간다. 자유 이동이 아니라 선택형 칸 이동이다.

**확정 — 맵 구조:** 참고 게임의 수정 광산·왕성 지하 던전 지도처럼, 통로 칸이 이어진 **격자 미로**로 층을 구성한다. 지도에는 시작점과 도착지가 있고, 참고 지도의 몬스터 상자 자리에 해당하는 지정 위치에 돌(광맥)이, 보물 상자 자리에 **보물 상자**가 놓인다. 참고 지도처럼 갈림길·막다른 길·순환 통로가 섞여 있어 길을 찾는 재미가 있어야 한다.

**확정 — 돌 재생과 뚫은 길:** 부순 돌은 **약 1분 뒤 같은 자리에 다시 생긴다.** 다만 **한 번 부숴서 뚫은 자리는 돌이 다시 생겨도 무시하고 지나갈 수 있다.** 재생된 돌은 길을 다시 막지 않고, 원하면 다시 캘 수 있는 광맥으로만 남는다. 길 개척은 영구히 남고, 채광은 반복된다.

**제안 — 맵·재생·상자의 연결**

- 층 지도는 직접 설계한 고정 지도로 둔다. 돌이 같은 자리에 재생되므로 플레이어가 "그 돌이 어디 있었는지" 기억하고 다시 찾아가는 재미가 생긴다.
- 도착지는 다음 층으로 내려가는 계단이다. 계단을 내려가면 층 돌파 거대한 돌이 있다 (4.8). 왕국 레벨·곡괭이 등급 조건은 이 거대한 돌에 건다.
- 뚫은 자리의 재생된 돌은 화면에서 길 옆으로 비켜난 모습이나 반투명한 표시처럼, "지나갈 수 있지만 캘 수도 있다"는 것이 보이게 한다. 그 앞에서는 지나가기와 캐기 중 고를 수 있게 한다.
- 재생이 1분으로 짧아 한 번의 탐험 중에도 돌이 계속 돌아온다. 돌의 재료는 사실상 무제한이므로, 곡괭이 제작 속도는 재생 시간이 아니라 **돌 하나의 타격 수와 재료 양**으로 조절한다.
- 재생 직후 바로 앞의 같은 돌만 반복해서 캐는 것보다 층을 돌아다니며 여러 종류의 돌을 캐는 편이 유리하도록, 다음 곡괭이 재료를 여러 종류의 돌에 나누어 둔다.
- 보물 상자에는 일반 돌보다 귀한 재료(희귀 광석, 곡괭이 제작 보조 재료 등)를 넣는다. 다만 다음 곡괭이의 필수 재료를 상자에만 넣지는 않는다.
- 보물 상자는 처음 발견했을 때 한 번 큰 보상을 주는 일회성 상자로 두는 방향을 제안한다. 재생시킨다면 돌보다 훨씬 긴 주기로 한다.

**제안 — 돌 배치와 곡괭이 등급**

- 현재 곡괭이로 부술 수 없는 돌도 화면에 보이게 하여, 막힌 길 자체가 다음 곡괭이의 목표가 되게 한다. 4.2의 "못 캐는 특수 광맥을 미리 보여준다"를 이 형태로 구현한다.
- 층의 주요 경로와 다음 곡괭이 재료가 나오는 돌은 현재 등급으로 부술 수 있어야 한다. 상위 등급 돌은 곁길, 숨은 방, 다음 층 계단 앞에 둔다. 주요 경로를 상위 등급 돌로 막으면 4.2의 순환 잠금 금지와 충돌한다.
- 등급이 모자란 돌을 클릭했을 때는 짧은 반응(튕기는 타격, "더 단단한 곡괭이가 필요해요")과 필요 등급을 보여준다.
**미정:** 돌 등급별로 재생 시간에 차이를 둘지(기본 1분), 돌을 부수는 타격 수와 손맛 연출의 재사용 범위, 돌 하나에서 나오는 재료 양, 돌 종류별 외형 구분, 보물 상자의 내용물·재생 여부.

### 4.5 나가기와 탐험 중 마을 처리

**확정 — 나가기:** 미로 UI에 나가기 버튼을 둔다. 누르면 미로의 어느 칸에 있든 **바로 밖으로 나간다.** 입구까지 걸어서 되돌아갈 필요가 없다.

**확정 — 탐험 중 마을:** 미로 체류 중 마을 생산은 경과 시간을 기록해 퇴장 시 한 번에 정산하고, **기존 오프라인 보고 화면**으로 보여준다. 보고 화면과 일괄 정산 방식을 재사용하는 것이며, 실제 앱 미접속에 적용하는 생산 감속까지 자동으로 적용한다는 뜻은 아니다.

**확정 — 재입장:** 나갔다가 다시 들어오면 미로 안의 마지막 위치가 아니라 **층 입구에서 시작한다.** 한 번 뚫은 길은 그대로 남아 있으므로 입구에서 다시 시작해도 개척한 만큼 빠르게 이동할 수 있다.

**제안 — 처리 규칙**

- 현재 [OfflineProductionService](../Assets/Scripts/Offline/OfflineProductionService.cs)의 실제 미접속 규칙은 생산 감속(`offlineSlowdown`), 최대 8시간 인정, 생산별 해금·근무 조건이다. 이를 미로 체류 전체에 그대로 적용하지 않는다.
- 앱을 켜고 직접 탐험하는 시간의 생산 속도·상한·해금 조건은 실제 미접속과 분리해 정한다. **탐험했다는 이유만으로 기존 생산이 줄지 않는 방향**을 우선 검토하며, 정확한 규칙은 직접 채광 보상과 함께 테스트한다. 감속을 채택할 경우에는 손실과 보상의 체감 검증이 필요하다.
- 미로 안에서 앱을 닫으면 종료 전 탐험 시간과 실제 미접속 시간을 나눠 기록한다. 실제 미접속 구간에는 기존 오프라인 규칙을 적용하고, 온라인 생산·탐험 정산·미접속 정산 사이에 같은 시간이 중복되거나 누락되지 않게 한다.
- 재입장할 층은 도달한 층 중에서 고를 수 있게 한다. 3층까지 내려간 플레이어가 매번 1층 입구부터 걸어 내려가지 않게 한다.
- 정산할 생산이 없을 만큼 짧게 머문 경우에는 보고 화면을 띄우지 않는다.

### 4.6 지도 해달

**확정:** 처음에는 지도 없이 미로를 탐험한다. **1~2번 지도 없이 돌아다닌 뒤 지도 해달이 자동으로 해금**되어 마을에 정착한다. 이후 지도 해달이 탐험에 함께 따라와 지도를 만들어 준다.

**확정 — 레벨과의 관계:** 지도 해달의 등장은 탐험 조건을 따른다. 7레벨까지 기다리게 하지 않으며 5~6레벨에 조건을 충족해도 등장한다. 15장의 7레벨 배치는 지도 해달의 고정 등장 시점이 아니라 지도 활용 퀘스트의 배치안이다. 맞이하기 목표를 쓴다면 이미 등장한 경우 소급 인정하고, 탐험 횟수를 다시 채우거나 재등장시키지 않는다.

지도 없이 헤매는 첫 경험이 "길을 찾는 미로"의 감각을 먼저 주고, 지도 해달의 등장이 그 불편을 풀어주는 보상이 된다. 시설을 레벨 보상으로 주는 대신 주민이 필요해서 오는 이 기획의 방향(10장)과도 맞는다.

**제안**

- "1~2번"은 미로에 들어갔다 나온 횟수로 센다. 2번째 퇴장 시 해금을 기본으로 하되, 첫 탐험에서 일정 칸 이상 돌아다녔다면 1번째 퇴장 때 해금한다.
- 지도는 한꺼번에 공개하지 않고, 지도 해달과 함께 **밟은 칸을 기록**하는 방식으로 만든다. 지도 해달이 오기 전에 밟은 칸은 기록하지 않거나, 정착할 때 "기억나는 길"로 한 번에 채워 준다.
- 지도에는 시작점, 도착지(계단), 발견한 돌, 열어본·열지 않은 보물 상자를 표시한다. 참고 지도의 범례 구성을 따른다.
- 도착 알림은 짧게: 다른 해달의 도착과 같은 방식(방명록, 광장 배치)을 따른다.
- 지도 해달의 그림은 새 해달 제작 방식(완성 그림을 받아 리그)에 따른다.

**미정:** 지도 해달의 이름·외형, 미로 화면에서 지도를 보는 방식(미니맵 상시 표시·버튼으로 펼치기), 지도 해달이 광장에서 하는 일.

### 4.7 층 구성

**확정:** 미로는 **약 5층**으로 생각한다. 최하층(5층)에 가스 발생 돌이 있다.

**제안 — 층별 역할**

| 층 | 진입 시점(제안) | 역할 |
|---|---|---|
| 1층 | Lv.5 발견 직후 | 오래된 갱도. 지도 없이 헤매는 첫 탐험, 지도 해달 해금 |
| 2층 | Lv.5~15 사이 | 곡괭이 2단계 재료, 보물 상자 탐색 |
| 3층 | Lv.5~15 사이 | 곡괭이 3단계 재료, 더 복잡한 갈림길 |
| 4층 | 낚시터 개방(Lv.15) 이후 | 가스 사건이 시작되는 심층 |
| 5층 | 최종 곡괭이 제작 전 (15장 제안: Lv.18, 해님 금 곡괭이) | 최종 곡괭이 재료 직접 수집 → 제작 → 가스 발생 돌 파괴 |

층별 왕국 레벨·곡괭이 등급과 층 지도 크기는 미정이다. 가스 사건이 4층 진입에서 시작될지, 4층 안의 특정 구역 개척에서 시작될지도 미정이다.

**확정 — 마지막 성장 순서:** 5층 진입 → 현재 곡괭이로 최종 제작 재료 채광 → 최종 곡괭이 제작 → 가스 발생 돌 파괴. 5층 입구 돌파 조건과 가스 발생 돌 파괴 조건은 다르다. 최종 곡괭이는 5층 입장 조건으로 요구하지 않으며, 필수 제작 재료는 제작 전 장비로 얻을 수 있어야 한다.

### 4.8 층 돌파: 계단 아래 거대한 돌

**확정:** 계단을 내려가면 **거대한 돌**이 다음 층으로 가는 길을 막고 있다. 이 돌을 **아주 많이(빡세게) 클릭해서 부숴야** 다음 층이 해금된다. 이 거대한 돌은 **일회성**이다. 한 번 부수면 다시 생기지 않고, 그다음부터 계단은 바로 다음 층 입구로 이어진다.

미로 안의 돌(1분마다 다시 생김, 4.4)과 다르게, 거대한 돌은 층마다 한 번뿐인 "돌파"의 순간이다. MineRework의 **막힌 길**(다음 층 입구의 큰 바위를 여러 번 쳐서 여는 것)과 같은 형태다.

**제안**

| 항목 | 제안 |
|---|---|
| 칠 횟수 | MineRework 막힌 길처럼 곡괭이 힘과 상관없이 한 번에 1씩 깎고, 치명타는 2. 층이 깊을수록 늘림 (예: 2층 30번 · 3층 45번 · 4층 60번 · 5층 80번, 테스트로 맞춤). 콤보는 이어지되 광석은 안 나옴 |
| 조건 | 거대한 돌 앞에 왕국 레벨 · 곡괭이 등급 조건. 모자라면 돌을 쳐도 튕기며 "왕국 Lv.N · ○○ 곡괭이가 필요해요"를 보여줌. 조건이 되기 전에도 돌은 보여서 다음 목표가 됨 |
| 중간에 나가기 | 친 횟수는 저장 (MineRework 막힌 길과 같음). 나갔다 와서 이어 침 |
| 화면 | 화면을 거의 채우는 큰 돌 + 진행 막대(친 횟수 / 필요 횟수). 칠수록 금이 가는 단계. 다 깨면 큰 연출(번쩍 · 화면 흔들림 · "지하 ○층이 열렸어요!") → 새 층 입구로 |
| 보상 | 돌 자체는 광석을 주지 않고, 다음 층 해금과 **자동 채굴 확장**(4.9)이 보상 |
| 재입장 | 돌파한 층은 갱도 입구에서 고를 수 있음 (4.5 제안과 같음) |
| 5층 | 5층 입구의 돌과 5층 안의 가스 발생 돌은 별개다. 가스 발생 돌도 같은 타격 형식으로 만들 수 있으나, 파괴 보상은 다음 층 개방이 아니라 가스 중단과 5층 자동 채굴 해금이다 |

**미정:** 층별 칠 횟수, 조건(레벨 · 곡괭이 등급), 깨는 연출 그림, 지하 1층 입구(갱도 발견 시)에도 거대한 돌을 둘지.

### 4.9 층 돌파와 자동 채굴

**확정:** 1~4층은 해당 층에서 다음 층으로 내려가는 거대한 돌을 부수면 **방금 개척을 완료한 층의 광석**이 광부 자동 채굴에 추가된다. 예를 들어 2층 입구를 열면 1층 광석이 추가된다. 최하층인 **5층은 가스 발생 돌 파괴를 층 돌파로 인정**하여 5층 광석을 추가한다. 오프라인 채굴도 같은 해금 목록을 쓴다.

직접 한 돌파가 방치 수입을 넓히는 구조다 (1장 게임 방향). 깊이 내려갈수록 광부가 캐 오는 광석 종류가 늘어 마을이 풍족해진다.

**제안**

| 항목 | 제안 |
|---|---|
| 들어가는 것 | 그 층의 **흔한 광맥 광석**(층 광맥 목록). 희귀 광석 · 화석 · 보물 상자 전용 재료는 넣지 않음 → 직접 탐험의 가치를 남김 |
| 들어가는 때 | 1층 계단 아래 돌을 부수면 1층 광석이 들어감 (= 2층이 열릴 때). 지금 개척 중인 층의 광석은 아직 직접만 |
| 최하층 | 가스 발생 돌 파괴 시 5층의 자동 채굴 대상 광석 해금. 가스 블록의 수출·회수 규칙은 별도이며 자동 생산 대상으로 간주하지 않음 |
| 섞는 비율 | 층마다 무게를 주고, 깊은 층 광석일수록 무게를 낮게. 돌만 나오던 비율이 조금씩 줄어듦 |
| 광부 말풍선 | 말풍선 안 광석 아이콘이 캐 온 광석에 따라 바뀜 (광산 개편 7장 그대로) |
| 알림 | 돌파 연출 뒤 "깡깡이가 이제 ○○도 캐 와요!" 한 줄 |
| 실제 미접속 | 같은 목록 · 같은 비율, 지금 규칙대로 느리게 (`offlineSlowdown`). 앱을 켠 미로 체류의 생산 속도는 4.5에서 별도 검토 |

**본 게임 연결 때 정할 것:** 지금 본 게임 광부는 돌 · 다이아몬드만 캔다 (곡괭이 강화로 다이아몬드 확률 +). 미로 광석이 본 게임 아이템이 될 때, 다이아몬드를 어디에 둘지(광산 개편 기획은 5층 희귀로 옮김)와 곡괭이 강화가 무엇을 올리는지를 같이 정한다.

## 5. 보이지 않는 가스와 주민 건강

### 5.1 질병의 성격

가스에 노출되어 생기는 질환으로 정리한다. 주민끼리 옮기는 전염병, 환각, 감염 전파 시스템으로 표현하지 않는다. 가스는 화면을 덮는 연기나 안개로 직접 보여주지 않으며, 주민과 마을의 변화로 존재를 전달한다.

확정된 결과는 **아픈 해달 증가와 가벼운 능력치 하락**이다.

**확정 — 영향 범위:** 질병은 플레이를 크게 흔드는 불이익이 아니다. 생산 감소는 치명적이지 않으며, 마을회관에서 또박이가 "요즘 아픈 해달들이 많아졌네요" 하고 걱정하는 정도의 분위기로 체감된다. 질병은 마을에 일이 생겼다는 신호이자 의사·병원·약초가 필요해지는 이유로 기능하며, 플레이어를 압박하는 페널티 시스템이 아니다.

어떤 능력치가 얼마나 감소하는지, 건강 상태를 몇 단계로 나누는지, 어느 층부터 발생하는지는 미정이다. 감소 폭은 위 영향 범위 안에서 정한다.

### 5.2 권장 진행 규칙 — 제안

- 확정된 선행 조건인 낚시터 개방 여부를 먼저 확인한다. 권장 발생 구조는 **낚시터 개방 완료 + 가스 사건 대상 심층 구역 개척**이며, 정확한 층과 개척 행동은 후속 결정한다. 낚시터를 여는 행동 자체가 가스의 원인은 아니다.
- 낚시터 개방 전에 미로를 많이 진행한 경우에도 질병을 소급 누적하지 않는 방향을 제안한다. 사건 대상 구역의 진입을 낚시터 개방 이후로 배치할지, 이후의 새 개척 행동으로 사건을 시작할지는 미정이다.
- 질병의 심화는 심층 개척 단계와 연결하고, 단순한 현실 시간 경과만으로 악화시키지 않는다. 오프라인 중 악화는 넣지 않는 방향을 제안한다.
- 최초 증상은 마을회관(또박이)의 걱정 한마디와 주민의 기침·쉬는 행동으로 보여주고, 이어서 약초와 의사에 접근할 수 있는 경로를 제시한다.
- 약초와 치료는 당장의 증상을 완화하고, 가스 발생원 파괴는 원인을 제거하는 서로 다른 역할을 맡긴다.
- 치료 중 재노출 여부는 미정이다. 치료가 무의미하게 느껴지는 반복 악화는 피한다.

질병의 영향을 가볍게 정했으므로, "질병 → 생산 감소 → 해결 장비 제작 불가 → 질병 악화"의 악순환은 구조적으로 생기지 않는다. 능력치 감소 폭을 정할 때 이 전제를 넘지 않는지만 확인한다.

## 6. 약초·마을회관·의사·병원·마을 길드 연결

### 6.1 사건 대응

상인 해달이 요정 상인에게 도움을 요청하는 것이 약초 공급의 계기다. 이를 긴 대화로 설명하기보다 상인의 짧은 알림과 상점의 새 상품으로 드러낸다.

- **요정 상점:** 약초 해금.
- **마을회관 게시판:** 약초 채집 부탁 추가 (또박이가 붙임). 이때는 마을 길드가 아직 없다.
- **의사 해달:** 등장하여 치료를 담당.
- **정식 병원:** 사건을 극복하는 과정에서 설립되어 마을의 상설 시설로 남음.
- **마을 길드:** 병원과 함께, 사건을 함께 넘긴 마을회관이 마을 길드로 커짐 (14장).

약초 채집 퀘스트가 플레이어의 직접 채집인지, 주민 파견인지, 납품 의뢰인지와 채집 장소는 미정이다. 요정 상점 구매와 게시판 채집 부탁이 어떤 관계인지도 수급 설계 때 확정한다.

### 6.2 시설 성장 — 제안

**확정 — 설립 순서:** 사건 중에는 임시 치료 공간에서 대응하고, 가스 발생원을 제거한 뒤 정식 병원을 설립한다. 임시 치료 공간의 외형, 별도 건설 여부와 비용은 미정이다. 정식 병원과 마을 길드를 함께 짓거나 차례로 지을지는 14장에서 후속 결정한다.

정식 병원이 생겼다는 사실은 의사의 상주, 진료 공간의 확장, 쉬는 주민의 행동 변화로 보여준다. 사건 해결 후 병원과 약초가 계속 어떤 기능을 담당할지는 후속 기획에서 정한다. 이를 위해 새로운 반복 질병을 반드시 추가해야 하는 것은 아니다.

## 7. 최하층 해결과 평화 회복

### 7.1 근본 해결 — 확정

최종 단계 곡괭이를 만든 뒤 최하층의 가스 발생 돌을 부순다. 돌 파괴로 가스 생성이 중단된다. 이 행동은 광산 성장의 큰 목표이자 마을 회복의 전환점이다.

가스 발생 돌 파괴는 5층 돌파 완료도 의미한다. 5층의 자동 채굴 대상 광석이 해금되며, 이후 정식 병원·마을 길드 설립으로 이어진다. 발생 돌은 다시 생기지 않는다.

### 7.2 회복 과정 — 제안

1. **발생원 제거 확인:** 파괴 연출과 짧은 완료 알림으로 원인 제거를 명확히 전달한다.
2. **새로운 피해 중단:** 추가 발병·상태 악화가 멈췄다는 사실을 표시한다. 이미 퍼진 가스가 빠지는 기간을 둘지는 미정이지만, 승리 직후 원인 모를 악화가 계속되는 느낌은 피한다.
3. **기존 환자 회복:** 의사의 치료와 확보한 약초로 남은 환자를 돌본다. 대규모 재료 수집을 다시 요구하기보다는 준비의 성과를 보여준다.
4. **일상 복귀:** 해달이 작업과 광장 활동으로 돌아오고 능력치가 회복된다.
5. **변화 정착:** 병원과 교역 시설이 남고 마을회관이 마을 길드로 커져, 사건 이전보다 발전한 마을을 보여준다.

마지막 왕진, 작은 축제, 기념 장식은 선택 가능한 연출안이다. 필수 퀘스트나 확정 보상으로 취급하지 않는다. 회복 시간, 치료량, 영구 보너스 여부도 미정이다.

## 8. 가스 블록 수출과 요정 나라

**확정:** 가스 블록을 요정 나라로 수출하고, 받은 약초에 대한 보상으로 사용한다. 의료 지원을 받은 마을이 자원을 돌려주면서 외부와 관계를 맺는다.

다음은 설정과 운영 규칙을 맞추기 위한 제안이며 아직 확정하지 않는다.

| 필요한 설명 | 제안 | 결정할 점 |
|---|---|---|
| 해달에게 해로운 물질을 요정 나라가 받는 이유 | 요정이 정화하거나 유용한 재료로 가공할 수 있음 | 실제 용도 |
| 파괴한 발생원과 수출 블록의 관계 | 발생원을 부순 뒤 남은 회수 가능한 조각 | 발생 돌 자체인지 부산물인지 |
| 운반 중 주민 보호 | 요정 기술로 밀봉하여 운송 | 보관·운송 표현 |
| 지원 보답 이후의 교역 | 최초 인도는 약초 보답, 이후 정식 거래로 발전 | 일회성 인도인지 반복 수출인지 |
| 장기 공급 | 안정된 잔여 광물이나 별도 가공을 사용 | 사건 해결 후 공급원과 고갈 여부 |

반복 수출을 넣더라도 가스 발생원을 다시 활성화해야 하는 구조는 피하는 방향을 추천한다. 원인 제거라는 플레이어의 성취와 교역 운영이 충돌하지 않아야 한다.

| 주민 건강 악화 | 마을회관 또박이의 걱정 한마디, 기침, 쉬는 행동 | 건강 상태와 실제 능력치 감소 |
| 외부의 도움 | 상점에 새 약초가 놓이고 짧은 입고 알림 | 약초 획득 방법과 치료 효과 |
| 의료 체계 형성 | 의사 상주, 진료 공간과 병원 등장 | 치료·건설에 필요한 조건 |
| 평화 회복 | 주민의 업무·산책 복귀, 광장 활기 | 발생원 해결 여부와 회복 상태 |
| 요정 나라와 교류 | 밀봉된 상자, 운송 수레, 물품 인도 | 인도 수량·보상·거래 조건 |

위 시각·행동 예시는 제안이다. 가스를 직접 보이지 않게 하는 방향은 유지한다. 원인을 처음부터 모두 공개할 필요는 없지만, 능력치 감소 사실이나 대응 방법까지 감추지는 않는다.

**사연은 암시하고, 조작·조건·불이익·해결 목표는 읽을 수 있게 만든다.**

## 10. 지속 플레이와 왕도 성장

광산의 직접 활동이 곡괭이를 성장시키고, 그 탐험이 마을의 문제를 드러내며, 문제 대응이 병원과 교역을 만든다. 시설이 단순한 레벨 보상으로 등장하는 대신 주민에게 필요해져 만들어지는 흐름이다.

최하층의 발생원 제거는 이번 사건의 결말이다. 광산 자체의 영구 종료를 뜻하지 않는다. 다만 이후의 추가 층, 새 광맥, 재방문 보상, 최종 곡괭이 이후 장비 확장 방식은 아직 정하지 않았다.

후속 설계에서는 다음 세 가지를 함께 확인한다.

- 사건 해결 뒤에도 직접 탐험할 이유가 남는가.
- 병원과 요정 교역이 마을의 상설 기능으로 자연스럽게 남는가.
- 질병을 다시 일으키지 않고도 광산을 확장할 수 있는가.

## 11. 기존 기획과의 관계

| 기존 자료 | 가져올 내용 | 이번 기획에서 재검토할 내용 |
|---|---|---|
| [광산 구현 작업기록](광산_구현_작업기록.md) | 광부 자동 채굴과 광산 생활 | 미로 진입과 기존 채굴의 공존 |
| [광산 개편 기획](광산_개편_기획.md) | 직접 광맥 타격, 광석 재료, 곡괭이 제작과 층 성장 | 미로 배치, 왕국 레벨 조건, 장기 확장, 경제 수치 |
| [밭 해금 재배치 기획](밭해금_재배치_기획.md) | 10레벨 전 광산 활동의 중요성 | 5레벨 미로 도입 후 초반 성장 속도 |

기존 MineRework는 별도 테스트 씬이며, 본 문서 작성으로 본 게임에 통합된 것은 아니다. 기존 문서의 이름·수치를 이번 논의의 확정안으로 자동 승계하지 않는다.

특히 첫 발견의 **광산 업그레이드 1회**와 미로의 **재료 기반 곡괭이 등급**은 개념을 구분한다. 광산 업그레이드 1회는 지금 게임의 곡괭이 강화 1회(오프라인 채굴이 열리는 Lv.2)로 정했다. 첫 미로 안에서만 구하는 재료를 첫 발견 조건으로 요구해서는 안 된다.

## 12. 후속 결정 항목과 점검 기준

### 우선 결정할 항목

1. 지하 1층 테스트 결과 반영 및 **재료 수집 → 곡괭이 제작 → 층 돌파 → 자동 생산 확대** 한 순환 검증 (13장). 이후 다층 확장.
2. 층 돌파 거대한 돌의 층별 칠 횟수 · 조건, 자동 채굴 광석 비율, 본 게임 광부의 다이아몬드 처리 (4.8 · 4.9).
3. 게시판 성장 재배치의 빈자리: Lv.6·7 메인 퀘스트, 마을 길드 공사 시점·비용, 옛 세이브 처리 (14장).
4. 5개 층의 지도 설계와 크기, 돌 하나의 타격 수·재료 양, 보물 상자 내용물·재생 여부.
5. 층별 왕국 레벨·곡괭이 등급, 최종 곡괭이와 사건 완료 시점.
6. 지도 해달의 해금 기준(1번·2번), 외형, 지도 보기 방식.
7. 낚시터 개방(Lv.15 선착장 수리) 이후 가스를 발생시킬 정확한 개척 단계(4층 진입 또는 4층 안 구역)와 선행 탐험 처리. 감소할 능력치와 폭(가벼운 영향 범위 안에서).
8. 약초 공급·소비, 게시판 채집 부탁 방식, 의사 등장 순서와 치료 효과.
9. 발생원 제거 후 정식 병원의 설립 비용·재료·길드와의 건설 순서·사건 이후 기능.
10. 가스 블록의 회수·용도·안전 운송·반복 공급 여부.
11. 사건 이후 광산 확장과 기존 최종 곡괭이의 역할.
12. 앱을 켠 미로 체류의 생산 속도·상한·해금 조건과 실제 미접속 구간의 정산 경계 (4.5).

### 기획 검증 기준

- 5레벨 발견 조건을 늦게 충족해도 퀘스트를 놓치지 않는가.
- 낚시터 개방 전에는 가스 질환이 시작되지 않으며, 개방 자체와 심층 개척의 인과관계를 혼동시키지 않는가.
- 자동 채굴만으로 직접 탐험의 핵심 성장을 대체하지 않는가 (자동 채굴에는 돌파한 층 광석만).
- 층 돌파 거대한 돌이 "빡세지만" 한 번에 끝낼 수 있는 길이인가, 중간에 나가도 친 횟수가 남는가.
- 방치만 하는 플레이어도 수입은 꾸준하고, 직접 하는 플레이어는 진행이 빨라지는가.
- 다음 곡괭이 재료를 현재 장비와 접근 가능한 층에서 구할 수 있는가.
- 최종 곡괭이 없이 5층에 진입하고 필수 제작 재료를 캘 수 있는가. 발생원 파괴 시 5층 자동 채굴도 해금되는가.
- 현재 곡괭이로 부술 수 없는 돌이 층의 주요 경로를 막지 않는가.
- 한 번 뚫은 길은 돌이 재생되어도 막히지 않고, 재생된 돌이 캘 수 있다는 것도 알아볼 수 있는가.
- 다음 곡괭이의 필수 재료를 보물 상자에만 의존하지 않는가.
- 나가기 버튼으로 어디서든 즉시 나올 수 있고, 다시 들어오면 층 입구에서 시작하는가.
- 돌이 1분마다 재생되어도 같은 돌 하나만 반복해서 캐는 것이 최선의 방법이 되지 않는가.
- 지도 없는 첫 탐험이 답답함으로 끝나기 전에 지도 해달이 오는가.
- 지도 해달이 7레벨 이전에 등장해도 관련 퀘스트가 진행되며, 이전 탐험을 다시 요구하지 않는가.
- 미로 체류 시간과 실제 미접속 시간이 구분되어 한 번씩만 정산되고, 앱 종료와 겹쳐도 중복·누락이 없는가.
- 탐험 때문에 마을 생산이 줄어든다고 느끼지 않는가. 감속안은 직접 채광 보상을 포함해 별도 검증했는가.
- 왕국 레벨과 장비 조건을 각각 이해하고 목표를 세울 수 있는가.
- 질병이 마을회관의 걱정 수준을 넘어 플레이를 압박하지 않는가.
- 방치형 게임에서 장기 미접속이 질병 불이익이 되지 않는가.
- 가스를 보여주지 않아도 주민 상태와 대응 방법을 알 수 있는가.
- 발생원 파괴가 실제 피해 중단과 일상 회복으로 체감되는가.
- 병원·교역이 남아 마을의 성장을 보여주는가.
- 마을 길드가 없는 동안(Lv.7~사건 해결)에도 마을회관만으로 필요한 기능(큰 부탁 · 발전 현황 · 공동사업 · 생활 의뢰 · 작은 집)이 다 열리는가.
- 반복 수출과 추가 개척이 가스 중단이라는 결말을 무효화하지 않는가.

본 단계에서는 이 문서를 기획 기준으로 남긴다. 지하 1층 테스트 씬 외의 세부 수치, 대사집, 본 게임 연결은 별도 작업이다.

## 13. 테스트 씬 기본 사용법 (지하 2~3층 확장은 16장)

### 여는 법

- `Assets/Scenes/MineMaze.unity`를 열고 Play. 본 게임 세이브·매니저와 **따로** 돈다 (저장: `persistentDataPath/mine_maze_test.json`).
- 다시 만들기: `Tools/Mine Maze/Build Test Scene` (그림 가져오기 → 설정 에셋 → 씬. 지도·상자 표는 `Assets/Editor/MineMaze/MineMazeSetup.cs`). 광산 개편 데이터(`Tools/Mine Rework/Build Test Scene`)가 먼저 있어야 함.
- 임시 그림 다시 그리기: `python Tools/UIGen/mine_maze_art.py` (막힌 벽 덧그림·보물 상자·계단). 갱도 그림 4장은 사용자 그림 그대로.
- 왼쪽 아래 **[테스트]**: 지도 해달 바로 오기 · 부순 돌 바로 다시 생기기 · 앞 돌을 반짝 광맥으로 · 곡괭이 단계 위/아래 · 처음부터.

### 플레이

| 무엇 | 구현 |
|---|---|
| 입구 | 갱도 입구 창 → [들어가기] → 층 입구(시작점)에서 시작. 나갔다 오면 늘 입구에서 |
| 이동 | 아래 버튼 앞·뒤·왼쪽·오른쪽. 왼쪽·오른쪽·뒤는 그쪽으로 돌아서 한 칸. 벽 쪽 버튼은 흐리게 |

| 나가기 | 오른쪽 위. 어디서든 바로 결과 창(탐험 시간 · 캔 것 · 부순 돌 · 연 상자 · 새로 밟은 칸 · 본 게임에선 오프라인 정산 안내) → 입구 창 |
| 지도 해달 | 처음에는 지도 칸에 "지도가 없어요". 2번 다녀오면(첫 탐험에서 40칸 이상 다녔으면 첫 번째에) 결과 창에 "지도 해달이 마을에 왔어요!" → 그다음부터 지도 칸에 밟은 칸 · 그 둘레 벽 · 돌 · 상자 · 계단 · 나(빨간 화살표)를 그림. 지도 해달이 오기 전에 밟은 칸도 기억해 둠 |
| 곡괭이 | 작업대에서 조개 구리 12개·150골드를 소모해 조개 구리 곡괭이 제작. 기존 MineRework 레시피 사용. 물결 철·달빛 은 곡괭이까지 제작 가능 (16장) |

### 지하 1층 지도 (17×15)

```
#################
#T..#.....R...#T#
#.#.#.###.#.#.#.#
#.#...#...#.#...#
#.#####.#####.###
#...R...#...#...#
###.###.#.#.###.#
#...#T..R.#.....#
#.###.#######.#.#
#.....#...R...#.#
#.#####.#.###.#.#
#.#T....#...#.R.#
#.#######.#.#.#.#
#S..R.....#...#E#
#################
```

`S` 입구 · `E` 아래층 계단 · `R` 길을 막는 돌 6개 · `T` 보물 상자 4개. 길 117칸, 입구에서 계단까지 최단 22걸음이고 돌을 부숴야 갈 수 있다. 돌 없이 갈 수 있는 칸은 23칸뿐이라 첫 돌(입구 동쪽 세 칸)을 부수는 것이 첫 목표가 된다.

### 아직 임시 · 다음

현재 테스트에는 길 찾기·타격감·재생·상자·지도 해달에 더해 작업대 제작·광석 판매·일회성 돌파·자동 채굴이 연결되어 있다. 규칙 검증은 완료했지만 실제 플레이의 재미와 화면 배치는 플레이 테스트가 필요하다.

**현재 테스트 범위 — 한 순환 구현 완료, 플레이 평가 필요:** 여러 층을 먼저 완성하기보다, 1층에서 직접 재료를 모아 실제 제작으로 곡괭이를 올리고, 계단의 일회성 돌을 부순 뒤 1층 광석이 자동 생산에 추가되는 한 순환을 연결했다. 다음 층은 해금 확인용 입구만으로도 검증할 수 있다. 직접 채광 시간·제작까지 걸리는 시간·돌파 타격 부담·돌파 전후 자동 수입을 함께 확인한다. 1층 플레이 확인 후 2~3층을 추가했다 (16장). 본 게임 연결과 4층 이후 제작은 후속 단계다.

- 임시 그림: 막힌 벽 덧그림(갱도 그림에서 떠 온 바위 결), 보물 상자, 계단, 지도 해달 얼굴(다른 해달 아이콘). 진짜 그림이 오면 같은 파일 이름으로 덮어쓰기.
- 갱도 그림이 4장(앞이 열린 모습)뿐이라, 막다른 길·꺾인 길은 덧그림으로 막는다. 막다른 길 전용 그림, 왼쪽·오른쪽만 열린 그림(T자 · ㄱ자)이 있으면 더 자연스러움.
- 테스트 왕국 레벨은 설정값 13으로 시작한다 (2~3층 탐험 검증용 임시값). 기존 1층 저장도 다층 저장으로 처음 이전할 때 최소 13으로 맞춘다. 본 게임 레벨을 변경하지 않는다. 최초 테스트 골드는 기존 MineRework의 200골드이며, 남는 광석을 판매해 보충할 수 있다.
- 돌파 후 테스트 자동 채굴은 1층 광맥 목록 중 Common·Uncommon만 대상으로 한다. 희귀·화석은 제외한다. 탐험·입구·작업대에서 같은 속도로 쌓이며, 실제 미접속에만 기존 감속·최대 획득량·8시간 상한을 적용한다. 본 게임의 기존 자동 채굴 수입은 이 테스트에서 재현하지 않는다.
- 제작 비용·골드·돌파 누적 피해·해금·자동 생산 잔여 시간을 저장한다. 기존 테스트 저장에는 시작 골드를 한 번만 부여하며, 이후 잔액 0도 유지한다.
- Unity EditMode MineMazeTests 30개 통과: 기존 20개 + 성장 순환 10개. 무치트 수집·제작·돌파·생산, 재료 부족·중복 레시피, 조건 검사, 저장 복원, 실제 미접속 감속·상한, 판매를 검증했다. 결과: `tmp/mine-maze-progression-tests.xml`.
- 테스트 후 정할 것: 갱도 화면 크기·버튼 배치, 한 칸 연출 속도, 돌 크기, 1분 재생이 적당한지, 상자 보상, 지도 해달 2번 기준.
- 본 게임 연결(Lv.5 발견 퀘스트 · 광산 씬 입구 · 오프라인 정산 · 광석을 본 게임 아이템으로)은 테스트 후.

## 14. 게시판 · 마을회관 · 길드 성장 재배치 (2026-10-18)

### 문제

지금은 게시판이 Lv.5~7 세 레벨 연속으로 커진다. 게시판 → 마을회관 → 길드 접수 창구 → 마을 길드가 한 레벨에 하나씩 이어져 너무 촘촘하고, 같은 건물을 연달아 고치는 퀘스트가 반복된다.

| Lv | 메인 퀘스트 | 공사 | 결과 (발전) |
|---|---|---|---|
| 5 | `M05_Board` 부탁이 많아졌어요 | `con_board_upgrade` 마을회관 (골드 300 · 목재 12 · 돌 6, 30초) | `board_upgraded`: 마을회관 · 또박이 방문 |
| 6 | `M06_Guild` 큰 부탁도 함께 | `con_guild_office` 길드 접수 창구 (골드 600 · 목재 24 · 돌 12, 60초) | `guild_office_built`: 게시판 등급 길드 · 큰 부탁(마을 위원회 묶음) 보임 |
| 7 | `M07_TownHall` 우리 마을의 길드 | `con_town_hall` 마을 길드 (골드 1,200 · 목재 36 · 돌 24, 120초) | `town_hall_built`: 아래 표의 기능 |

### 확정

- **접수 창구는 마을회관에 합친다.** 따로 짓는 공사·퀘스트(Lv.6 `M06_Guild`)를 없애고, 마을회관이 생기면 큰 부탁도 함께 받는다.
- **마을 길드는 가스 질환 해결 뒤, 병원과 함께 세워진다.** 사건을 함께 넘긴 마을회관이 커지는 것이 사건의 유산이 된다 (2 · 6 · 7장).
- **마을 길드가 열던 것은 마을회관이 연다.** 마을 길드가 없는 동안(Lv.7~사건 해결)에도 진행이 막히지 않게 한다.

### 마을 길드(`town_hall_built`)가 지금 여는 것 → 옮길 곳

| 지금 마을 길드가 여는 것 | 어디서 | 옮길 곳 |
|---|---|---|
| 발전 현황 화면 | `SettlementManager.IsTownHallOpen` | 마을회관. 이미 `board_upgraded`(마을회관)로도 열리게 되어 있어 마을 길드 조건만 빼면 됨 |
| 작은 집 짓기 | `SettlementSetup.Buildings` `bld_small_house` 필요 발전 | 마을회관 (`board_upgraded`) |
| 공동사업 "우리 마을의 첫 비축" (Lv.7) → 이어지는 공동사업 · 영토 확장 | `SettlementSetup.P3` 필요 발전 | 마을회관. 안내문 "길드는 생겼는데 함께 쓸 재료가 없네"는 "마을회관은 생겼는데…"로 |
| 생활 의뢰 (Lv.7) | `SettlementSetup.P3` `_lifeRequestDevelopment` | 마을회관 |
| 광장 건물 모습 (마을회관 → 마을 길드 그림으로 바뀜) | `SettlementSetup.P2` · `Plots` 게이트 | 그대로 두되, 바뀌는 시점만 사건 해결 뒤로 |
| 성 부탁 (`req_upgrade_town_hall`을 틀로 복사) | `SettlementSetup.Castle` | 영향 없음 (틀만 씀) |

### 접수 창구(`guild_office_built`)가 지금 여는 것 → 마을회관으로

| 지금 접수 창구가 여는 것 | 어디서 | 옮길 곳 |
|---|---|---|
| 게시판 등급 "길드" (큰 부탁 칸) | `SettlementBoardRules.GetTier` | 마을회관 단계에서 같은 칸을 보여 줌 |
| 큰 부탁 묶음 "마을 위원회" 보이기 | `SettlementSetup.P2` `_visibleDevelopment` | 마을회관 (`board_upgraded` 또는 또박이 배치 `board_managed`) |
| 광장의 접수소 건물 | `SettlementSetup.P2` 게이트 | 없앰 (마을회관 그림이 그대로 이어짐) |

### 제안

- **Lv.6 · 7 빈자리:** `M06_Guild`(경험치 200)와 `M07_TownHall`(경험치 300)이 빠진다. 같은 경험치를 광산 미로 초반 퀘스트로 채운다. 예: Lv.5 오래된 갱도 발견 → Lv.6 첫 돌 부수기 · 첫 보물 상자 → Lv.7 지도 활용. 지도 해달은 탐험 조건으로 먼저 올 수 있으며, 맞이하기 목표를 쓰면 기존 등장을 소급 인정한다. 미로가 Lv.5에 열리는 것과도 맞는다.
- **마을 길드 공사:** 사건 해결(최하층 돌 파괴) 뒤 병원 공사와 같은 흐름에서. 비용은 그때 경제에 맞춰 다시 정한다 (지금 1,200 · 36 · 24는 Lv.7 기준).
- **이름:** 사건 전까지는 게시판 화면 · 건물 이름 모두 "마을회관"으로 통일하고, "길드" 글자는 마을 길드가 생길 때 처음 쓴다.
- **옛 세이브:** 이미 접수 창구 · 마을 길드를 지은 세이브는 그대로 둔다 (지은 건물을 빼앗지 않음). 접수 창구만 지은 세이브는 마을회관으로 본다.

### 미정

- 마을 길드가 생기면 새로 여는 것 (지금 마을 길드의 기능은 모두 마을회관으로 옮기므로, 마을 길드만의 새 역할이 필요한지).
- 병원과 마을 길드를 한 공사로 묶을지, 차례로 지을지.

### 적용 (2026-10-21, `feature/OmissionFunction`)

- **순서:** 게시판 → 마을회관(Lv.5) → 또박이 배치 → … → 가스 사건 해결 → 병원 → **마을 길드**(마을회관을 넓힘) → **성**(마을 길드를 넓힘) → 길드 지부. 사용자 결정: 길드 먼저, 성은 그 뒤
- **접수 창구 부탁(`req_build_guild_office`)** 은 메인 목록에서 뺐다. 짓던 세이브는 불러올 때 공사를 조용히 끝냄 (`SettlementMigration.RetireGuildOfficeJob`)
- 접수 창구가 열던 것 → 또박이 배치(`receptionist_assigned`): 게시판 길드 칸(`_guildDevelopment`), 큰 부탁 묶음(이름 "함께 꾸리는 마을회관", 단계 = 게시판 보강 · 또박이 배치 · 쉴 자리)
- 마을 길드가 열던 것 → 마을회관(`board_upgraded`): 작은 집, 첫 비축, 생활 의뢰. 발전 현황 화면은 원래 마을회관으로도 열림
- **마을 길드 부탁(`req_upgrade_town_hall`)** 의 조건 = 병원(`mine_hospital`). 비용 골드 3,000 · 목재 36 · 돌 40 · 3분. 광장 그림은 그대로 마을회관 → 마을 길드 → 성
- 광산 이야기의 마을 길드 단계는 이 부탁으로 셈. 따로 짓던 `bld_mine_guild`는 꾸미기 목록에서 뺐다 (지은 세이브는 길드로 셈)
- **성**(`CastleRules`)은 마을 길드(`town_hall_built`)가 있어야 열림. 질서도 안내에 "성은 마을 길드가 생긴 뒤에" 문구
- **메인 Lv.6 · 7**: `M06_Guild` = 갱도에서 돌 부수기(`maze_first_rock`), `M07_TownHall` = 지하 1층 돌 모두 부수고 나오기(`maze_first_trip`). 세이브 키 때문에 퀘스트 ID · 에셋 이름은 그대로. 광산 미로가 들어갈 때 · 돌을 부술 때 · 나올 때 기록함
- 사건 전 문구의 "길드"는 "마을회관"으로 (첫 비축 · 첫 모임 · 마을 생활 준비 · 마을회관 주변 정리)
- 남은 것: 성이 마을 길드 뒤로 밀려 Lv.16 이후 바로 성을 세울 수 없음 (가스 사건 Lv.18~20). 15장 레벨별 흐름안과 함께 다시 볼 것

## 15. 레벨별 흐름안 (2026-10-18, 제안)

지금 퀘스트 표(`Assets/Editor/Quest/QuestSetup.cs`, `Docs/레벨별_메인퀘스트.md`)와 진행 시간 기록(`Docs/QA_Lv1-10.md`)을 바탕으로 한 제안이다. 확정이 아니며 코드 · 퀘스트 표는 바꾸지 않았다.

### 지금 흐름의 문제

1. **Lv.5~9는 기다리는 구간이다.** 시뮬레이터 기준 Lv.4까지 8분, Lv.10까지 236분이고 그중 약 220분이 광석 · 판매 숫자가 차기를 기다리는 시간이다. 이 구간 메인이 "광석 60 · 50 · 150개"의 반복이다.
2. **Lv.10이 혼자 크다.** 농업 지역 → 밭 개간 → 새싹이 배치 → 당근 → 첫 모임 → 판매 10,000이 한 레벨에 몰려 있다.
3. **Lv.14와 Lv.16 이후는 숫자 채우기다.** Lv.14는 업그레이드 · 작물 1,500 · 판매 80,000, Lv.16 이후는 줄거리가 얇다.
4. **새 기획과 부딪힌다.** 성이 Lv.16(`_castleLevel`)에 열려 왕도의 마지막이 가스 질환 사건보다 앞선다. 게시판의 **길드 지부** 부탁(순서 18)은 마을 길드를 사건 뒤로 미룬 14장과 맞지 않는다.

### 원칙

- **한 레벨 = 새것 하나 + 손으로 할 것 하나 + 기다릴 것 하나.** 새 시스템 둘을 한 레벨에 넣지 않는다.
- **"광석 N개" 대신 미로 목표.** 방치 숫자 대신 직접 하는 일(돌 · 상자 · 계단 · 층 돌파)로 기다림을 할 일로 바꾼다 (1장 방치 + 상호작용).
- **광산 → 밭 → 바다를 번갈아.** 미로 층을 띄엄띄엄 열어 밭 · 바다가 열린 뒤에도 광산에 돌아갈 이유를 만든다.
- **가스 질환 사건 = Lv.16~20의 줄거리.** 해결 보상이 병원 · 마을 길드이고, 그 뒤에 성으로 왕도를 마무리한다.

| 19 | 최종 곡괭이 | 5층 등 접근 가능한 구역에서 재료 수집 → 제작, 증상 완화 | 최종 장비로 가스 발생 돌 파괴 준비 |
| 20 | **가스 발생 돌 파괴** | 회복 → **병원 + 마을 길드** → 요정 나라에 가스 블록 인도 | 가스 중단과 5층 자동 채굴 해금. 사건의 끝 = 마을 길드 |
| 21~ | 요정 나라와 정식 교역 · 길드 지부 | **성 세우기 = 왕도** | 성 · 길드 지부를 여기로 |

### 덧붙이는 아이디어

- **지도 해달 = 끄적이.** 지금 Lv.17에 오는 "밤의 메모쟁이" 끄적이(기록관)를 초반 미로의 지도 해달로 당기는 제안이다. 등장은 Lv.7 고정이 아니라 탐험 1~2회 조건을 따른다. 기록하는 해달이 지도를 그리는 것이 어울리고 새 해달 그림이 필요 없다 (테스트 씬 임시 얼굴도 끄적이 아이콘). 기록관은 뒤에서 화석 · 지도를 모아 두는 건물로.
- **P4 해달 이야기와 광산을 번갈아.** Lv.10~20에서 둘이 같은 레벨에 겹치지 않게 해 "이번엔 마을, 다음엔 광산" 리듬을 만든다.

### 확인할 것

- 미로 목표로 바꾼 Lv.5~9 진행 시간: 시뮬레이터(`Tools/Balance/p1_farm_relocation_pacing.py`)에 미로 · 층 돌파를 넣어 다시 본다.
- 2~5층 레벨: 지하 1층 테스트 느낌에 따라 바뀔 수 있다.
- 성을 Lv.21 뒤로 미루는 것: 이미 Lv.16 이상인 세이브 · 질서도 게이지가 걸려 있어 따로 결정이 필요하다.

## 16. 지하 2~3층 테스트 구현 (2026-10-18)

사용자 요청: 1층 플레이 확인 후 지하 2~3층을 먼저 구현. 기존 `MineMaze.unity`에서 이어서 플레이한다. 본 게임·가스 질환·4층은 이번 범위에 포함하지 않는다.

| 층 | 지도와 보상 | 다음 진행 |
|---|---|---|
| 1층 | 기존 지도·저장 유지 | 왕국 Lv.9·조개 구리 곡괭이, 돌파 30 → 2층과 1층 자동 채굴 |
| 2층 물결 갱도 | 고정 17×15, 광맥 8개·상자 4개. 기존 2층 광맥·체력 사용, 상자에서 철 5~8·은 2~4 | 왕국 Lv.13·물결 철 곡괭이, 돌파 45 → 3층과 2층 자동 채굴 |
| 3층 산호 수정 동굴 | 고정 19×17, 광맥 10개·상자 4개. 기존 3층 광맥·체력 사용, 상자에서 수정 5~8·은 2~4 | 달빛 은 곡괭이 제작과 탐험 가능. 끝 계단은 닫힌 심층 안내만 표시. 4층 개방·3층 자동 채굴·가스 이벤트는 발생하지 않음 |

- **입장:** 돌파 화면의 ‘다음 층 들어가기’로 내려간다. 나간 뒤에는 입구의 ‘열린 층 선택’에서 해금된 층을 고른다. 다시 들어갈 때는 선택한 층 입구에서 시작한다.
- **장비:** 기존 MineRework 레시피 사용. 조개 구리 12·150G → 물결 철 15 + 조개 구리 10·500G → 달빛 은 10 + 물결 철 20·1,500G. 후속 제작 재료는 현재까지 열린 층에서 채광할 수 있다.
- **저장:** 가방·골드·곡괭이·지도 해달은 공유한다. 방문 칸·상자 개봉·돌 재생·돌파 피해·돌파 완료는 층별로 저장한다. 기존 1층 저장은 1층 기록으로 이전하며 획득물이나 열린 길을 초기화하지 않는다.
- **탐험 정산:** 계단으로 층을 옮겨도 한 번의 탐험으로 이어져 재료·탐험 시간 집계가 유지된다. 층 이동을 지도 해달 해금용 퇴장 횟수로 세지 않는다.
- **자동 채굴:** 현재 머무는 층과 관계없이 이미 돌파한 층들의 일반 광맥 목록을 합쳐 생산한다. 미돌파 층·희귀·화석은 제외하며, 총 채굴 간격은 곡괭이 보너스를 적용한 기존 간격을 유지한다.
- **테스트 왕국 레벨:** 신규 테스트와 기존 1층 저장의 최초 다층 이전은 Lv.13으로 맞춘다. 본 게임 왕국 레벨에는 영향을 주지 않는다. 레벨별 해금 수치는 본 게임 연결 전 재조정할 수 있는 임시값이다.
- **배경:** 기존 정면 갱도 4종을 유지하고 층별 지도·광석 띠·광맥과 제목을 바꾼다. 새로운 전용 배경 이미지는 추가하지 않았다.
- **데이터 갱신:** `Tools/Mine Maze/Update Floors 2 and 3`로 2·3층 설정을 재생성할 수 있다. 지도는 고정 시드로 에디터에서 생성해 에셋에 저장되므로 플레이 때마다 바뀌지 않는다. 기존 1층 씬·지도는 다시 만들 필요 없다.
- **검증:** Unity EditMode `MineMazeTests` 34개 통과. 기존 30개와 함께 다층 저장의 JSON 왕복, 층별 기록 독립성, 잠긴 층 접근 방지, 탐험 중 무단 층 이동 방지, 자동 생산 대상, 3층 종점, 실제 에셋 지도의 전체 연결성과 제작 재료 접근성을 확인했다. 결과는 `tmp/mine-floors-tests.xml`. 새 층의 화면과 난이도는 실제 플레이 확인이 필요하다.

## 17. 본 게임 연결: 갱도 발견과 입장 (2026-10-19)

사용자 요청: 코덱스가 만든 지하 1~3층을 인게임에 적용하기 위해, 왕국 Lv.5와 다른 조건을 달성하면 미로 탐험을 할 수 있게 연결. 범위는 **입장 연결까지**: 광석·골드·곡괭이는 당분간 갱도 안에서 따로 돌고, 본 게임 경제와 합치는 것은 다음 단계.

### 흐름

| 단계 | 구현 |
|---|---|
| 발견 | 왕국 Lv.5 이상 + 곡괭이 강화 1회(곡괭이 Lv.2 = 오프라인 채굴이 열리는 레벨) + 광부가 채굴 중(채굴 켬 · 광부 배치) → 깡깡이가 오래된 갱도를 찾음. 어느 장소에서든 1초마다 확인 (`GameManager.MineMaze.cs`, 규칙 `MineMazeRules.ShouldDiscover`). 발전 `mine_maze_found`로 남아 나중에 채굴을 멈춰도 닫히지 않음. Lv.5를 넘긴 세이브도 조건이 맞는 순간 찾음 |
| 알림 | "깡깡이: 광산 안쪽에서 누군가 쓰던 오래된 갱도를 찾았어요!" — 광산 밖이면 [광산 가기] 버튼 |
| 메인 퀘스트 (Lv.5) | 곡괭이 강화(100) → 마을회관(120) → 광석 60개(230 → **130**) → **오래된 갱도**(40, 발전 `mine_maze_found`, 기록으로 다시 셈) → **갱도 속으로**(60, 장소 MineMaze 도착) → Lv.6 또박이. 레벨 합 450 그대로. 메인 표 판 3 (`QuestManager.MainChainVersion`): Lv.6 이상 세이브는 새 Lv.5 퀘스트를 보상 없이 넘김 |
| 광산 씬 입구 | 광산 카트(배경 픽셀 756, 480) 뒤에 숨 쉬는 빛 + "오래된 갱도 ▼" 글자. 갱도를 찾은 뒤에만 보임. 누르면 "깡깡이가 찾은 오래된 갱도에 들어가 볼까요?" → 미로 장소로 이동 (`MineMazeEntranceView`). 광산 씬은 `MineSceneSetup`이 통째로 다시 만들기 때문에 씬에 넣지 않고 광산 씬이 열릴 때 만듦 |
| 미로 장소 | `Zone_MineMaze` (씬 MineMaze, 갱도 발견 · 왕국 Lv.5부터). 이동 팝업 카드가 생기지 않게 전역 UI 장소 목록에는 넣지 않음 → 광산 카트로만 들어감. Build Settings에 MineMaze 추가 |
| 미로 안 | 전역 상단바 · 네비게이션 바를 숨김(화면 어두워짐 · 알림 · 팝업은 그대로). 층 돌파 조건의 왕국 레벨은 **본 게임 왕국 레벨** (테스트 레벨 대신). 입구 창에 [광산으로 돌아가기], 결과 창의 [광산으로] → 광산 씬. 테스트 버튼은 테스트 씬 · 개발 빌드에서만 |
| 테스트 씬 | MineMaze 씬을 직접 열면 지금처럼 테스트 씬 (테스트 왕국 레벨 · 테스트 창) |

### 아직 따로인 것 (다음 단계)

- **경제:** 갱도 광석 · 갱도 골드 · 곡괭이는 갱도 저장(`persistentDataPath/mine_maze_test.json`)에만 있고, 본 게임 가방 · 골드 · 곡괭이 강화와 이어지지 않음. 입구 창에 "갱도의 광석 · 골드 · 곡괭이는 아직 갱도 안에서만 써요"로 표시.
- **자동 채굴:** 돌파한 층의 광석은 갱도 작업대 쪽 자동 채굴로만 쌓임. 본 게임 광부(돌 · 다이아몬드)는 그대로.
- **탐험 중 마을:** 미로 씬에는 GameManager가 없어서, 다른 장소로 옮긴 것처럼 처리됨 — 광산으로 돌아오면 그동안의 밭이 다른 장소에 있다 온 것처럼 따라잡음. 4.5의 "나올 때 오프라인 보고 화면"은 경제 연결 때.
- **저장 파일 이름:** 테스트 씬과 본 게임이 같은 갱도 저장을 씀. 경제를 합칠 때 본 게임 세이브로 옮김.
