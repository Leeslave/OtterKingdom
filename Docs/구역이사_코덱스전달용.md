## 0. 일하는 방식 (사용자 요청 — 꼭 지킬 것)

1. **단계로 나눠 구현하고, 한 단계가 끝나면 멈춰서 사용자 확인을 받는다.** 다음 단계를 이어서 하지 않는다.
2. 답은 **한국어**, 짧게. 사용자는 바로 구현하는 것을 원함 (설명은 짧게).
3. 커밋 · 푸시 · PR은 사용자가 말할 때만.
4. 단계가 끝나면 `Docs/구역이사_작업기록.md`에 그 단계 절(구현 · 구조 · 확인 · 남은 것)을 덧붙인다.

## 1. 기획 요약

어지러운 공터 정착지가 행정 해달과 함께 질서 잡힌 왕국이 된다 (5막).

| 막 | 레벨 | 내용 |
|---|---|---|
| 1막 공터 정착 | 1~5 | 지도 가운데 공터에서 시작. 첫 집 · 의자 · 광산 길 · 이웃 집 · 게시판 보강. 자리는 자유. (밭은 이 막에서 빠짐 — 5단계) |
| 2막 체제가 잡힌다 | 6~7 | 마을회관 완성 → 게시판 관리 해달 **또박이가 행정 해달로 승격**. "음… 좀 정신없네요" — 난잡함을 캐릭터가 먼저 말함. **마을회관에 왕국 질서도 게이지** |
| 3막 구역 나누기 | 6~9 | **마을회관 완성·또박이 승격 후 중앙 공터를 강조해 첫 주거 지정 안내**. 추가 개간 없이 중앙부터 지정하고, 확장한 땅은 열린 뒤 용도를 고름. 지정 후 변경 가능 (10장 사용자 수정) |
| 4막 이사 지시 | 8~10 | 질서도 기준 도달 → **이사 지시서**: 1장에 건물 1~3개, 대상 건물 · 목표 구역 반짝임, 플레이어는 부지 칸만 고름, 건설 해달이 집을 들고 옮김(시간), 장마다 보상, 다 끝나면 빈 공터가 넓은 광장 + **정리 전·후 비교 컷** |
| 5막 왕국이 된다 | 10~15+ | 특성 건물(가게 · 공방 · 채석장 · 곡물창고)은 **맞는 구역에만**. **농업 구역을 개간하면 밭 해금**. 질서도가 높으면 **마을회관 → 성**, **길드는 상업 구역으로 분가** |

구역: 중앙(행정: 게시판 → 마을회관 → 성) · 주거(집 · 쉬는 자리) · 상업(요정 상점 · 가게 · 길드 접수소) · 생산(공방 · 채석장 · 곡물창고) · 농업(밭).
패널티는 없고, 구역 밖 건물은 보너스에 안 셈 + "민원" 말풍선(5단계).

## 2. 나눈 단계 · 상태

| 단계 | 내용 | 상태 |

## 3. 사용자가 정한 것 · 아직 정할 것

정함:
- 미리 정한 블록(칠하기 없음), 패널티 없음(보너스만 + 민원 말풍선), 위치는 지도 배치안(주거 북동 · 상업 남 · 생산 북서 · 농업 서).
- **블록은 작게 시작해 그 방향 영토를 넓힐 때마다 커짐** (2단계에서 함).
- **상업 · 농업처럼 시설이 있어야 쓸모 있는 구역은 그 시설이 열릴 때 함께 열림** (2단계에서 함).
- **첫 구역(주거)이 열릴 때 튜토리얼로 구역 정하는 법을 알려 줌** (3단계에서 할 것).

아직 정할 것 (사용자에게 물어볼 것, 임의로 바꾸지 말 것):
- 개간 속도: 4방향 × (3 + 2 + 2) = 28번인데 기회는 레벨마다 1번 (Lv.6 → 33).
- 용도를 여는 시설: 상업 = `p4_trader_settled`, 생산 = `p4_lumber_settled`, 농업 = `farmland` (임시).
- 질서도 식 · 기준(이사 10 · 성 80) · 보너스 수치 (모두 임시).
- 밭을 농업 구역으로 끌어올지 / 밭 화면 유지할지, 성 목표 레벨(제안 Lv.16+).

## 5. 3단계 구현 범위 (완료 — 작업기록 8장 참고)

1. **또박이 → 행정 해달 승격 (2막)**
   - 조건: 마을회관 완성(`board_upgraded`) + 또박이(`otter_receptionist`)가 게시판 관리(`role_board_manager`, 결과 발전 `receptionist_assigned`)를 맡고 있음.
   - 한 번만 나오는 연출 + 대사 "음… 좀 정신없네요"(난잡함을 먼저 말함) → 발전(예: `admin_otter_promoted`)을 열고 저장. 옛 세이브에서 조건을 이미 채웠으면 다음 광장 방문 때 한 번.
   - 화면에 보이는 이름 · 말풍선을 "행정 해달"로 (관리 역할 표시 위치를 찾아 바꿈).
2. **마을회관 질서도 게이지**
   - `TownHallPopupView` / `TownHallPresenter`에 게이지 줄: `manager.DistrictOrder.Score` (0~100), 다음 목표 한 줄 (예: "구역을 정하면 +10" · "이사 지시서까지 n" · "성까지 n").
   - 승격 전에는 숨김.
3. **"이 땅을 뭘로 쓸까요?" 구역 정하기**
   - `PendingDistrictBlocks()`가 있으면 알림(마을회관 카드 · 광장의 그 블록 위 표지).
   - 화면: 블록 이름 · 고를 수 있는 용도(`DistrictChoices`) · 잠긴 용도와 이유(`config.FindDistrictTypeUnlock(type).LockedHint`, `CheckDesignate` 결과로 문구) · 예시 용도 추천 표시 → `TryDesignateDistrict`.
   - 고를 용도가 하나도 없으면 "아직 쓸 곳이 없어요" + 잠긴 이유.
4. **첫 구역(주거) 튜토리얼** (사용자 요청)
   - 승격 후 중앙 공터를 아직 지정하지 않았을 때: 중앙 공터 하이라이트 · 첫 주거 지정 · 맞는 구역의 건물 보너스 · 질서도. 숲 개간을 기다리지 않음 (10장 사용자 수정).
   - 기존 튜토리얼 틀을 쓴다: `Assets/Scripts/Tutorial/ZoneTutorials.cs`(기능 튜토리얼 ID — `Build` 처럼 새 ID 추가, 완료 기록은 `tutorialsDone`), `TutorialOverlay` · `TutorialPointer`, `GameManager`의 튜토리얼 흐름. 건설 모드 튜토리얼(`ZoneTutorials.Build`, `Docs/건설모드_전환_작업기록.md` 3장)이 좋은 예.
   - 실제로 주거를 정해야 완료.
5. **구역 바닥 표시**: 정한 블록의 열린 단계 칸을 용도 색으로 옅게 칠하고, 부지 칸 테두리 (적어도 건설 · 꾸미기 모드에서).
6. 테스트: EditMode (승격 조건 · 한 번만 · 옛 세이브, 구역 정하기 흐름의 순수 로직), 가능하면 PlayMode로 실제 광장 확인.

## 6. 이 저장소의 규칙 · 함정

- **데이터 · UI · 광장 배치는 에디터 스크립트가 만든다** (`Assets/Editor/Settlement/SettlementSetup*.cs`, `Assets/Editor/Navigation/GlobalUISetup.cs`). 프리팹 · 씬을 손으로 고치지 말고 생성 코드를 고친 뒤 메뉴를 실행. UI는 범위가 좁은 메뉴를 새로 만들어 쓰는 편이 diff가 작다 (예: `Tools/Settlement/Rebuild Task Popup`).
- **`Apply P3 Projects` / `Apply Map Expansion`을 돌리면 팀원이 손으로 고친 에셋을 덮어쓴다** (해달 · P4 부탁 · 그림 import 설정 · 폰트 SDF). 돌린 뒤 `git status`로 보고 의도하지 않은 것은 `git checkout --`으로 되돌린다. 줄바꿈만 바뀐 파일도 되돌린다.
- 그 밖에 생성 도구가 건드리기 쉬운 것: `Assets/Fonts/*SDF.asset`, `Prefab/Collection|Currency|Quest|Shop`, `InventoryTestScene`, `Navigation` 존, `QuestDatabase`, `EditorBuildSettings`, `ProjectSettings` → 의도하지 않았으면 되돌림.
- `Assets/Scripts/Currency/`는 사용자 소유 (API 고정, enum은 뒤에만 추가).
- enum · 세이브 필드는 숫자로 저장되므로 순서를 바꾸지 않고 뒤에만 붙인다. 세이브 형식을 바꾸면 `SettlementSaveData.CurrentVersion` + 옮기기 코드 + 테스트.
- 줄바꿈: `core.autocrlf=true`, C# 파일은 CRLF (BOM 있는 파일도 있음 — 그대로 유지).
- 주석 · 문서는 한국어, 주변 코드의 말투 · 밀도에 맞춤.
- Python: `%LOCALAPPDATA%\Programs\Python\Python312\python.exe` (bash의 `python`은 Windows 스토어 가짜 실행 파일).

## 10. 사용자 수정 — 현재 적용 정책 (2026-10-14)

**마을회관 완성 → 또박이 행정 해달 승격 → 중앙 공터 하이라이트 → 주거 구역 설정 안내 → 중앙 주거 지정**. 숲 개간을 기다리지 않는다. 이미 승격한 세이브에도 다음 광장 방문에 안내한다.

**설정한 구역은 다시 변경 가능**. 회관의 구역 관리에서 열린 구역을 고르고 용도를 바꾼다. 시설 잠금은 유지하되 같은 용도를 여러 블록에 사용할 수 있다. 기존 건물·구역 저장을 보존하며 중앙의 지정 값이 기본 행정 용도보다 우선한다.

이 정책이 앞 절의 중앙 행정 고정·바깥 첫 주거·용도 변경 불가·용도 중복 제한보다 우선한다. 상세 구현·검증은 작업기록 9장. 사용자 확인 전 4단계는 시작하지 않는다.
