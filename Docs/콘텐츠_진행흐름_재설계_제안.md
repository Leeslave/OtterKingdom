# 해달 왕국 콘텐츠 진행 흐름 재설계 제안

- 작성일: 2026-10-21
- 상태: 검토용 기획안. **8장 1차는 2026-10-21 적용**(아래 8장 참고). 나머지 순서·수치·해금 변경은 제안이며, 게임에는 적용하지 않았다.
- 목표: 플레이어가 다음 시설을 짓는 이유를 이해하고, 완성한 시설을 사용하면서 다음 목표를 발견하게 한다.
- 첨부 대화는 ‘부족함을 느낌 → 해결 시설을 마련함 → 다음 생활 목표가 생김’이라는 방향의 참고 자료로 해석했다.
- 2026-10-21 후속 방향: 장난감 삭제·해달 가챠 전환. 관련 규칙은 `장난감삭제_해달가챠_응원동료_기획안.md`를 함께 본다. 필수 주민은 이야기로 등장하고, 가챠 동료는 응원 버프를 제공한다.
- 2026-10-21 정찰 방향 반영: 갱도의 지도 해달이 또박이와 마을회관에서 일하고, 정착 주민으로 정찰대를 보내 섬 지도를 만든다. 정찰 중에는 다른 작업을 할 수 없다. 발견한 낚시터로 길을 뚫도록 유도한다. 상세 규칙은 11장에 정리했다.

## 1. 핵심 방향

**집과 일터를 늘어놓는 진행에서, 마을의 생활 문제를 하나씩 해결하는 진행으로 바꾼다.**

기본 순환은 다음과 같다.

`새 생활 경험 → 작은 불편 발견 → 해결할 해달과 시설 소개 → 건설 → 새 기능 사용 → 더 큰 생활 목표`

예: 집을 더 짓고 싶다 → 손으로 줍는 목재만으로는 느리다 → 꾸벅이와 목공소를 마련한다 → 목재를 반복 확보한다 → 새 이웃의 집과 밭을 짓는다.

‘부족하다’는 반드시 자원 0개나 강제 대기를 뜻하지 않는다. 이미 충분히 가진 플레이어에게는 “앞으로 집을 더 지으려면 일터가 필요해요”라고 안내하고 바로 진행시킨다.

## 2. 현재 구조에서 흐름이 끊기는 지점

현재 소스의 설정표를 기준으로 확인했다. 이전 문서에는 밭이 일찍 열리던 내용이 남아 있으므로, 밭 Lv.10·광장 농장 구조를 기준으로 한다. 실행 중 에셋과 실제 체감 시간은 별도 플레이 검증이 필요하다.

| 현재 구조 | 플레이 경험의 문제 | 바꿀 방향 |
|---|---|---|
| 첫 모임 이후 작은 집 → 해달 상점 → 목공소 → 채석 작업소 → 농업 창고 | 재료를 많이 쓰는 초반에는 생산 시설이 없고, 중반에 입주·건설이 연속됨 | 목재·돌의 기본 일터를 주거·영토 확장 시점으로 당김 |
| (2026-10-21 QA 뒤) 목공소·채석 작업소는 그 특성 주민 전원이 한 마리당 1시간에 12개를 자동으로 모음. % 보너스는 없어짐 | 생산은 생겼지만 Lv.13~15에야 열리고, 첫 결과까지 오래 걸림 | 기본 일터를 앞당기고, 첫 생산을 빨리 체감하게 함 |
| 개간 기회는 레벨 진행과 연결됨 | 목재를 구하려고 확장해야 하는데, 진행 비용에도 목재가 필요한 상황이 생길 수 있음 | 기본 재료는 개간과 별개로 반복 확보 가능하게 함 |
| 목공소 → 스프링클러, 채석 작업소 → 돌길, 농업 창고 → 흙길 | 돌길을 먼저 열어도 기본 길은 뒤 건물에서 열리는 순서 | 흙길을 먼저 체험하고 돌길은 농장 확장 뒤 개선으로 소개 |
| 메인은 대량 수확·판매·채굴, 시설은 게시판 부탁에서 따로 진행 | 퀘스트를 따라가도 시설의 필요성과 효과를 놓칠 수 있음 | 같은 발전 기록을 메인 목표와 게시판에서 함께 참조 |
| 건설소가 어업 작업소 뒤에 등장 | 이미 많은 공사를 마친 뒤 건설 편의가 옴 | 밭 증설·선착장 공사가 늘어나는 시점으로 이동 |

과거 QA에는 목재 구매만으로 병목을 해결해 개간과 목공소의 의미가 약해졌다는 기록도 있다. 2026-10-21 QA에서 상점 목재 판매는 없앴다(커밋 e2c2d7f).

## 3. 추천 진행 순서

레벨은 배치 목표다. 실제 선행 조건은 완료한 생활 사건과 시설 기록으로 연결한다. 아래 레벨 배치는 기존 메인 경험치·레벨 상한을 함께 재조정해야 하는 변경안이다.

| 구간 | 플레이어가 원하는 것 | 중심 콘텐츠 | 해결 후 다음 목표 |
|---|---|---|---|
| Lv.1~3: 정착 | 살 곳과 첫 수입 | 첫 집 → 의자 → 광산 길 → 깡깡이 배치 | 다른 해달도 함께 살게 하기 |
| Lv.4~5: 이웃 | 해달 초대와 마을 관리 | 요정·첫 무료 응원 동료 → 새 집 → 게시판·또박이 | 더 많은 집을 지을 목재 확보 |
| Lv.6~7: 목재 일터·지도 | 집과 확장에 쓸 나무, 섬 주변 지형 파악 | 기존 첫 개간 체험 → 지도 해달 회관 합류·첫 정찰 → 꾸벅이·쿵쿵이 정착 → 생산 구역 → 목공소 | 새 집 건설과 지도에 표시된 확장 방향 선택 |
| Lv.8~9: 돌 일터·확장 | 늘어나는 건축에 쓸 돌, 다음 생활 터전 | 정찰한 땅 개간 → 데굴이·채석 작업소 → 새 이웃. 남쪽 정찰 시 낚시터 발견·경로 표시 | 농경지 확보, 바닷길 개간을 장기 목표로 제시 |
| Lv.10: 자급 | 해달들이 먹을 작물 | 농업 구역 → 밭 3칸·수확 상자 → 새싹이 → 첫 수확·첫 모임 | 밭을 더 편하게 운영 |
| Lv.11: 보관과 운반 | 상자를 덜 자주 비우고 이동 줄이기 | 보들이 정착 → 농업 창고 → 큰 상자·흙길 사용 | 여유가 생긴 농장 증설 |
| Lv.12: 장사 | 남는 작물을 생활비로 바꾸기 | 짤랑이 정착 → 해달 상점 → 첫 작물 판매 목표 | 수입으로 농장 설비 개선 |
| Lv.13: 농장 설계 | 넓어진 밭을 효율적으로 돌리기 | 목공소 설비 확장 → 스프링클러 / 채석 작업소 정비 → 돌길 | 자동 운반과 큰 공사 준비 |
| Lv.14: 건설과 자동 수거 | 잦은 공사·상자 수거 부담 줄이기 | 콩콩이 정착 → 건설소 → 수레·밭 공사 단축 체험 | 선착장 복구 |
| Lv.15~16: 바다 | 발견해 둔 낚시터에서 새로운 생산과 수집 | 남쪽 진입로 확보 → 선착장 복구 → 첨벙이 → 첫 낚시 → 퐁당이·어업 작업소 | 물고기 수집·바다 관련 의뢰 |
| Lv.17 이후: 왕국 | 마을 전체를 발전시키기 | 끄적이·기록관 → 주민·구역 정비 → 성 → 황금 흙 | 장기 수집과 다음 지역 준비 |

기존 광산 미로·길드 사건은 이 흐름 사이에 유지한다. 광산은 광석·탐험, 채석 작업소는 건설용 돌 확보로 역할을 나눈다. 목공소와 채석 작업소를 먼저 짓게 한다고 광산 탐험 보상을 함께 앞당기지는 않는다.

## 4. 목공소·채석 작업소의 역할

### 목공소: 건설을 이어갈 기본 목재 공급

현재 개간 보너스만으로는 ‘나무 부족 해결’이라는 부탁과 실제 보상의 차이가 크다. **시설에서 반복 목재 작업을 시작하고 받을 수 있게 하는 것**을 추천한다. 별도 숲 씬이나 원목·판자 같은 새 재료는 우선 추가하지 않는다.

- 입문: 광장 나뭇가지·나무로 첫 집과 목공소 준비 비용을 확보한다.
- 기본 작업: 목공소 완공 뒤 정착한 나무 특성 해달 1명을 보내 목재를 얻는다. 작업비로 목재·돌·개간 기회를 요구하지 않는다.
- 확장: 영토 개간은 새 땅과 목재를 함께 얻는 큰 보상으로 유지한다. 기존 개간 목재 +20%도 유지 후보다.
- 중반 재방문: 농장이 커지면 목공소의 설비 확장 부탁으로 스프링클러를 연다. 건물만 일찍 지었다고 농사 전부터 설비를 소개하지 않는다.

### 채석 작업소: 광산 탐험과 다른 건축 재료 공급

- 입문: 광장 바위와 기존 광산으로 시설 준비용 돌을 얻는다.
- 기본 작업: 채굴 특성 주민 1명을 보내 건설용 돌을 반복 확보한다. 광석·보석은 여기서 생산하지 않는다.
- 기존 돌 +20%는 부가 보너스로 두되, 반복 작업에 적용할지는 수급표에서 한 번만 계산한다.
- 중반 재방문: 농업 창고에서 흙길을 쓰고 난 뒤, 작업소 정비 부탁으로 돌길을 연다.

현재 코드(2026-10-21)는 **특성 주민 전원이 자동으로** 모으는 방식이다(`SettlementManager.Production`, 오프라인 최대 8시간). 위의 ‘1명을 보내는 작업’은 그와 다른 방식이라, 2차 전에 어느 쪽으로 갈지 정해야 한다.

### 주민·작업 배치 규칙

기존의 특성 주민 2명 조건을 유지하되 꾸벅이·쿵쿵이·데굴이의 이야기 방문을 앞당긴다. 장난감 방문은 제거하고 주민별 생활 진행 조건으로 확정 등장시킨다. 가챠 응원 동료는 주민 특성 수와 별개로 관리한다.

특성 2명은 시설 건설 자격이고, 실제 작업에는 그중 1명이 필요하다. 특성 인원수와 배치 인원수를 구분해 표시한다. 동일 해달을 광산과 채석 작업소에 동시에 배치하지 않는다. 깡깡이를 광산에 둔 채 데굴이가 채석을 맡을 수 있게 한다.

## 5. ‘부족함 → 해결’을 체험시키는 퀘스트 예시

### 첫 목공소

1. 새 집의 필요 재료를 미리 보여 준다. “집을 더 지으려면 나무가 꾸준히 필요해요.”
2. 꾸벅이가 목공소를 제안하고 쿵쿵이의 방문·입주를 안내한다.
3. 생산 구역 지정과 목공소 부지 선택으로 연결한다. 부지가 모자라면 먼저 확장 또는 재배치를 안내한다.
4. 목공소를 완공한다. 여기서 메인 이야기를 끝내지 않는다.
5. 첫 목재 작업을 맡기고 결과물을 받는다.
6. 받은 목재가 새 집 준비에 보태지는 모습을 보여 준 뒤 다음 집 건설을 안내한다.

자원을 이미 가진 플레이어도 1단계가 완료된다. 소비를 강제해 부족 상태를 만들지 않는다.

### 농업 창고와 길

1. 밭을 3칸 운영하고 수확물을 상자에서 한 번 받는다.
2. 농부가 작물을 나르는 모습을 보여 주며 “밭이 늘면 상자도 길도 필요해요”라는 부탁을 연다.
3. 보들이 정착 → 농업 창고 → 상자 용량 증가를 확인한다.
4. 밭과 상자 사이에 흙길을 놓고 농부가 이동하는 것을 본다.
5. 밭 증설 이후 스프링클러와 돌길 개선을 소개한다.

긴 길을 일부러 만들거나 상자를 반드시 가득 채울 필요는 없다. 효율적인 배치로 이미 해결했다면 해당 목표를 인정하고 넘어간다.

## 6. 안내와 퀘스트 운영 규칙

- 상단의 대표 목표는 하나다. 예: `다음 이웃의 집 준비 · 목재 18/30 · [목공소로]`.
- 게시판 부탁과 메인 퀘스트는 같은 완료 기록을 본다. 서로 별개의 공사를 두 번 요구하지 않는다.
- 시설 소개는 `왜 필요함 → 무엇을 하면 됨 → 완성 뒤 가능한 행동` 순서로 쓴다.
- 완공 창에는 수치보다 새 행동을 먼저 쓴다. 예: `목재 작업을 맡길 수 있어요!` 다음 줄에 `숲 개간 목재 +20%`.
- 시설 완공 다음에는 첫 생산·길 놓기·수레 수거 등 새 기능을 한 번 쓰는 목표를 둔다.
- 완료 기록·보유 상태로 판단 가능한 목표는 미리 달성해도 인정한다. 동작 이벤트만 기다려 다시 구매·강화하게 만들지 않는다.
- 대량 수확·판매 누적 목표는 도전으로 옮기는 것을 우선 검토한다. 메인은 새 기능을 이해하는 데 필요한 소량 체험과 실제 다음 공사 준비에 집중한다.
- 기다리는 동안은 광산 탐험·수확·꾸미기 등 이미 열린 선택 활동을 안내한다. 할 일이 없는 상태에서 여러 집과 시설 공사만 연속으로 기다리게 하지 않는다.

## 7. 비용과 막힘 방지 기준

확정 비용표를 먼저 만들기보다, 시설이 다음 목표를 실제로 해결하는지부터 맞춘다. 아래는 첫 플레이테스트용 가설이다.

- 첫 작업은 1~2분 안에 결과를 확인하고, 다음 집 준비에 의미 있게 보탠다.
- 기본 작업 1회 수급량은 ‘다음 필수 공사의 재료 부족분 ÷ 목표 반복 횟수’로 산정한다. 첫 필수 공사 준비는 2~3회 작업을 출발점으로 검증한다.
- 작업 시간이 길어지는 후속 단계는 접속 간격과 함께 조정한다. 오프라인에는 저장 한도까지 생산하고 가방이 차면 보관·수령 대기로 남긴다.
- 처음 목공소·채석 작업소는 기존 Lv.12~14 비용을 그대로 앞당기지 않는다. 시작 자원·줍기·광산·이전 보상만으로 지을 수 있는 비용을 다시 산정한다.
- 생산 시설을 짓기 위해 그 시설에서만 나오는 자원을 요구하지 않는다. 시설 입주용 집 비용도 준비 경로에 포함한다.
- 상점 목재 판매는 2026-10-21 QA에서 없앴다. 다시 넣는다면 기본 생산을 열기 전의 필수 해법으로 삼지 않는다.
- 레벨 상한, 정찰·개간 조건, 생산 구역, 주거 부지의 선행 조건을 함께 검사한다. 기존 레벨별 개간 기회와 정찰을 이중 제한으로 두지 않는 방향은 11장을 따른다. 특히 `목공소 → 목재 → 레벨 상승 → 목공소 해금` 같은 순환을 금지한다.
- 정착 인원·시설·부지 요건은 충족했는데 경험치만 모자라 같은 행동을 오래 반복한다면 메인 경험치를 다시 배분한다.

## 8. 적용 범위와 순서

### 1차: 기존 기능을 활용한 진행 정리

새로운 생산 기능 개발 전에 효과를 확인할 수 있는 범위다. 전체 추천안의 중간 단계이며 목재 공급 문제까지 해결하는 범위는 아니다.

> **2026-10-21 적용함.** Lv.10~15 메인 체인의 각 레벨 끝이 다음 레벨로 올리는 시설 부탁(살 집 → 일터)이 되고, 시설 다음 레벨은 첫 생산·스프링클러·흙길·돌길 사용으로 시작한다. 농업 창고(흙길, →Lv.14)를 채석 작업소(돌길, →Lv.15)보다 먼저 짓도록 순서를 바꿨다. 판매 1만~8만·광석 200·400·작물 300·1,500 메인은 도전으로 옮겼다. 완공 문구는 새 행동 → 효과 → 찾아온 해달 순서로 고쳤다. 상세는 `Docs/레벨별_메인퀘스트.md` 2장, `Docs/특성사회성장_P4_기획반영.md` 9장.

1. 현재 Lv.10~15 시설 부탁을 메인 퀘스트와 연결한다.
2. 농업 창고·흙길 체험을 돌길 소개보다 앞에 둔다. 목공소·채석 작업소의 농장 설비도 각각 첫 사용까지 안내한다.
3. 긴 누적 목표를 줄이고 새 기능 체험으로 바꾼다. 기존 경험치 총량·상한과 같이 조정한다.
4. 안내 띠·부탁·완공 창에서 이유와 다음 행동을 같은 문구로 연결한다.

### 2차: 추천 진행표 적용

1. 목공소·채석 작업소 반복 작업과 보관·오프라인·주민 배치를 구현한다.
2. 관련 입주 이야기와 기본 일터를 Lv.6~9로 이동한다. 기존 ‘첫 모임 이후 P4 시작’ 선행 조건을 해체한다.
3. 생산 구역 해금, 작은 집 자격, 주거 부지, 건설 비용을 함께 앞당긴다.
4. 스프링클러·돌길은 별도 설비 확장 완료 조건으로 바꿔 농사 이후에 연다.
5. 상점·건설소·기록관·성의 레벨 및 이야기 선행 조건을 새 표에 맞춘다.
6. 새 게임부터 바다까지 플레이하고 자원·경험치·대기시간을 조정한다.

기존 세이브는 건물·주민·완료 기록을 유지한다. 이미 가진 기능은 다시 잠그지 않고, 새 체험 목표는 기록으로 충족 처리하거나 안내만 한다. 기존 시설 ID를 유지해 건물을 중복 지급하지 않는다.

## 10. 기획 검증 기준

성공 기준은 ‘모든 건물을 순서대로 지었는가’보다 ‘짓는 이유와 바뀐 생활이 연결되는가’다.

- 처음 플레이하는 사람이 다음 시설의 필요성을 자기 말로 설명할 수 있다.
- 시설 완공 후 새 기능을 한 번 사용하고 다음 목표로 이어진다.
- 목재·돌 부족은 이미 열린 반복 활동으로 해결할 수 있다.
- 광산을 계속 쓰면서 채석 작업소도 쓰일 이유가 있다.
- 흙길 → 돌길, 직접 상자 수거 → 수레 순서가 실제 체감으로 구분된다.
- 최적 배치·사전 수집·사전 방문을 한 플레이어도 목표가 막히지 않는다.
- 필수 주민의 무작위 방문·가챠 획득이나 상점 구매만 기다리는 구간이 없다.
- 레벨별 재료 수지에는 집·입주·구역 확장·시설·첫 설비 비용을 모두 포함한다.

플레이테스트에서는 단계별 진입·완료 시각, 재료 부족으로 멈춘 시간, 시설 첫 사용 시점, 대표 목표 없이 보낸 시간을 기록한다. 수치는 이 결과를 보고 확정한다.

## 11. 지도 해달과 정찰대 — 섬을 알아가며 확장하기

### 11.1 사용자 방향과 역할

사용자 방향은 지도 해달을 갱도 전용 안내에서 섬 확장의 안내자로 넓히는 것이다. 지도 해달 등장 후 마을회관에서 또박이와 함께 일한다. 섬 지도에 필요한 정보를 정착 주민의 정찰대로 모으고, 정찰 중인 주민은 길드 주변 쓸기·숲 개간 등 다른 작업을 할 수 없다.

| 담당 | 회관에서 하는 일 |
|---|---|
| 또박이 | 부탁·주민 작업 접수, 정찰대 명단과 출발·귀환 관리 |
| 지도 해달 | 갱도 지도 정리, 섬 정찰 방향 제안, 보고받은 지형·자원·시설을 지도에 기록 |
| 정찰대 | 아직 모르는 방향을 다녀와 지형과 장소를 발견 |

지도 해달은 기존 갱도 탐험 조건으로 등장한다. 섬 지도를 위해 다시 횟수를 채우거나 새 지도 해달을 뽑지 않는다. 먼저 등장했는데 회관 운영이 아직이면 등장 기록을 유지하고 회관이 준비될 때 합류한다. 반대 순서라면 등장 직후 합류한다.

기존 광산 문서의 ‘지도 해달 = 끄적이’는 제안으로 남아 있다. 이번 규칙은 그 이름 확정 여부와 무관하게 기존 지도 해달의 해금 기록을 재사용한다. 정체를 끄적이로 확정한다면 뒤의 기록관 이야기는 재등장이 아니라 기존 주민의 새 일터로 바꾼다.

갱도에서 지도 해달이 실제 동행한다는 기존 설명은 회관 근무와 함께 정리해야 한다. 첫 구현 권장은 **기존 갱도 지도 기능은 계속 사용하고, 회관의 지도 담당이 탐험 기록을 정리한다**는 설명이다. 광장과 갱도에 동일 NPC가 동시에 실체로 나타나는 연출은 피한다. 현장 동행을 유지한다면 회관의 모습만 부재 처리하되 섬 지도 열람·정찰 접수는 또박이가 계속 맡는다.

### 11.2 확장 순환

`갱도에서 지도 도움을 받음 → 회관에 지도 담당 자리 마련 → 섬 지도를 그리고 싶다는 부탁 → 정착 주민으로 정찰대 편성 → 방향 선택·출발 → 귀환·발견 기록 → 해당 방향 개간 → 새 땅·생활 기능 사용 → 다음 정찰`

핵심은 **정찰이 지도와 목적지를 넓히고, 개간이 실제 이용 가능한 마을을 넓히는 것**이다. 정찰만으로 건물 부지·농경지·낚시가 즉시 열리지는 않는다.

| 지역 상태 | 지도 표현 | 할 수 있는 일 |
|---|---|---|
| 미탐사 | 안개와 방향명 | 현재 접근 가능한 경계에 정찰대 보내기 |
| 정찰 중 | 정찰대 얼굴·남은 시간 | 마을의 다른 활동, 정찰 상황 확인 |
| 발견 | 지형·자원·장소 아이콘, 막힌 진입로 | 경로와 개간 필요 재료 확인, 개간 시작 |
| 진입로 개간 중 | 개간 구간·주민·남은 시간 | 단계별 길 열기 |
| 접근 가능 | 열린 길과 도착점 | 구역 지정·시설 복구 등 장소별 다음 행동 |
| 운영 중 | 시설과 생산 표시 | 농사·낚시·건축 등 실제 콘텐츠 사용 |

첫 버전은 현재 지도와 구역 블록 위에 안개·발견 아이콘·길 표시를 얹는다. 무작위 섬이나 별도의 거대한 탐험 맵을 새로 만들 필요는 없다. 갈 수 없는 땅을 발견해도 카메라로 확인할 수 있을 뿐, 배치 가능 격자나 주민 이동 영역은 개간 전까지 확장하지 않는다.

### 11.3 첫 섬 지도 이야기

지도 해달의 부탁 예시:

> 갱도 길은 조금씩 알게 됐어요. 그런데 우리가 사는 섬은 아직 모르는 곳이 많네요. 마을 친구들이 주변을 살펴봐 주면, 제가 섬의 지도를 그릴 수 있을 것 같아요!

1. 마을회관에서 지도 해달을 만나 섬 지도 탭을 연다.
2. 이미 사는 주민 중 1명을 골라 가까운 방향을 정찰한다.
3. 출발 전 `정찰 중에는 주변 쓸기·개간 등 다른 일을 맡길 수 없어요`와 예상 시간을 보여 준다.
4. 첫 귀환 때 지도의 한 구간에서 안개가 걷히고 쓸 만한 숲·공터가 표시된다.
5. `숲 너머에 넓은 공터가 있어요. 길을 내면 집과 일터를 더 지을 수 있겠어요!`로 해당 구간 개간을 안내한다.
6. 그 땅을 실제로 쓰면 다음 방향 정찰을 소개한다.

첫 정찰은 1명·60~90초·재료 비용 없음으로 체험시키는 가안이다. 후속은 1~2명과 더 긴 시간을 검토하되, 첫 버전 동시 정찰대는 1개로 시작한다. 아직 충분한 주민이 없는 구간에 2명을 필수로 요구하지 않는다.

### 11.4 정찰대 편성·작업 배타 규칙

- 마을에 **정착한 주민만** 가능하다. 방문객·입주 대기 해달·가챠 응원 동료는 명단에 넣지 않는다.
- 한 주민은 같은 시간에 정찰·개간·주변 쓸기·생산 작업 중 하나만 수행한다. 정찰은 기존 주민 작업과 같은 배정 검사를 거친다.
- 이미 작업 중인 주민은 이유와 함께 선택 불가로 표시한다. 기존 작업을 조용히 취소하거나 중복 배치하지 않는다.
- 광부·농부·건설·회관 담당처럼 역할을 맡은 주민은 ‘한가한 일반 주민’과 구분한다. 기존 역할이 유지된 채 몰래 정찰에 참여하지 않게 한다. 첫 버전은 역할 배정 해제 후 편성하도록 한다.
- 또박이·지도 해달은 회관의 고정 담당으로 정찰 후보에서 제외한다. 정찰을 갔다고 접수와 지도가 함께 사라지지 않게 한다.
- 탐험 특성이 없는 주민도 첫 정찰을 할 수 있다. 특정 해달·가챠 결과가 없어서 정찰이 막히지 않는다. 특성별 시간 보너스는 후속 검토한다.
- 정찰 중에도 주민 수·보유 특성 수·집 배정은 유지한다. 마을을 떠나거나 퇴거한 상태로 처리하지 않는다.
- 귀환 시점에 작업 점유를 자동 해제한다. 보고서를 열지 않았다는 이유로 주민을 계속 묶지 않는다. 발견 내용은 자동 기록하고 새 보고 알림은 남긴다.
- 앱을 꺼도 종료 시각까지 정찰이 진행된다. 재접속 때 발견·귀환·주민 복귀가 한 번만 처리되게 한다.
- 첫 버전은 실패·부상·주민 상실 없이 확정 귀환한다. 실패 재도전을 주요 진행에 넣지 않는다.
- 회수는 가능하게 하되 발견 결과 없이 종료한다. 같은 방향 재출발은 처음부터이며, 취소로 정찰 완료나 보상을 중복 얻지 못한다.

정찰대 전체가 마을 밖으로 나가는 경우에도 시간 경과로 귀환할 수 있으므로 막다른 진행은 아니다. 다만 출발 화면에 `남는 일반 작업 주민 0명`을 표시해 생산·개간 대기 여부를 판단하게 한다. 진행에 필수인 전문 역할을 자동 해제하지 않는다.

### 11.5 낚시터 발견 → 남쪽 길 → 선착장

낚시터 발견은 시간만 지나면 뜨는 알림보다 **남쪽 정찰의 확정 발견 결과**로 둔다.

> 남쪽 숲 너머에서 잔잔한 바닷가를 찾았어요! 물고기가 많이 보이고, 낡은 선착장도 남아 있어요. 숲길을 정리하면 마을에서도 갈 수 있겠어요.

1. 남쪽 정찰 귀환 → 지도에 낚시터·낡은 선착장 표시.
2. 회관의 다음 목표는 `발견한 바닷가로 길 내기`가 된다.
3. 지도에서 [길 확인]을 누르면 남쪽 개간 경로와 현재 단계가 강조된다.
4. 정찰한 인원은 돌아온 뒤 같은 길 개간에 배치할 수 있다. 정찰과 개간의 동시 배정은 불가하다.
5. 길을 확보하면 선착장 복구 부탁으로 이어진다.
6. 복구 → 첨벙이 안내·배치 → 첫 낚시 → 퐁당이·어업 작업소 이야기로 연결한다.

Lv.8~9에 남쪽을 정찰해 미리 목표를 발견하고, 준비를 거쳐 Lv.15 전후 낚시를 시작하는 배치를 가설로 둔다. 발견 즉시 한참 잠긴 레벨 숫자만 보여 주지 않고, 지금 할 수 있는 진입로 준비를 안내해야 한다. 길까지 완성했는데 레벨만 부족해 오래 기다린다면 선착장 해금 시점·경험치를 함께 조정한다.

낚시를 안내하는 메인에 도달했는데 아직 남쪽을 정찰하지 않았다면 `남쪽 바닷바람을 따라` 정찰 부탁을 우선 제시한다. 다른 방향을 먼저 선택했다고 확장 기회가 바닥나 다음 레벨까지 막히지 않아야 한다.

남쪽 단계별 개간은 낚시터까지 이어지는 경로만 요구한다. 낚시를 위해 무관한 다른 방향이나 섬 전체를 개간시키지 않는다. 최종 선착장 수리비는 목공소·채석 작업소의 생산을 활용하는 목표로 연결한다.

### 11.6 정찰과 레벨·기존 개간 기회의 관계

현재 확장은 레벨별 개간 기회와 연결되어 있다. 여기에 정찰을 그대로 더하면 `정찰 대기 → 개간 기회 부족 → 레벨 대기 → 개간 대기`가 겹칠 수 있다.

추천은 **정찰 완료와 경로 준비를 개간의 선행 조건으로 삼고, 레벨마다 주는 소모성 개간 기회는 새 흐름에서 정리하는 것**이다. 다음 깊이의 정찰은 이전 지역의 활용·마을 발전으로 연다. 기본 노동력·시간·재료는 개간 비용으로 유지한다. 레벨은 단계 표시와 다른 콘텐츠 안내에 사용한다.

- 이미 가까운 땅을 여는 기존 첫 개간 튜토리얼은 유지할 수 있다. 이후 ‘주변을 보니 더 넓은 섬을 조사할 필요가 생김’으로 지도 이야기와 연결한다.
- 그 뒤부터 새로운 미탐사 구역은 정찰 → 개간 순서를 따른다. 첫 개간을 위해 지도 해달을 기다리게 하지 않는다.
- 농경지·생산 구역처럼 필수 땅을 확보할 경로는 선택 순서와 무관하게 남긴다. 초반 정찰에 희소 소모권을 쓰지 않는다.
- 후속 정찰의 주민·비용 조건이 그 정찰로만 얻는 주민·땅·자원을 요구하지 않는지 검사한다.
- 주민 노동력은 정찰과 개간 사이에서 선택하지만, 마을의 기본 목재·돌 공급은 레벨 상승에만 의존하지 않게 한다.

### 11.7 UI·구현 경계·검증

마을회관에 `부탁 / 주민 작업 / 섬 지도`를 둔다. 또박이가 접수하고 지도 해달이 지도 탭을 담당하는 구성이며, 별도 지도 제작소 건물은 우선 추가하지 않는다.

정찰 출발 화면은 방향·발견 힌트·정착 주민 후보·다른 작업 상태·예상 시간·남는 노동력을 보여 준다. 귀환 보고에는 발견한 장소와 [해당 방향 보기]를 제공한다. 필수 목표 하나를 대표 안내로 두고 다른 방향 선택은 지도에서 유지한다.

현재 `Settlement`의 주민 작업은 작업별 배정 해달과 종료 시각을 저장하고, 같은 주민의 중복 작업을 검사한다. 정찰은 이 점유 구조를 재사용하는 것을 우선 검토한다. 다만 전문 역할과 회관 배치까지 같은 검사로 막히는지는 별도 점검이 필요하다. 기존 코드에 정찰이 이미 구현된 것으로 취급하지 않는다.

구현 순서는 지도 해달 해금·회관 합류 기록 연결 → 섬 지역 발견 상태 → 정찰 작업·저장·복귀 → 개간 조건 연결 → 남쪽 낚시터 보고·경로 안내 → 레벨·비용 재조정으로 잡는다. 새로운 행군·탐사 리깅 대신 회관에서 출발해 지도 위 표시로 진행하고 귀환 보고로 마무리한다.

기존 세이브의 열린 지역·진행 중 개간·낚시터는 그대로 유지하고 필요한 정찰·발견 기록을 충족 처리한다. 이미 지도 해달을 얻은 세이브도 재탐험을 요구하지 않는다. 남은 개간 기회의 처리 정책은 기존 저장 수치와 실제 사용자 범위를 확인한 뒤 확정하며, 전환에서 조용히 소모하지 않는다.

검증할 시나리오:

- 작업 중인 주민을 정찰에, 정찰 중인 주민을 쓸기·개간에 중복 배정할 수 없는가.
- 정찰 중에도 주민 수·특성·집·이미 해금한 건물이 유지되는가.
- 귀환 보고 미확인·오프라인 복귀·재접속 때 주민이 정상 복귀하고 결과가 한 번만 기록되는가.
- 지도 해달과 회관이 어느 순서로 준비돼도 합류하는가.
- 북쪽을 먼저 정찰해도 농경지·남쪽 낚시 진행이 막히지 않는가.
- 발견한 땅은 개간 전까지 건축·이동에 사용할 수 없는가.
- 남쪽 보고에서 실제 남쪽 개간과 선착장 복구까지 다음 행동이 이어지는가.
- 기존 확장·낚시·지도 진행 세이브에 새 잠금이 생기지 않는가.
