# 해달 캐릭터 리깅 작업기록 (농부 시트 + 바리에이션 + 새 정면 일러스트 4종)

작성일: 2026-10-03
문서 성격: 클로드 작업 세션 기록. 다음에 Unity 리그(OtterRigSetup)에 연결할 때 참고용.

## 1. 요청 배경

기존 프레임 애니메이션 시트(`FarmerOtter_Sheet.png`)는 활용도가 낮아서 본 리깅으로 바꾸고, 다른 캐릭터도 같은 리그/애니메이션을 쓰게 할 계획.
이전 시도(RigParts A/B)는 AI로 새로 그린 파츠 시트라 원본과 그림체가 달랐음. 이번에는 **원본 시트 프레임에서 직접 파츠를 잘라** 그림체를 그대로 유지함.

## 2. 사용한 프레임

`Assets/Sprites/Characters/FarmerOtter/FarmerOtter_Sheet.png` (8x5, 칸 416x240)

| 시점 | 행/열 | 비고 |
|---|---|---|
| 정면 | 3행 7번째 (row 2, col 6) | 오른쪽 다리는 왼쪽 다리를 좌우 반전해서 사용 |
| 측면(오른쪽) | 1행 8번째 (row 0, col 7) | 뒷팔/뒷다리는 앞팔/앞다리를 어둡게 복사. 왼쪽 = 좌우 반전 |
| 뒷모습 | 4행 1번째 (row 3, col 0) | 분홍 타원은 **꼬리**(뒤에서 본 납작한 꼬리). 왼쪽 다리가 꼬리에 가려져서 오른쪽 다리 반전 사용 |

## 3. 분리 방식 (`Tools/SheetRig/cut_parts.py`)

1. 2배 업스케일 후, 검은 외곽선으로 둘러싸인 영역을 라벨링 → 시드 좌표로 파츠에 배정. 한 영역이 여러 파츠에 걸치면(멜빵 = 몸통+다리, 측면 팔 외곽선 끊김 등) 폴리곤으로 강제 분할.
2. 외곽선 픽셀은 가까운 파츠 중 **위에 그려지는 파츠**에 배정 (팔 외곽선은 팔, 턱선은 머리).
3. 가려져 있던 부분을 새로 칠함:
   - 팔 밑 몸통, 머리 밑 목/셔츠: 주변 색(멜빵 초록/셔츠 흰색 영역 지정) + 새 외곽선
   - 다리 윗부분: 단면을 위로 늘린 뒤 둥근 캡슐 모양으로 잘라서 회전해도 몸통 밖으로 안 튀어나오게
   - 측면 꼬리 뿌리: 몸통 밑으로 이어지게 칠함
   - 뒷모습 몸통의 꼬리 가린 부분: 반대쪽을 좌우 대칭 복사
   - 측면 가랑이 외곽선: 다리를 벌렸을 때 보이도록 추가
4. 원본이 흰 배경 위에서 추출된 거라 반투명 테두리가 흰 후광 → 외곽선 색으로 교체 (파츠가 겹칠 때 흰 줄 안 보이게).

## 4. 산출물 (`ArtSource/Otter/SheetRig/`)

캐릭터별 폴더 `FarmerOtter/`, `ChiefOtter/`, `MinerOtter/`, `FishingOtter/` (8절)에 각각:
- `parts/{View}_{Part}.png` — 파츠 22개 (정면 6 / 측면 9 / 뒷모습 7), 원본 2배 해상도
- `{Prefix}_SheetRigParts.png` — 위 파츠를 한 장에 패킹한 아틀라스 (1024 폭)
- `rig_layout.json` — 파츠별 아틀라스 rect(Unity 좌하단 기준), 피벗(정규화, = 관절 위치), 부모 본, 정렬 순서, 발 중심(Root) 기준 관절 위치. `bones`에 스프라이트 없는 본(측면 Hip)까지 전체 계층
- `parts_overview.png` — 파츠 한눈에 보기 (노란 점 = 피벗)

루트에:
- `cast_lineup.png` — 4명 정면/측면/뒷모습 한 장
- `otter_cast_demo.mp4` — 캐릭터 4종 시연 영상 (8절)
- `otter_rig_demo.mp4` — 농부 리그 시연 영상 (파츠 분해/조립 → 본 구조 + Idle → 4방향 Walk → 측면 양발 교차 걷기 → 밭 자유 이동 → 색 변형 캐릭터)

본 구조: `Root(발 중심) → Body → Head / Arm_* / Tail(측면은 3마디)`. 정면/뒷모습은 `Root → Leg_*` (다리는 몸통 흔들림과 무관하게 땅에 붙어 있도록 Root 자식), 측면은 `Root → Hip → Body / Leg_Near → Foot_Near / Leg_Far → Foot_Far` (3차 수정에서 발 분리).

## 6. 2차 수정 — 측면 걷기 / 선 마감

피드백: 앞뒤 이동은 좋은데 양옆 이동이 절뚝거림, 선 마감이 덜 된 느낌.

- **절뚝거린 원인**: 원본 측면 프레임이 다리를 벌린 채로 그려져 있어서, 두 다리가 서로 다른 고관절(41px 떨어짐)에서 각자 흔들리기만 하고 교차하지 않았음.
- **측면 다리 재구성**:
  - 앞다리 하나만 잘라서 쓰고, 뒷다리는 그 복사본을 어둡게 만든 것. 두 다리를 거의 같은 고관절(x 203 / 214)에 매달아서 걸을 때 교차함.
  - 다리 윗부분은 둥근 캡슐 모양이라 회전해도 몸통 밖으로 안 나옴. 몸통 아래는 둥근 엉덩이 곡선으로 다시 그림.
- **보행 사이클** (`anim.side_walk`):
  - 디딤(사이클 앞 절반): 발이 일정 속도로 뒤로 이동. 캐릭터가 `SIDE_SPEED`로 움직이면 디딘 발이 미끄러지지 않음.
  - 스윙(뒤 절반): 발을 8px 들어서 앞으로 보냄.
  - 골반: 새 `Hip` 본이 몸통과 두 다리를 묶음. 디딘 다리 각도만큼 내려가서 발이 땅에서 안 뜸.
  - 팔은 같은 쪽 다리와 반대로 흔들리고, 머리와 꼬리는 골반 출렁임을 살짝 늦게 따라감.
- **선 마감** (`cut_parts.ink`):
  - 파츠마다 실루엣을 살짝 매끈하게 다듬고 같은 굵기(1x 기준 3.2px)의 외곽선을 다시 그림. 4배 슈퍼샘플링으로 안티앨리어싱. 자른 경계에도 외곽선이 생겨서 끊긴 선, 각진 모서리, 들쭉날쭉한 굵기가 없어짐.
  - 예외: 정면/뒷모습 몸통의 아래 경계(다리와 이어지는 부분)는 일부러 외곽선 없이 둠.
  - 파츠 사이에 남은 작은 구멍은 주변 색으로 채움.
  - 원본이 업스케일이라 흐려서 안쪽 선(눈, 모자 띠)에 약한 선명화를 적용함. 영역 분할은 선명화 전 이미지로 함.
- 시연 영상에 "측면 걷기 — 양발 교차" 구간을 추가함 (화면을 가로지르는 걷기 + 0.35배 슬로 모션). 바닥 점선은 발 고정 기준.

## 7. 3차 수정 — 둥근 선 / 마리오식 측면 다리

피드백: 선을 더 동글동글하게, 옆모습 다리는 뉴슈퍼마리오2처럼 더 자연스럽게.

- **둥근 선** (`cut_parts.ink`, `ROUND_SIGMA = 6`):
  - 실루엣을 4배 해상도에서 가우시안 블러 후 다시 이진화함(곡률 스무딩). 모서리는 원호가 되고, 작은 돌기/패임(뺨 털 지그재그, 팔 모서리)은 녹아서 매끈한 곡선이 됨.
  - 그 위에 같은 굵기 외곽선을 다시 그림. 둥글리면서 새로 덮이는 픽셀은 가장 가까운 색으로 채움.
  - 파츠 안쪽 원본 선(모자 띠, 눈)은 손대지 않음.
- **측면 다리 = 바지 통 + 발**:
  - 발(`Foot_Near`)을 따로 잘라서 발목(바지 밑단 아래, y 207)에 관절을 둠. 발 윗부분은 밑단 속에 숨는 부분까지 칠해서 발이 돌아가도 빈틈이 없음.
  - 고관절을 y 186으로 올림(바지 길이 21px). 바지 위쪽 캡슐도 거기에 맞춤.
  - 뒷다리/뒷발은 앞쪽 복사본을 0.72배로 어둡게 해서 겹쳐도 구분됨.
- **걷기** (`anim.side_foot / side_legs / side_walk`):
  - 디딤: 뒤꿈치로 착지(발끝 12° 들림) → 발바닥이 평평해짐 → 뒤꿈치가 들리며 발끝으로 밀어냄(-26°). 발은 접지점을 중심으로 굴러서 땅에서 미끄러지지 않음.
  - 스윙: 발끝이 아래를 향한 채 뒤로 살짝 차 올렸다가(뒤로 5px, 위로 9px) 앞으로 뻗으며 발끝을 들고 착지 준비.
  - 다리: 발목 목표 위치로 바지 통을 회전시키고, 거리가 남으면 통을 몸속으로 밀어 넣음(무릎 굽힘처럼 보임). 손이 안 닿으면 골반이 더 내려감.
  - 골반: 착지 직후 가장 낮고(2.2px), 다리가 지나갈 때 가장 높음. 착지 때 몸통이 살짝 눌림.
  - 팔은 ±32°로 크게 흔들고, 몸통은 4° 앞으로 기울임. 머리와 꼬리는 출렁임을 늦게 따라감.
  - 한 사이클 0.56초, 미끄러지지 않는 이동 속도 `SIDE_SPEED` = 114px/s(1x).
- Unity로 옮길 때: 발은 다리 본의 자식이고 회전만 씀(다리 본에 스케일 없음). 그래서 SpriteSkin에서 찌그러짐 없이 그대로 재현 가능.

## 8. 캐릭터 바리에이션 — 촌장 / 광부 / 낚시 해달

요청: 얼굴을 약간씩 바꿔서 촌장·광부·낚시 해달을 같은 방식으로 만들기. 바리에이션이 있어도 귀여워야 함.

- **방식** (`variants.py`): 농부 파츠를 그대로 복사해서 다시 칠함. 캔버스·본·피벗이 같아서 리그와 애니메이션을 그대로 공유함. 파츠 이름과 개수(22개)도 같음.
  - 모자: 짚/띠/챙 영역만 색을 바꾸고 명암은 유지. 띠는 결이 지저분해서 평평한 리본으로 다시 칠하고 챙 위 외곽선을 새로 그림. 모자 꼭대기 짚 술은 잘라내고 외곽선을 다시 땀.
  - 옷: 멜빵(초록 + 밑단 하이라이트), 신발 색 변경. 낚시꾼은 셔츠에 줄무늬.
  - 얼굴: 농부의 반쯤 감긴 눈은 주변 털색으로 지우고 새 눈을 그림. 볼터치, 코, 동글동글한 외곽선은 유지함.
- **색 기준**: 기존 `MinerOtter` / `FishingOtter` 스프라이트(노란 안전모 + 청멜빵, 올리브 버킷햇 + 줄무늬 셔츠)를 따름. 촌장은 새로 디자인함.

| 캐릭터 | 모자 | 옷 | 얼굴 |
|---|---|---|---|
| 촌장 (`ChiefOtter`) | 진갈색 펠트 + 금색 띠 + 잎사귀 | 와인색 멜빵 + 금색 나비넥타이, 검은 신발 | 웃는 눈(∩), 금테 동그란 안경, 몽실몽실한 흰 눈썹·수염 |
| 광부 (`MinerOtter`) | 노란 안전모(광택) + 헤드램프, 뒤에 배터리 | 청멜빵 | 반짝이는 큰 눈, 볼에 검댕 |
| 낚시 (`FishingOtter`) | 올리브 버킷햇 + 카키 띠 + 찌 | 카키 멜빵 + 파란 줄무늬 셔츠, 청록 장화 | 동글 점눈, 벌린 입(혀), 주근깨 |

- 측면은 눈 하나, 뒷모습은 모자 장식만 보임(배터리 / 찌 / 잎사귀).
- 명암 기준값(`VREF`)은 농부 정면에서 한 번만 잡음. 그래서 같은 캐릭터면 시점이 달라도 색 톤이 같음.
- 새 캐릭터 추가: `variants.py`에 함수 하나(모자/옷 색 + 얼굴 그리기)를 쓰고 `CHARACTERS`·`export_parts.PREFIX`에 등록하면 됨.

## 9. 새 일러스트 4종 정면 리깅 — 잠옷 / 광부 / 낚시 / 촌장 해달

요청: 새로 받은 정면 일러스트 4장(잠옷·광부·낚시·촌장 해달)을 리깅해서 애니메이션으로 만들기.
8절의 색만 바꾼 바리에이션과는 다른 별도 캐릭터로, 그림이 정면 한 장뿐이라 **정면 리그**만 있음.

- **원본**: `ArtSource/Otter/FrontRig/Source/{PajamaOtter, MinerOtter, FishingOtter, ChiefOtter}_Front.png` (약 1250px, 투명 배경)
- **분리 방식** (`Tools/SheetRig/front_rig.py`, 농부와 같은 `cut_parts` 함수 재사용):
  - 귀 끝부터 발바닥까지 395px(농부 2배 파츠와 같은 키)로 줄인 뒤, 영역 폴리곤(`zones`)으로 픽셀 단위 배정함. 별·단추처럼 작은 영역은 통째로 다수 쪽 파츠에 붙임.
  - 외곽선은 위에 그려지는 파츠가 가져감. 소매-몸통 경계처럼 같은 색 위의 절단면(`open`)은 외곽선 없이 살짝 페더링함.
  - 가려진 부분(팔 밑 몸통, 다리 윗부분, 모자 꼭지 밑, 낚싯대 뒤 모자 챙, 스카프 밑 목)은 주변 색으로 새로 칠함.
  - 외곽선 색은 각 그림의 실제 선 색을 씀. 이 그림들은 선이 깔끔해서 둥글리기는 약하게(`ROUND_SIGMA = 2`) 적용함.
  - 눈 감은 머리(`Head_Blink`): 눈 검색 박스 안의 진한 픽셀(lum < 70, 털은 90 이상)을 눈·눈썹으로 보고 주변 털색으로 지운 뒤 감은 눈 선과 눈썹을 새로 그림.
- **본 구조**: `Root(발 중심) → Leg_L / Leg_R / Body → Head / Arm_L / Arm_R`. 캐릭터별 소품은 아래처럼 붙음.

| 캐릭터 | 소품 본 | 동작 (`front_anim.py`) |
|---|---|---|
| 잠옷 | `Pompom` (Head 자식, 수면모자 방울) | 꾸벅꾸벅 졸기: 고개가 천천히 떨어지며 눈 감음 → 화들짝 깸, 방울 진자 흔들림 |
| 광부 | 곡괭이 = `Arm_L` 스프라이트에 포함 | 곡괭이질: 들어올림 → 내려찍기 → 반동 + 몸 튕김 (팔은 머리 앞에 그림) |
| 낚시 | `Rod` (Arm_L 자식) → `Bobber` (Rod 자식) | 낚싯대 던지기: 뒤로 젖힘 → 앞으로 휘둘러 던짐, 찌는 진자처럼 따라감 |
| 촌장 | `Scarf` (Body 자식, 스카프 매듭) | 손 흔들어 인사 (오른팔은 머리 뒤에 그려서 손만 옆으로 보임) |

- 대기: 숨쉬기 + 랜덤 눈 깜빡임(잠옷은 느리고 길게). 걷기: 농부 정면 걷기 클립을 그대로 쓰되, 광부는 곡괭이 팔을 덜 흔들고 낚시꾼은 낚싯대가 팔 흔들림을 반대로 보정해 똑바로 서 있음.
- 렌더러 추가 기능 (`rig.py`): 포즈에서 `alt`로 스프라이트 교체(눈 깜빡임), `layer`로 그리는 순서 변경(곡괭이를 머리 앞으로).
- **산출물**: `ArtSource/Otter/FrontRig/<Prefix>/` — `parts/*.png`, `<Prefix>_FrontRigParts.png`(아틀라스), `rig_layout.json`(본 계층, rect, 피벗, 정렬 순서, 위치, `swaps`), `parts_overview.png`. 시연 영상: `ArtSource/Otter/FrontRig/otter_front_demo.mp4`.
- 스크립트: `python export_front.py`(파츠), `python make_front_demo.py`(영상).
- **한계**: 정면만 있어서 옆·뒤로 걸을 때 쓸 그림이 없음. 측면/뒷모습 일러스트를 받으면 같은 방식(`front_rig.CHARS`에 시점별 스펙 추가)으로 4방향으로 확장 가능.

## 10. 남은 작업

- **Unity 연결 안 함**: `OtterRigSetup`에 config C로 붙이려면 `rig_layout.json`의 rect/pivot을 RectsA처럼 옮기고, Views 배치를 position 값으로 채우면 됨 (PPU는 파츠가 2배라 기존 230 근처 그대로 쓰면 비슷한 크기).
- 측면 뒷팔/뒷다리는 앞쪽 복사본이라 모양이 같음. 필요하면 따로 다듬기.
- 칠한 부분(팔 밑 몸통 등)은 평평한 색이라 원본 질감보다 매끈함. 팔을 크게 휘두르는 동작을 넣으면 눈에 띌 수 있음.
- 원본 해상도(캐릭터 약 220px)를 2배로 키운 거라 확대해서 보면 흐림. 고해상도 원본이 생기면 같은 스크립트로 다시 뽑으면 됨 (좌표만 원본 칸 기준).
