# 해달왕국 미구현 기능 정리

- 기준: `main`의 `1c96285` (PR #27 광장 확장 머지) + 광장 로딩 수정(`Hotfix/LoadingSlowly`), 2026-10-05 / A1~A4 완료 반영 (`feature/OmissionFunction`)
- 비교 대상: `Docs/`의 모든 문서 35개 (상세 기획서, 기획 변경 명세, 성장곡선·퀘스트 기획서, P0~P3·영토 확장 작업기록, 연동 문서)
- 방법: 문서에 "없음 / 남은 일 / 보류 / 미확인"으로 적힌 항목을 지금 코드·에셋과 대조해서, **아직 없는 것만** 남겼다.
- 이전 판(2026-09-30) 이후 해결되어 빠진 것은 맨 아래 "이번에 빠진 것"에 있다.

## 쓰는 법

- 항목마다 번호(A1, B2 …)를 붙였다. **한 번호 = 따로 브랜치를 따서 할 수 있는 작업 하나**로 나눴다.
- 시작하기 전에 그 항목의 **결정 필요** 칸을 먼저 본다. 결정이 안 된 항목은 결정부터 받는다 (모아 보기: 6장).
- 끝나면 이 문서에서 그 항목을 지우고 "이번에 빠진 것"으로 옮긴다. 번호는 다시 쓰지 않는다.
- 관련 코드 칸은 손댈 가능성이 큰 곳이다. 같은 파일을 동시에 고치면 머지할 때 충돌이 나니, 겹치는 항목은 동시에 하지 않는다.

## E. 플레이로 확인 안 된 것

작업기록마다 "실행하지 않음"으로 남은 것. 기능은 있지만 실제 플레이로 본 적이 없다.

- 새 게임부터 P0 → P1 → 전문 해달 → P2 → P3 → 영토 확장까지 한 번에
- 영토 확장: Lv.6 → 개간 3번 → 미션 → 땅 열림을 실제 시간으로
- 실기기 터치 영역, 기기별 해상도·Safe Area
- 밸런스 실측 (P0~P3·영토 모두 계산값만 있음, 플레이 시간 측정 없음)
- 건설·주민 작업·역할 이동 중 앱 종료, 오프라인 장시간 복귀 중 정비 완료 화면

## 이번에 빠진 것 (2026-09-30 판 이후 해결)

| 항목 | 해결 |
|---|---|
| 밭 강화 UI | 밭 씬 [밭 강화] 버튼·강화 창 (영토확장 6장) → 오프라인 농사도 일반 플레이로 열림 |
| 상단바 설정 버튼 | 설정 화면 연결 (`SettingsPresenter`) |
| 해달 도감 | 전문 해달·관리 해달을 배치할 때 등록 (낚시꾼도 A1에서 연결) |
| 광장 해달 | 정착 진행이 주민·방문 해달을 내보냄 (`PlazaSettings.otterCount = 0`) |
| 다른 장소에 있는 동안 밭 | 농부 수확이 모든 장소에서 진행 (P3-F) |
| 채굴 퀘스트 | `Main_Mine_1·2` |
| 강화 버튼 겹침 | 장소 화면 버튼을 그리는 순서 90으로 내림 (개간지역_P1 7장) |
| 임시 판매 버튼 | 가방 판매 팝업으로 옮김 |
| **A1 낚시터를 여는 방법이 없음** | 왕국 Lv.15에 몽실이가 낡은 선착장 발견(`SettlementConfig._levelDevelopments` → `fishing_found`) → 게시판 "바다로 나가는 선착장"(건설 해달, 골드 2,000 · 목재 60 · 돌 30 · 3분, 임시값) → 낚시꾼 해달 첨벙이 방문 → 광장에서 [낚시터에 배치] → 낚시터 안내를 끝내면 낚시. 낚시 퀘스트는 `fishing_working`부터 보임. 정착 진행 전 옛 세이브는 그대로 낚시 (`feature/OmissionFunction`) |
| **A2 딸기 모종을 사도 심을 수 없음** | 딸기 작물(120초 · 5개 · 심을 때마다 모종 1개) + 수확물 아이템 `crop_strawberry`(21골드) + 도감 채소 칸 + GameManager 작물 목록. 그림은 임시 (`Tools/UIGen/strawberry_art.py`: 당근 씨앗·오이 새싹·감자 덤불을 빌려 딸기를 그려 넣음). Lv.11 해금은 B3에서 상점 레벨 잠금으로 해결. 모종값 문제는 A4 |
| **A3 오프라인 시간 상한** | 한 번 자리를 비운 시간은 최대 8시간까지만 인정 (`OfflineProductionService.MaxCreditedSec`: 오프라인 생산·밭 성장 모두). 돌아옴 팝업에 "최대 8시간까지 일해 둬요" 표시. 시계 되돌리기 반복은 B10에서 막음. 남은 구멍: 건설·주민 작업의 완료 시각은 시계를 앞당기면 바로 끝남 |
| **A4 소모형 모종을 심을수록 손해** | 한 번 수확해서 파는 값 = 모종 하나 값 × 1.5가 되게 수확물 판매가를 정함: 감자 15 → 50, 고구마 35 → 75, 딸기 21 → 90. 배율은 `Assets/Data/Crops/CropPricing.asset` 하나에서 바꾸면 바로 다시 계산 (`CropPricingSetup`). 상점 모종값·수확량을 바꿨으면 `Tools/Farm/Apply Crop Pricing`. 오프라인 수확(1개씩)은 이 규칙 밖 |
| 광장 로딩이 느림 | 걷기 영역 계산을 행 단위로 바꾸고 영토 칸을 꺼진 채 저장 (`Hotfix/LoadingSlowly`) |
| **B6 획득 연출** | 수확(농부)·낚시·채굴(광산 말풍선) 때 아이콘이 가방으로 날아가고 그 자리에 "+N"이 떠오름 (`RewardFly.FromWorld`의 `amountLabel`, `GameManager.HarvestStored`·`FishCaught`). 다른 장소에서 캔 광석은 기존 알림 그대로 |
| **B7 Android 뒤로 가기** | `BackButtonHandler`(저절로 생김): 장소 팝업 → 전역 UI 맨 위 창 → 꾸미기 모드 → 아무것도 없으면 "한 번 더 누르면 종료돼요" 안내 후 2초 안에 다시 누르면 종료. 씬 전환·튜토리얼 중에는 무시 |
| **B2 레벨별 메인 퀘스트** | 성장곡선 기획서 구조를 정착 흐름에 맞춤: 레벨마다 메인 2~5개를 한 줄로 순서대로, 경험치 합 = 레벨 필요 경험치 (공동사업·영토 미션 경험치 포함해 맞춤). 예전 누적 체인은 "도전"(골드만), 일일은 Lv.9부터 골드만. 새 목표 종류: 정착 단계·장소 가 보기·고랑 열기·가방 확장·일일 끝내기, 상점 구매는 아이템 지정. 옛 세이브는 지나온 레벨의 메인을 넘김. Lv.1~15 표: `Docs/레벨별_메인퀘스트.md`. 🖐 안내는 보류 |
| **B3 고랑 한 칸씩 · 레벨 해금** | 밭 1의 3칸 + 나머지 6칸을 순서대로 한 칸씩 (Lv.5·6·8·9·11·13, 300~4,000골드, `FarmBalanceData.furrowUnlocks`). 잠긴 칸은 회색 "잠김". 상점 모종 레벨: 감자 Lv.4 · 고구마 Lv.8 · 딸기 Lv.11 (`ShopProduct._requiredLevel`) |
| **B5 설정 화면** | 진동: 큰 순간(레벨 업·건설 완료·주민 작업 완료)에만, 여러 창이 겹치면 한 번 (`SettingsManager.VibrateMoment`). 수확·낚시처럼 잦은 일은 안 울림. 푸시: 상세기획서 3.3대로 이번 범위 밖 → 켜려 하면 "알림은 다음 업데이트에서 지원해요" 안내 후 꺼진 채. 언어는 한국어 하나, 메뉴 4개(계정·쿠폰·고객센터·약관)는 서버·페이지가 생길 때까지 "준비 중" 그대로 |
| **B9 세이브 보강** | 불러온 값 검사 `SaveDataSanitizer` (빠진 목록, 음수·NaN 시간, 0 레벨, 빈 밭 줄 → 고치고 경고 로그). `*.corrupt-*`는 최근 3개만 남김 (`SaveService.KeptCorruptFiles`). 모르는 아이템 ID는 이미 **보존** (`InventoryManager`가 저장 때 그대로 다시 씀). 더 새 버전의 세이브면 경고 로그. 버전 변환은 `SaveMigrations` 한 곳에 단계 목록으로 모음 (불러온 직후 한 번: 2 첫 심기 안내 · 3 장소 튜토리얼 · 4 옛 정착 진행 — 새 단계는 `CurrentSchemaVersion`을 올리고 한 줄 추가). 설정 화면 [데이터 초기화] (두 번 확인, `GameDataReset`): 저장을 막고 → 세이브를 보관함으로(마지막 초기화 하나만 남김) → 씬을 넘어 사는 진행 상태를 모두 없애고 → 첫 씬부터 새 게임. 소리·진동 설정은 남음 |
| **B10 분석 이벤트 · 테스트용 시간** | 로컬 로그 `AnalyticsLog` → 기기의 `analytics/events.jsonl` (한 줄 JSON, 2MB 넘으면 이전 파일 하나만 남김). 공통 필드: eventId·utc·installId(익명)·sessionId·build·dev. `AnalyticsReporter`(저절로 생김)가 기록: session_start/end, reward_claimed, items_sold, upgrade_purchased, plot_unlocked, shop_purchased, collection_discovered, level_up, village_stage_reached, request_completed, construction_finished, settlement_task_finished + GameManager의 offline_settled, save_recovery. 개발자 지급(TestGet)은 안 남김. tutorial_step·production_started는 아직 없음. 수집 방식을 바꿀 때는 `IAnalyticsSink`만 교체. 시간은 `GameClock`(실제 시계 + 에디터 `OtterKingdom/Dev/Clock`으로 앞당긴 시간)으로 통일: 일일 퀘스트·건설·주민 작업·오프라인 경과·낮밤. 로그 폴더는 `OtterKingdom/Dev/Open Analytics Log`. A3의 남은 구멍(시계를 돌렸다 되돌리기 반복)도 막음: 기기에서는 저장 시각이 뒤로 가지 않음 (`SaveService.Stamp`), 백그라운드 복귀도 그 시각부터 셈 |
| **B4 효과음 (임시 소리)** | 종류 `SfxKind`: 클릭(모든 버튼, `ButtonPressFeedback`)·수확·낚시·광산 발견·재화(판매·구매·보상)·강화/확장·레벨 업·건설/작업 완료. 소리 내는 곳은 `GameSoundEvents` 한 곳에 모음 (기능 코드는 소리를 모름). 수확·낚시 소리는 그 장소에 있을 때만. 같은 소리는 0.06초 안에 겹쳐 울리지 않음. 음원이 없는 종류는 `PlaceholderAudio.CreateSfx`가 만든 임시 소리 |
| **B8 튜토리얼 보강** | ① 처음 심은 작물은 한 번만 10초에 자람 (`FurrowSlotSaveData.durationSec`, 자라는 단계도 10초 기준) ② 설명할 월드 대상이 화면 밖이면 광장 카메라를 그쪽으로 옮김 (`TutorialStep.AtWorld`) ③ 장소 튜토리얼 마지막 장은 "직접 해 보기": 강조된 곳(광장 게시판·밭 고랑·낚시 자리·광산 입구)만 눌리고, 누르면 그 동작이 되며 끝남 (`TutorialStep.TryIt`) |
