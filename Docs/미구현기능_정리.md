# 해달왕국 미구현 기능 정리

- 기준: `feature/Tutorial` 브랜치 (`develop`의 `e5394ce` + 커밋 `bb8df47` + 커밋 안 된 장소 튜토리얼·세이브 관리 작업), 2026-09-30
- 비교 대상: `Docs/`의 모든 문서 (상세 기획서, 기획 변경 명세, 각 작업기록·연동 문서)
- 방법: 문서에 "없음 / 남은 일 / 미확인"으로 적힌 항목을 지금 코드와 대조해서, **아직 코드에 없는 것만** 남겼다.
- 이전 판(2026-09-28) 이후 구현되어 빠진 것: 씬 이동, 밭 개간, 가방·판매, 도감, 퀘스트, 왕국 레벨(프로필), 요정 상점, 소모형 모종, 꾸미기(장난감 배치·해달 놀기), 오프라인 생산(밭·낚시·광산), 광산, 세이브 손상 안내, 첫 안내("당근을 심어 볼까?"), 장소별 첫 방문 튜토리얼, 타이틀 씬, 광장 방문객 해달 3종, 광장 카메라 줌.

## 1. 핵심 진행 구조 (기획서에 있는데 없음)

| 항목 | 현재 상태 | 근거 문서 |
|---|---|---|
| **밭 강화 UI** | 강화는 `GameManager`의 OnGUI 디버그 패널에만 있고, 패널을 여는 코드(`ToggleDebugPanel` 호출처)가 없다. 플레이어가 밭 레벨을 올릴 수 없어서, 밭 Lv.2부터 열리는 **오프라인 농사도 실제로는 켤 수 없다** (개발용 `Offline Test` 창으로만 올릴 수 있음) | 상세기획서 7.2, 오프라인자동수확 |
| 성장 패널 | 시설 레벨, 현재/다음 생산 시간, 가격, 해금 조건, "다음 생산부터 적용" 표시 화면 없음 | 상세기획서 9.1 |
| 단계별 해금 | 왕국 레벨(퀘스트 경험치 → 레벨 보상, 꾸미기·퀘스트 해금)은 있지만, 기획서 7.3의 마을 단계처럼 **작물·밭 개방이 레벨에 묶여 있지 않다** (밭 개간은 코인만 봄) | 상세기획서 7.3 |
| 해달 해금·배치 | `PlotSaveData.workerId`를 저장만 하고 쓰지 않음. 해달 배치 없이 생산되고, 밭 개간에 해달 조건 없음. 규칙 대부분이 기획에서도 미정 (변경명세 12장) | 변경명세 4장 |
| 튜토리얼 첫 10초 생산 | 첫 작물 1회만 10초로 자라는 기능 없음 | 상세기획서 4.2 |
| 튜토리얼 "직접 눌러 보기" | 장소 튜토리얼은 설명만 한다. 실제 버튼을 누르게 하는 단계 없음 | 튜토리얼_세이브관리 |

## 2. 연동 구멍 (지금 바로 이상하게 보일 수 있는 것)

| 항목 | 현재 상태 |
|---|---|
| **딸기 모종** | 요정 상점이 `shop_seed_strawberry`를 파는데 딸기 작물(`CropDefinition`)이 없다. 사도 심을 수 없다 |
| 해달 도감 | `CollectionManager.Register` / `MarkVisited`를 게임 쪽에서 호출하는 곳이 없다. 해달 탭(`otter_farmer`, `otter_fisher`)이 채워지지 않는다 |
| 해달 방문 | 오프라인 방문은 복귀 팝업에 이름만 보이고 저장하지 않는다. 이름은 `OtterVisitBalanceData`의 임시 10개에서 무작위라서, 광장의 방문객 3종(먹보·잠꾸러기·화가)과도 연결되어 있지 않다. 방문 해달 풀(왕국 레벨·장난감에 따라 결정)과 광장에서 해달을 눌러 등록하는 기능도 없다 |
| 광장 해달 | `PlazaSettings.otterCount`(5)만큼 프리팹 4종(농부 모습 + 방문객 3종)에서 무작위로 스폰. 보유 해달(`SaveData.otters`)과 연결 안 됨. 어떤 해달이 나올지는 기획에서도 미정 |
| 방문객 고유 동작 | 장난감 옆에서 놀 때만 나온다. 평소 대기 중에는 나오지 않음 |
| 상단바 버튼 | 설정 버튼(`TopBarView.OnSettingsClicked`)을 구독하는 곳이 없어서 눌러도 반응 없음. 튜토리얼 설명에서도 빠져 있음 |
| 강화 버튼 겹침 (확인 필요) | 낚싯대·곡괭이 강화 버튼이 `GameUI`(캔버스 sortingOrder 200) 왼쪽 아래 (40, 40)에 있다. 네비게이션 바(sortingOrder 100, 아래에서 24~214)보다 위에 그려져서 겹칠 가능성이 높다 |
| 당근·오이 모종 아이템 | 용도 미정. 두 작물은 영구 모종이라 아이템을 쓰지 않는다 |

## 3. 시간·저장

| 항목 | 현재 상태 |
|---|---|
| 오프라인 시간 상한 / 시계 조작 방지 | 없음. 기기 시계를 앞으로 돌리면 그만큼 받는다. 막기로는 확정, 방식은 보류 (인터넷 시간 확인안 등, `오프라인자동수확_작업기록.md` 참고). 3분 미만 부재를 무시하는 기준만 있음 |
| 모르는 아이템 ID 정책 | 명시적 정책 없음. 지금은 경고 로그 후 가방에 넣지 않음 (옛 ID 이름 바꾸기 `LegacyItemIds`만 있음) |
| 세이브 버전 변환 | `schemaVersion` 3까지 있지만 튜토리얼 플래그 처리에만 쓴다. 일반적인 변환 구조는 없음 |
| 세이브 로드 검증 | 중복 ID, 존재하지 않는 작업자 ID, 한 해달의 중복 배치 검사 없음 |
| `corrupt-*` 파일 | 깨진 세이브를 보관만 하고 개수 제한·정리 없음 |
| 플레이어용 데이터 초기화 | 없음 (세이브 날리기·복구는 에디터 전용 `Dev > Save Files`) |

## 4. 연출·사운드·설정

| 항목 | 현재 상태 |
|---|---|
| 획득 연출 | 수확·낚시 때 아이콘이 가방으로 날아가기, 획득 숫자 없음. 광산만 말풍선 위로 아이콘이 뜬다 |
| 사운드 | BGM·효과음 전혀 없음 (`AudioSource` 사용처 없음) |
| 설정 화면 | BGM·효과음·진동·버전 표시 없음 |
| Android 뒤로 가기 | 최상단 창부터 닫는 처리 없음 |
| 튜토리얼 카메라 | 강조 대상이 화면 밖이면(광장 카메라를 움직여 둔 경우) 강조 없이 설명만 나온다. 카메라를 대상 쪽으로 옮겨 주는 기능 없음 |
| 임시 아트 | 밭 NPC(농부 해달 걷기 프레임을 파랗게 칠함), 돌 아이콘(`Tools/MineItems/make_stone_icon.py`) |
| 임시 UI | `GameManager`의 OnGUI 디버그 패널, `GameUI`·튜토리얼의 코드 생성 팝업·버튼 (글꼴도 내장 `LegacyRuntime.ttf`) |

## 5. 확장·콘텐츠

| 항목 | 현재 상태 |
|---|---|
| 낚시터 확장 | 낚시 자리·낚시 해달 1개 고정 |
| 밭 확장 | 밭 3개가 최대 (`PlotSaveData.PlotCount`) |
| 광산 | 채굴 전용 퀘스트 목표 없음(광석은 낚시 목표에 안 셈), 도감에 광석 탭 없음, 광석 2종(다이아몬드·돌)뿐 |
| 퀘스트 | 목록·보상 미확정. 지금은 임시 10개 |
| 가방 전체 판매 | `InventoryManager.SellAll`은 있지만 가방에 버튼을 둘지 미정 |
| 농부 해달 정렬 | 밭 2·3번을 오가면 Y 기반 동적 정렬이 필요할 수 있음 (지금은 고정 sortingOrder) |

## 6. 테스트·개발 도구

| 항목 | 현재 상태 |
|---|---|
| 분석 이벤트 | 없음 (상세기획서 12장) |
| 테스트용 시간 (`TimeProvider`) | 없음 |
| 개발 도구 | 일부: 세이브 날리기·복구 (`Dev > Save Files`), 자리 비운 시간 만들기·레벨 설정·튜토리얼 다시 보기 (`Dev > Offline Test`). **재화 지급은 없음** |
| Unity 플레이 확인 안 된 작업 | 광장 아트 교체(셋업 재실행 필요), 농부 해달 셋업 재실행, 광산(셋업·플레이·EditMode 테스트), 방문객 해달·타이틀 씬(셋업 메뉴 실행 필요), 장소 튜토리얼, 오프라인 3분 기준 |

## 기획에서 바뀌어서 안 해도 되는 것

- 낚시터의 **수영·잠수 채집** → 낚싯대 낚시로 확정 (`낚시터_구현_작업기록.md`)
- 밭 **6회분 저장소 / 작물 전환 예약 / StorageFull** → 밭고랑 슬롯 3개 + 해달 수확 구조로 변경
- **물고기 5종 확률표** → 고등어 / 쓰레기 (낚싯대 레벨로 확률 상승)
- 가방 **용량 무제한** → 칸 제한 + 조개로 확장
- **마을 단계 3개** → 퀘스트 경험치로 오르는 왕국 레벨 (단, 작물·밭 해금 연결은 위 1장 참고)
- **순차 목표 8개** → 퀘스트 목록 (보상 받기 방식)

## 우선순위 제안

1. **밭 강화 UI** — 없으면 플레이어의 성장 경로가 막힌다 (오프라인 농사 포함).
2. **딸기 모종 / 해달 도감 / 설정 버튼** — 지금 빌드에서 "고장"처럼 보이는 것들.
3. **오프라인 시간 상한** — 방식만 정하면 되는 작은 작업이고, 경제가 쉽게 깨지는 구멍이다.
4. **해달 방문 ↔ 방문객 해달 ↔ 도감 연결** — 방문객 3종이 생겼으니 방문 기록과 도감 등록을 한 번에 이을 수 있다.
5. 성장 패널과 왕국 레벨 해금 연결 — 1번을 만들 때 같은 화면으로 묶는 것을 검토.
