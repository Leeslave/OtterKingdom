## 0. 요약

네비게이션 바의 **퀘스트** 버튼으로 퀘스트 화면이 열린다. 시안 구성을 그대로 따랐다.

- 목표를 달성하면 **[보상 받기]**가 뜨고, 누르면 골드를 받는다. **[모두 받기]**로 한 번에 받을 수도 있다.
- 받을 수 있는 퀘스트 수가 퀘스트 버튼에 빨간 숫자 뱃지로 뜬다.
- 진행 수치는 기존 알림으로 센다. **그쪽 게임 코드는 바꿀 필요가 없다.**

**부탁할 것은 2장의 세이브 연결 한 가지다.** 연결하지 않으면 앱을 껐다 켤 때 퀘스트 진행이 처음으로 돌아간다.

## 1. 무엇을 어떻게 세는가

| 목표 | 세는 방법 | 그쪽에서 쓰는 곳 |
|---|---|---|
| 수확 N개 | 가방에 `ItemChangeReason.Harvest`로 늘어난 개수 (작물 분류만) | 밭 수확, **오프라인 수확 포함** |
| 낚시 N마리 | 가방에 `ItemChangeReason.Fishing`으로 늘어난 개수 (물고기 분류만, 쓰레기 제외) | 낚시, **오프라인 낚시 포함** |
| 판매로 N골드 | `InventoryManager.OnItemSold`의 `TotalPrice` 합계 | 가방 판매, `TrySell`, `SellAll` |
| 생산 업그레이드 N회 | 재화 소비 출처가 `FarmUpgrade` 또는 `RodUpgrade`인 거래 1번 = 1회 | `FarmService.TryUpgrade`, `FishingService.TryUpgradeRod` |
| 해달 N마리 만나기 | 도감 해달 탭 항목이 **등록 완료**가 될 때 (방문 흔적은 세지 않음) | `CollectionManager.Register` |

- 세이브 복원(`ItemChangeReason.Load`)과 시작 모종 지급(`Grant`)은 세지 않는다.
- 업그레이드는 **비용이 0보다 클 때만** 센다. 비용이 0인 강화는 거래가 없어서 알 수 없다. 그런 강화가 생기면 알려 달라.
- 해달 퀘스트는 그쪽이 `CollectionManager.Register`를 부르기 시작해야 오른다 (도감 요청 문서 참고).

### 이쪽에서 바꾼 공용 부분

- `CurrencyManager.OnTransaction` (`Action<CurrencyChange>`): 거래로 잔액이 실제로 바뀔 때마다 **출처와 함께** 알린다. 세이브 복원(`SetBalance`)은 알리지 않는다.
- `TransactionSource.QuestReward`: 퀘스트 보상 출처. enum **맨 뒤에** 추가해서 기존 값은 그대로다.

## 2. 부탁할 것: 세이브 연결 — 필수

도감과 같은 방식이다.

```csharp
// SaveData
public List<QuestSaveEntry> quests = new List<QuestSaveEntry>();
```

```csharp
// 불러올 때 (게임 시작 시 한 번)
QuestManager.Instance.LoadFromSave(save.quests);

// 저장할 때
QuestManager.Instance.WriteToSave(save.quests);
```

- `QuestSaveEntry`는 `questId`, `progress`, `claimed`, `claimedLevel`(받은 순간의 왕국 레벨) 네 필드다. 옛 세이브에는 목록이 없으니 빈 목록으로 두면 되고, `claimedLevel`이 없는 옛 줄은 0(모름)으로 읽힌다.
- `QuestManager`는 전역 UI(`GlobalUI`)에 붙어 있고, 실행 순서 `-80`에 준비된다. `GameManager`가 세이브를 불러올 때는 이미 있다.
- 퀘스트 목록에서 빠진 ID의 기록도 지우지 않고 그대로 다시 저장한다.

## 3. 퀘스트 목록

시안의 제목, 조건, 보상 금액을 그대로 옮기고 5개를 더해 **10개**를 넣었다. **실제 목록과 보상은 아직 정해지지 않았다.** 정해지면 에셋에서 고치면 된다.

- 위치: `Assets/Scriptable Obejects/Quest/Quests/` (퀘스트 1개 = 에셋 1개)
- 새 퀘스트: 같은 폴더에 `Create > Game Data > Quest > Quest Definition`으로 만들고 `Tools > Navigation > Build Global UI`를 실행한다. DB가 폴더 안의 퀘스트로 다시 채워진다.
- `questId`는 세이브에 저장되므로 한 번 정한 뒤에는 바꾸지 않는다.
